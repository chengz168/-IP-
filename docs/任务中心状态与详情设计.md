# 任务中心状态、筛选与详情

日期：2026-11-14。范围：补齐原图 task-center-functional.png、task-detail-functional.png、task-detail-bottom.png 中已观察的列表字段、筛选、七阶段详情与底部操作。整体复刻目标保持未完成。

## 事实与实现决定

- 原软件列表显示任务标题、模式、状态、进度、当前步骤、创建时间、继续/详情/删除。顶部统计针对任务，不能混用执行次数。
- 当前产品只有手动逐步执行；模式筛选可以查询自动/后台的空结果，不代表已实现自动调度。
- 当前 d.step 是用户打开的页面。列表同时呈现待完成阶段及详情中的正在查看页，不能用点击导航制造业务进度。
- 七阶段当前就绪条件分别为：原文非空、最终文案已确认且非空、有效配音素材、有效生成或导入视频、有效剪辑视频、有效封面图片、真实发布确认。
- 当前没有真实发布服务或发布确认记录契约，第七阶段不能标完成。exported 只显示“已导出，待发布”。不引入伪造的已发布字段或虚构平台作品ID。
- 素材就绪必须检查当前引用、类型、文件存在与非空。这里只证明文件可用，不替代媒体格式、模型效果与质量验收。
- 进度为当前就绪阶段数除以7；真实业务进度不以历史成功次数累计。当前产物失效或文件丢失会降低当前进度，历史记录仍保留。
- 正在执行/排队、远程待确认优先展示。旧的远程待确认记录不能被后一次成功隐藏。当前无有效产物时，所属阶段最近失败/中断体现为失败/中断；已就绪时保留失败历史，当前产物仍可用。
- 副作用隔离：state 返回动态 taskSummaries，不保存派生状态，不迁移业务数据。不在读取状态时发起模型调用、重试或远程查询。

## 改动范围与失败恢复

- 新增 server/task-state.cjs 统一派生任务统计与七阶段状态，service.state 暴露结果；不将目录包导出等同于发布。
- TaskCenter.vue 恢复六列任务表格、状态与执行模式筛选/清空、任务详情，保留执行记录入口。全部统计按创作任务计数。
- 列表分页与搜索继续使用实际过滤后的记录，筛选后回第1页；任务删除后更新本地状态，不强制整页刷新。
- 删除运行中/排队中/远程待确认任务明确拒绝，避免丢失未知远程ID；错误保留弹窗和记录。
- 详情通过ID读取最新状态，七阶段内保留执行次数、时间、错误和运行详情入口。导入/手填与模型生成区分提示，不把导入视频称为已生成数字人。
- 专用样式保持原图900宽任务详情、顶部信息区与历史区、独立滚动和底部操作；1100窗口保证可读可操作。

## 验收

1. 自动契约：空任务待处理、点击导航不增进度；实际文件/类型/引用决定就绪；丢失文件降低进度；成功执行不能代替已确认文案或真实发布。
2. 失败、重试成功、上游失效与历史保留；旧远程未知记录不能被成功覆盖；删除未知/运行任务拒绝。
3. 源码桌面实点状态/模式筛选、筛选按钮、清空、搜索、页码、任务详情及底部、继续、取消删除、临时任务删除；有效任务与临时任务计数正确。
4. 用当前已有真实PIP任务核对导入视频/剪辑就绪和历史，无模型付费调用、不伪造成功业务数据。
5. 两尺寸留图并检查列边界/弹窗范围/表格滚动。测试、构建和打包仅作各自范围的证据，整体仍未完成。
