# 字数与预计视频时长

需求：在已有字数选择处看到对应的预计时长，并随预设、自定义字数及配音语速更新。

2026-11-28检查仓内 WordLimit、声音语速控件和现有时长模块，未找到适用于目标字数的统一口播估算。已查已安装 UI/UX Pro Max 的表单提示规范，使用专用 Google Chrome 检索 GitHub：read-time-estimate chinese，首轮无结果，随后核对 ngryman/reading-time 的 v1.5.0 页面与官方文档。该项目为 MIT 的文章阅读时长库，未验证为当前配音模型的实际口播预测器，未采用其默认阅读速率，未引入依赖、复制代码或新增推理。固定版本仅作适配评估，不宣称最新维护状态或模型精度。

本项目采用透明可查的规划参数：中文口播每秒3–5字，以选定语速相除并向上取整。参数是产品粗估假设，没有用当前音色校准，不能保证覆盖实际音频。200字、1倍速显示40–67秒。字数目标含标点，未排除舞台说明；其他语言、数字、读法、停顿及不同引擎都会影响实际长度。按用户要求界面统一显示“预计视频时长”，不限定创作类型；提示说明仅按字数和配音节奏粗估，纯画面或剧情不能仅凭字数确定时长，最终以实际成片为准。

复用现有 WordLimit，当前选择旁和下拉选项显示范围，自定义输入同步响应。没有创建额外流程或修改正式数据结构。非法字数不显示错误的数值。边界测试覆盖全部预设、空白、非法输入、自定义、语速及极短时长；实际构建和界面验证另保存在本机 evidence。
