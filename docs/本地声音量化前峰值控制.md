# 本地声音量化前峰值控制

2026-11-15 首次真实IndexTTS产物完整播放成功，7.941224秒，原始22050Hz PCM中140个采样达到满幅。ASR输出为繁体，经Windows StrConv简体转换、忽略标点后与正文一致。这不等于听感验收通过。

固定源码infer_v2_5.py在BigVGAN输出后执行torch.clamp(32767*wav)。进一步核对BigVGAN的实际config.use_tanh_at_final=false及forward源码，模型在返回波形之前已经执行clamp(-1,1)。最初外层forward hook虽消除了PCM满幅点，但无法恢复内部被限幅的波形，v3候选保留作中间对照，不称失真修复。

最终策略vocoder-before-limit-peak-0.95-v2在BigVGAN最终conv_post卷积的forward hook中检查有限峰值，必要时对整段施加统一增益，将峰值降至0.95，然后才进入BigVGAN内部clamp、外部PCM量化和保存逻辑。结构必须与固定版本匹配，未知结构拒绝生成；不修改模型权重和上游源码。保留实际限幅前峰值、增益、目标值及location。该措施不保证其他模型失真和听感均已解决。

处理策略进入本地声音请求快照，版本变更使旧产物失效；新推理收据必须包含实际处理记录。原始失败质量候选及其请求、ASR、播放收据均保留。正常、情绪、语速对照使用同一新策略，避免不同处理混入比较。

验证：真实Torch张量覆盖超幅、低幅、静音、非法数值；实际新生成的WAV原生采样检查、全文ASR、完整播放器播放与刷新绑定；独立取消测试确认Windows虚拟环境真实派生进程已停止。保留听审、音色相似度及整品复刻未验收项。
