# 本地声音配置与试听

本机已安装的独立声音环境为 `D:/AI-Runtimes/super-ip/indextts-2.5`，2026-11-15实测Torch 2.8.0+cu128、CUDA可用；不需要重装ComfyUI。15项模型与配置总计7259666511字节，逐文件SHA和固定revision见 `evidence/validation/indextts-generation/delivery-report.json`。

## 在产品里使用

1. 打开菜单→设置→模型设置，在“语音合成方式”中将“语音接入”选择为“IndexTTS 本地声音”。
2. 在“本地声音环境路径”填写上述完整目录，点击“检查本地声音环境”。检查通过表示依赖、模型文件与CUDA就绪，不能替代生成效果试听。
3. 返回新工作流→声音生成，点击“上传声音”。使用自己的声音或已获授权的参考，选取清晰单人语音，填写名称后保存。视频会先提取音轨；本地IndexTTS以样本为参考，无需逐音色单独训练。
4. 选择已保存的声音，在“最终文案”填写本次需要朗读的新正文。高级设置可调整语速、情绪与情绪强度。点击一次“生成声音”，等待原任务；首次模型加载也计入等待时间，不要因进度暂未变化重复点击。
5. 在“声音生成结果”中完整试听，核对漏字、错读、断句、尾音和音色。如果使用后续视频生成，确认驱动音频确实为选中的新配音。

运行时当前接入支持1至60秒的有效参考样本，Skill建议优先使用10至30秒清晰单人语音。实际模型效果仍需逐段试听；本批验收使用5.184秒自主H3虚构人物音轨作参考，没有完成用户真人音色相似度验收。

## 本批实测与边界

相同42字符正文、相同参考与种子，正常配音7.941224秒；高兴0.7为8.417234秒；正常1.2倍语速为6.617687秒。三份均经完整解码、原生播放器播放至结束、刷新绑定验证，22050Hz原生PCM满幅采样点均为0。正常与快语速经简繁规范化后识别正文一致。

高兴候选将“台灯”识别为“胎能”。该结果保留为未通过，不能仅凭ASR区分模型发音与识别错误，也没有把识别文字强行替换成原文。音色相似度、情绪真实性和听感尚未验收。

峰值保护位于固定BigVGAN最终卷积之后、内部限幅之前，实际记录源峰值及增益；原始满幅候选与处理位置较晚的中间候选均留档。保护降低了限幅风险，不能保证所有声学瑕疵消失。

这次验收使用独立数据目录，未自动更改原任务的服务配置。原厂完整隐藏提示词与内部声音模型暂无可靠信息，不能将本地接入解释为已取得原厂内部实现。
