# 批量链接静默提取后端

日期：2026-11-22。范围：后端批次调度、服务动作、桌面白名单和定向测试。

## 设计与验收

- 单项和多项统一由 `startExtractBatch({id,links})` 发起，立即返回持久化批次；字符串支持多行分享文本，数组支持逐条分享文本，最多 50 项。规范 URL 去重，重复项保留并标明来源。
- 每项依次调用既有静默提取入口，保留真实本地下载、后台浏览器会话和外部服务能力，不播放音频、不主动打开可见窗口。每项登记 `extract` 运行记录，记录批次与项目 ID。
- `extractBatchStatus({id,batchId})` 返回批次本体；省略 batchId 返回 `{batches}`。批次包括逐项状态、进度、错误、转写正文和素材引用；counts 包含 total、queued、running、succeeded、failed、cancelled、unknown、duplicate、interrupted。
- `cancelExtractBatch` 立即标记 stopping，取消尚未开始项目并向当前运行发出真实 abort；当前执行器结束前保留 stopping，绝不宣称远端已取消。
- 单项普通失败继续下一项，结果为 partial 或 failed；unknown 停止后续提交并保留原任务凭据，阻止同任务再次开始提取。应用重启不自动重交，依据真实运行记录恢复为 interrupted 或 unknown。
- 结果存储在 `store.data.extractionBatches`，草稿普通保存不能覆盖异步结果。提取不会自动修改原稿。
- `useExtractBatchItem({id,batchId,itemId,expectedDraft})` 仅选用 succeeded 项，要求当前 sourceUrl、sourceText、rewrite、finalText、confirmed 五个字段匹配客户端完整正文来源快照。先归档原原文、改写与确认稿，再写入正文和来源，清空过期改写与最终稿、撤销确认、进入第二步。素材保留，归档可审计。
- 修改范围仅新增后端模块、service 必要接入、preload 动作、定向测试。保留已有原单链接动作兼容。每项证据和失败状态来自真实执行结果，测试夹具不冒充真实平台解析验收。

## 恢复与限制

平台链接是否可获取由已有提取器、网络、服务和平台权限决定；批量能力不绕过登录或平台限制。云端异步提取目前没有可靠查询契约，返回任务 ID 时保留 unknown，不自动重试。同任务有 unknown 时必须先核对原服务结果。

## 验证

定向测试覆盖去重、单条、逐项串行、进度、部分失败、取消、重启恢复、unknown 防重、显式选用、草稿快照冲突及素材保留。整体验收由负责人执行本地应用更新和真实媒体创作链路验证。

## 本批实现与回执

- 实现文件：`server/batch-link-extraction.cjs`；服务动作与来源独立参数接入 `server/service.cjs`；桌面动作白名单接入 `electron/preload.cjs`。
- 单条失败继续，unknown 停止后续队列。相同 URL 的 unknown 防重同时检查其他草稿中的提取任务；不能通过新建草稿重复提交同一未知远程来源。
- 普通草稿保存不会覆盖批次；提取素材引用保护进入既有删除动作。选用文案核验来源哈希，当前原稿变化会拒绝覆盖，原稿、改写和确认稿归档后保留。
- 参考画面采集额外转发 `allowSilentVideo=false`，只由参考分析显式启用；普通提取文案仍保留音轨要求。此项配合负责人修改的无音轨画面分析路径。

## 独立质量复核后的修复

- 独立小组复现同 URL 跨草稿并发、正文未变但新确认稿被旧请求清空、原运行已成功但批次仍 unknown 等问题；此前的首次回归未覆盖这些边界，已补真实状态回放测试。
- 选用接口强制 `expectedDraft={sourceUrl,sourceText,rewrite,finalText,confirmed}` 五字段全部相等。仅传旧 `expectedSourceText` 不足以选用，缺字段或任一字段变化均拒绝。
- 同 URL 在 queued、running、stopping 窗口及 unknown 状态跨草稿互斥；参考视频 analyze/create/use 动作也检查已落盘批次，封堵 `setImmediate` 前没有 run 的排队窗口。
- 提取回包 `stale` 在 Runtime 工作返回前即拒收；存量成功记录若后来被标记 stale，选用也拒绝。
- `deleteDraft` 清理该草稿的终态提取批次，实际素材不删除；保存失败回滚数据。素材引用检查忽略已不存在的草稿，避免残留记录永久占用素材。
- `extractBatchStatus` 与 `reconcileExtractBatch` 只对账当前本地权威原 run 的 succeeded/failed/cancelled 终态。没有可靠远端查询契约时仍保留 unknown，不声称查询过远端，不自动重交。
- `confirmExtractBatchTerminated` 只允许无活跃执行器的 unknown 项，必传 expectedRunId、expectedRemoteId、confirmed=true、8 至 2000 字的核对说明。人工回执保留原任务和远程 ID，并明确结论来自用户确认；凭据变化或已经成功时拒绝人工终止。
