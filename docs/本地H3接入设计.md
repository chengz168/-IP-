# 本地 H3 接入设计

已验证现有 ComfyUI 可生成新的中文口播音视频。接入沿用视频生成页面及同一执行记录，不新建一套工作流界面。

单形象短片实现接受1至15秒驱动音频，可构建608×1056竖屏或1056×608横屏；目前真实产品短片成片样本约5.17秒竖屏，不能外推全部时长和横屏均已实测。首帧来自所选形象视频，音频通过H3 AddGuide约束，生成后使用原驱动音频封装；画面来自新推理，声音来源明确记录，不把重新封装称作重新克隆。多镜头仍须单独实现和验收，不能静默退回现有成片。

超过15秒的单形象分段实现已接入原入口，真实17.31025秒验证正在进行，尚未完成长片成片验收。分段计划记录连续的24fps帧界与32k驱动采样区间，优先选择静音附近切点；原驱动副本、完整PCM、每段驱动和原始新生成画面均保留SHA。每段约4至12秒，独立任务凭据在提交前保存。最后按计划帧数裁切并拼接各段新画面，再封装完整原音轨，不循环短片，也不拼接多次重编码的片段音轨。

续接核实：两段真实模型已生成17.333333秒/416帧完整长片，正常产品查询绑定、解码、正文ASR、刷新和原生完整播放通过。最终封装移除shortest，避免音轨在帧内结束时丢尾帧。旧方案8.5秒处的手指与嘴部表情重置未通过连续性检查；新计划改为记录previous-planned-last-frame-v1，后续段从前一段最终保留的末帧派生PNG并先保存来源和SHA。旧计划保持原策略恢复。对照实验明确沿用第一段，只新增第二段推理，实际RGB像素/服务器输入字节和音轨参数已核对；是否改善接缝须等结果，不能由代码结构推断效果。

中断后的查询只读取已提交段，不产生新推理。“继续分段生成”是明确提交后续段或重试确认失败段的入口；已完成片段保持原产物和原模型ID，失败尝试完整保留。原输入或配置变化后禁止提交下一段；已有结果可回收，过期结果不绑定当前任务。技术检查、原生播放、听感、连续口型与接缝质量分别记录，不能相互替代。

模型设置选择本地 ComfyUI H3，填写本机服务地址。原任务和原设置不自动切换。每次提交记录 prompt_id、上传输入的散列、图结构及版本，超时或失联只查询旧任务，不自动重交。取消仅针对自己的 prompt_id，保留未确认状态；恢复查询沿用原任务与原上传音轨，不能读取已被替换的驱动音频。

验收包括：真实界面提交新模型任务、确认新视频文件、完整解码、语音识别辅助检查、身份与连续同步检查、失败不覆盖、单任务取消及恢复查询。生成成功不等于质量通过，也不等于整体一比一复刻完成。
