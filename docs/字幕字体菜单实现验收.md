# 字幕字体菜单实现与验收

日期：2026-11-14。总目标继续进行；本批只校正字幕字体选择控件，不代表全部页面一致。

## 可核验依据

原软件1400×1000实点：字体触发框约207×24，展开面板与触发框左边、宽度一致，下间隔4px；深色背景、圆角、约266px高、每项64px、约四项可见并可滚动，选中项蓝底。原生select无法复现此展开样式。截图reference-font-menu.png保留在本批证据目录。

原软件临时测试任务已由界面删除，继续原任务后只读SQLite确认仅updated_at变化，pipeline_data/settings_data一致。本批原软件菜单观察不确认任何新样式。

## 实现范围

- 独立字体选择组件，保持既有fontId/fontFamily契约、系统和本地字体目录以及真实FFmpeg预览。
- 自定义深色列表，与触发框同宽；优先展示已配置目录字体，显示真实目录中的名称，不硬编码不存在的字体。当前字体缺失时保留明确提示。
- 触发框保留焦点，通过上下键、Home/End、翻页、输入名称前缀定位；Enter/空格选择。Escape只关闭列表，Tab与外部点击关闭列表且正常移动焦点。
- 列表在可用空间内定位，随窗口改变或外层滚动收起，避免遮住固定页脚；选中项自动滚入视野。卸载移除监听器。

## 验收与恢复

通过源码Electron及既有Playwright/CDP工作流，在新隔离任务实际点选本地/系统字体、键盘选择、滚动、Escape/Tab/外部点击，确认与取消后重新打开、保存刷新恢复。验证两种窗口、四档字号的触发框对齐、列表宽度/可见范围/页脚命中；看实图。基线业务JSON留档，结束通过UI删除本批任务并恢复原任务、字号和窗口，比较业务JSON。

对原厂与本项目已生成的同源视频，仅度量解码帧底部新增字幕区域；源视频自带字幕不算本项目能力。保留底部80的测试前提，不能将其当作编辑器420参数已核实。

本批不凭预览相似改变正式字幕字号；实际ASS和CSS预览映射、动态模板及其余业务差距继续记录。若没有独立EXE启动证据，明确保留未验证。

## 本批结果

- 自定义列表已接入真实系统字体，字体/字号触发控件24px等高，列表宽207.25px、最大高266px，与触发框左边一致，四档字号、两窗口共8种菜单状态所列几何问题0、页面错误0。最终实图已查看1400舒适和1100大字号。
- 实际点选、上下键、Home/End、翻页、名称前缀、Enter/空格、Escape、Tab、外部点击、滚轮和窗口改变收起通过。取消不写盘且重开保留，确认保存fontId/fontFamily、刷新恢复通过。
- 当前隔离桌面未配置附加字体目录，本轮桌面选择的是系统目录中的微软雅黑；不能把目录优先的代码分支称为已在此桌面实际验证。原厂与本项目菜单的实际可选字体集仍不同。
- 两次专项超时来自验证脚本前提：第一次点击了菜单下面被覆盖的粗体按钮作为“外部点击”，改为点击未覆盖的预览标题；第二次要求Home后scrollTop为0，实际受4px内边距影响为4，已改成验证首项可见且滚轮确实改变滚动位置。未用强制点击绕过遮挡，也未冒充产品修复。
- npm test本批一次：54/54、1519.4222ms、退出0，存在既有Node模块类型警告；最终build3194模块、JS278.50kB/CSS105.75kB、3.32秒、退出0；目录打包和28文件哈希一致、退出0。独立EXE首次启动仍未验证。
- 临时任务经UI删除，恢复1400×1000及舒适字号，当前隔离工作区完整业务JSON与本批开始前一致。
