# 样式与交互巡检

## 本批目标与边界

用户反馈非口播资产列表文字堆叠。本批保留原有视觉语言，修复确定的挤压、裁剪、溢出和操作可达性问题，并巡检各主要页面。布局验收不替代媒体生成质量验收，不触发付费生成或下载。

## 方案与验收矩阵

- 主负责人：新建独立数据工作区复现13项资产、长名称与多集列表；比较修复前后几何与截图。覆盖1400×1000、1100×760和舒适/大字体，检查首中尾滚动、查看与勾选分离、筛选与全选、返回和关闭。
- 测试：独立空白工作区检查新工作流7步、旧工作流、声音、形象、素材、任务、账号、设置与主要弹窗；记录空状态与有数据状态的实际覆盖，不能外推未操作状态。
- 审查：只读核对全局样式和主要视图的固定尺寸、flex收缩、滚动、禁用原因与操作层级；只修可复现或可直接证明的问题。
- 探索情形：超长中文名称；超过可视高度的长列表；字体放大；窗口变窄；切换筛选后勾选范围是否清楚。
- 每个列表项按内容自然增长，列表自身滚动；主要操作、文本与选择控件不得重叠或被压扁。所有修复需实际Electron复核。

## 模块影响与恢复

优先局部CSS，确需交互说明时修改对应组件，不改生成协议、模型配置和业务持久化格式。保留候选、选用、批量范围现有含义。构建失败先修源码，日常更新前确认无活动任务并备份；通过桌面既有入口正常重开，不强杀任务，不停共享模型服务。

2. 工作台窄于860px时列表置于详情上方，以两列显示可滚动的选择项；点击资产直接定位并聚焦详情，勾选仍只改变批量范围。大窗口维持左右布局。
3. 资源卡长名称、200字连续ASCII描述按边界换行；素材名称/分类断词。素材选择明确“全选当前页”，展示其他页选中数量，并提供取消全部选择。刷新仅剔除已不存在ID。
4. 设置离开保护涵盖返回、菜单、新任务/选任务、自绘标题栏关闭；继续编辑、放弃修改、保存并离开均有明确行为。保存失败留页，专用启动配置独立保存，切换设置分类保留未保存启动路径，不静默提交密钥。Windows强制结束进程不在此保护声明内。
5. 资源保存提交点击时快照，异步返回只关闭原编辑会话，不关闭随后打开的新会话。
