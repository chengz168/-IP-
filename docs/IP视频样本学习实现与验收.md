# IP视频样本学习实现与验收

2026-11-14。上一轮为有证据的进展，完整复刻目标继续active。本批补教程所述深度学习的视频内容依据；只使用明确选定的本地视频和现有服务，不假称已完成账号主页采集或全视频理解。

## 设计与影响

1. 在已有“导入本地学习样本”弹窗增加文案/视频切换及视频素材选择，主页面保持当前结构。视频浅度学习分析实际转写，深度学习同时分析15%/50%/85%三处采样画面，再结合实际音轨文字生成风格档案。明确三帧不等于看完所有镜头。
2. 使用已有离线Whisper、本机视觉模型及文本模型，不下载模型。复用素材采样实现，不把素材原有描述作为新分析。视频无音轨/转写为空/服务未配置明确失败，允许使用原有文本学习路径，不静默伪造成功。
3. 保存assetId、文件SHA256、实际转写与时间轴、画面时间/描述、实际模型和请求参数。文本证据只能引用真实转写连续摘录；画面分析独立展示，不混充音轨事实。
4. 学习前后验证同一视频字节及输入/模型配置。更换视频、修改输入、停止或保存失败不能覆盖旧档案；结果先完成全部核对后一次保存。失败保留已完成阶段的证据。档案引用素材时不能删除源文件。
5. 不自动改变用户原模型与TTS配置，不改原厂，不调用主页桥、克隆、口型或发布。现有文本档案无需迁移；文本重学不得错误沿用已失效的视频来源。

## 验收标准

- 有意义测试覆盖视频浅/深区别、采样与音轨依据、模型伪造摘录、文件/输入/配置变化、停止和写盘回滚，保留原文本功能。
- 对现有本地19秒视频实际执行识别、深度视觉及文本分析，逐项检查采样图、转写和摘要，未确认细节保留未知；不以schema通过代替内容质量通过。
- 源码Electron实点选择视频、学习、打开分析、刷新与重新学习取消；两个窗口四字号检查新增弹窗对齐、间距、滚动与页脚可点。只读失败/过期回归按受影响范围验证。
- 测试/构建/目录包哈希后恢复原工作区完整JSON含updatedAt；独立EXE历史审批拒绝不绕过。全功能、原厂像素一致和生成效果仍需继续验收。
