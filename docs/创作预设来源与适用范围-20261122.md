核验日期：2026-11-22。研究目标是给软件内的中文创作预设提供可追溯的方法资料；没有取得对标软件的私有提示词，没有安装或执行任何第三方 Skill 脚本。下面的短视频规则为本项目针对现有文案、分镜、语音和视频链路编写的适配规则，并非外部 Skill 原文。

## 八类本地中文预设建议

以下均为本项目适配。每次仅注入当前创作阶段的规则，业务输出结构、用户已确认事实、实际素材与时间限制优先。自动路由的依据是已有内容与当前流程；“素材、视频、内容”等泛词不足以推断具体类别。混合或资料不足应返回通用，并让用户覆盖。

### 商品介绍

适用：商品详情/商品图驱动的选题、文案、商品分镜、单镜设计与视频指令。依据：copywriting、ad-creative、video。

1. 文案以一个真实使用需求切入，把已知产品特征连接到可以从资料支持的使用价值；不补销量、评价、测试结果、赠品或保证。
2. 钩子承诺应在本片内兑现；有证据才能用对比或效果，不强制制造夸张痛点。
3. 分镜安排“对象/结构可见 → 一次具体操作 → 可见变化或细节”，每镜一个表达目标；仅素材允许时安排手/动物/环境，不能把摆设当商品附件。
4. 动作基于实际首帧，明确起始、一个主动作、终态；展示节奏服务当前保留窗口，不能靠描述把白底图瞬间变成不存在的自然场景。
5. 配音采用自然说明口吻，一处卖点留一个语义停顿；不靠全程高亢制造推销感，品牌/型号/材料保持原文。

### 知识口播

适用：知识型选题、文案生成/改写、口播画面提示。依据：content-strategy、copywriting、copy-editing、social；镜头规则为本地适配。

1. 开头直接提出观众的一个具体问题，并给出本片能解释的范围；不虚构“99%的人不知道”等比例。
2. 正文采用结论、原因、资料支持的例子，保留前提和例外；例子缺失时不用编造案例填补。
3. 镜头/图示只解释当前句的概念，避免无关素材堆叠；有人物时保留身份与自然动作。
4. 口语化拆长句，重音落在关键词，解释句稍缓；保留用户选定音色，不因切换预设改声音身份。

### 操作教程

适用：教程文案、步骤分镜、生成/录屏说明。依据：social 的 how-to、copy-editing、video；可验证步骤规则为本地适配。

1. 先说目标结果和前置条件；只有有来源时才承诺完成时间，不猜界面名称、按钮与版本。
2. 每步写清对象、操作、操作后的可观察结果；少一步会失败的条件必须保留。
3. 画面一次只示范一个关键操作，按实际先后出现；有精确 UI 时优先真实素材/录屏，不能让生成模型杜撰软件界面。
4. 配音随动作停顿，重点动作完成后再说下一步；不把所有操作挤进同一短镜。

### 测评对比

适用：测评选题、对比文案、评测/产品分镜。依据：copywriting、ad-creative 的证据限制；比较条件为本地适配。

1. 先定义同一比较维度、对象及资料范围；规格对照必须称规格对照，未亲测不能写“实测”。
2. 每项结论对应参数、画面或用户提供记录；没有条件控制的数据不升级为普遍优劣。
3. 分镜使用相同景别/角度/尺度表达可比项；不能靠视觉合成伪造效果对照。
4. 给出适用人群与局限，结尾依据已展示信息收束；语音克制，强调差异而非刻意贬低。

### 故事叙事

适用：故事选题、叙事文案、拆集分镜与视频指令。依据：social 的 mini-story/story arc；角色连续性规则为本地适配。

1. 用一个具体局面引出角色目标、阻碍与选择，让结果与前因呼应；不强制套反转。
2. 用户给的是事实记录时保留事实与不确定性；明确创作为虚构时才能补虚构情节，不能混写成真人经历。
3. 角色身份、服饰、关键道具与空间关系跨镜保持连续；每镜用动作推进一个情节点，避免旁白和画面讲不同事件。
4. 语气跟角色处境变化，情绪留转折空间；不过量塞入手势、夸张表情与多段运镜。

### 数据解读

适用：数据选题、解读文案、图表分镜；现有渲染不能精确绘图时先提供画面需求。依据：content-strategy 的资料与新增信息、copywriting 的证据要求；数值可视化规则为本地适配。

1. 所有数值带来源语境、单位、时间与比较基准；无资料不能猜补，不把相关性说成因果。
2. 每段围绕一个数据问题，区分原始事实、计算结果、作者判断；标题不能夸大正文结论。
3. 数字、坐标、单位、标签应由可控排版/后期呈现，不能要求生成式视频模型保证精确文字；不能用无比例装饰图冒充真实图表。
4. 配音在数字与结论之间留理解时间，按资料支持程度表达确定性；不能读成一串数字。

### 生活记录

适用：日常/宠物/旅行/体验记录的选题、文案、非口播分镜。依据：social 的真实经历和生活内容、video 的素材制作方式；观察与声音规则为本地适配。

1. 从资料中一个具体时刻、动作或细节切入，不把普通片段强行编成人生教训或带货剧情。
2. 保留第一人称表达和真实观察；未知地点、人物经历、心理与结果不猜写。
3. 镜头服务一个日常事件的开始、变化与收束，光线/空间/人物连续；动作量适合短时长。
4. 有可用环境声时为其留空间，旁白少而具体；音色仍使用当前选择，不强制全程背景音乐。

### 通用表达

适用：内容不足、混合内容、不能可靠分类或用户选择通用。依据：copywriting、copy-editing、video 的基础方法。

1. 使用资料中最明确的一个主题与观众问题，不增加未提供的身份、产品、成绩或情节。
2. 一段一个要点，开头与正文一致，结尾只给与当前内容相关的下一步。
3. 分镜写清已知主体、环境、动作、机位与声音；资料不支持的部分留为待用户补充，不能用花哨运镜掩盖内容缺失。
4. 语音以自然口语为准，按语义停顿；字幕/画面和已确认文案一致，不能让预设改写已经确认的事实。

## 阶段隔离与质量验收建议

| 阶段 | 允许注入 | 不应注入 |
| --- | --- | --- |
| 选题 | 目标受众、内容问题、钩子候选、资料范围 | 未知事实、完整镜头/模型参数、虚构热度 |
| 文案生成/改写 | 开头承诺、正文顺序、信息证据、口语节奏 | 输出契约外字段、强行扩大局部改写范围 |
| 分镜 | 可见表达目标、主体/环境/动作/连续性、素材约束 | 生成模型不能保证的精确文字、过量跨场景剧情 |
| 声音 | 文案语义、自然停顿和重音、已有音色身份 | 未接入的情绪能力、为适配模板伪改正文 |
| 视频指令 | 已保存镜头四字段、实际参考图与当前保留时段 | 隐藏历史剧情、新增无来源人物或商品效果 |

建议每次运行保存 `presetId/version/stage/sourceIds/reason` 与实际采用的规则文本，方便核对自动选择；用户覆盖需写入项目选择，系统预设不能被项目局部修改覆盖。

方法接入成功、结构通过、模型返回、媒体可播放、内容质量达标是不同结论。需要实际检查主张是否有据、首帧到动作是否连续、产品/人物是否保持、字幕/数字是否正确、听感是否自然；没有通过相应检查就不能称“高质量已完成”。
