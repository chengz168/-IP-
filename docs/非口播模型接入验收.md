# 非口播模型接入与验收记录

日期：2026-11-16。仅记录本模块可核实结果；主线程负责实际产品端到端验收。

## 配置与接口

`new StoryGenerator(store, media, providers)` 提供 `image(input,ctx)`、`video(input,ctx)`、`compose(input,ctx)`、`check(ctx)`、`recover(run,ctx)`。生成、合成、恢复成功均返回实际 Store 素材；素材的 `storyGeneration` 保留输入指纹、修订、目标、引用、模型、输出 SHA256，且 `qualityAccepted:false`。技术生成成功不能代替用户确认。

- 图片协议：`storyImageProtocol=comfy|compatible`，地址 `storyImageBaseUrl`，模型 `storyImageModel`。默认本机8188与 `sd_xl_base_1.0.safetensors`。
- 视频协议：`storyVideoProtocol=comfy-h3|bridge`，地址 `storyVideoBaseUrl`，模型 `storyVideoModel`。默认本机8188与 `minimax_h3_fl2va_pruned_int8_convrot.safetensors`。本地仅该H3模型适配，不能随意替换Wan、Flux等UNET；云桥由配置的实际服务处理。
- 支持9:16、16:9、1:1、4:3、3:4。H3每镜头4至15秒，模型17k+5帧网格可能产生额外尾帧，收集阶段明确裁去超出计划的生成帧，不循环或补静帧凑数，原模型时长及文件指纹留痕。

## 图片引用能力边界

本地SDXL文本生成与图生图均是真实Comfy工作流。真实验收发现多图参考板会保留拼贴布局，故已移除参考板方案。当前只能选择单张主参考图片进入VAEEncode与denoise=0.68图生图，标记single-primary-img2img；有多个绑定而未指定主参考时拒绝提交。其余绑定仅以名称/描述/提示词参与文本要求，未作为视觉控制。完整保留每个源资产ID与SHA256、usedReferenceAssetIds、unusedVisualReferenceAssetIds和能力限制。它没有身份控制模型，不能承诺人物身份一致，需要用户逐图确认。

云兼容无参考走 `/images/generations`，有参考必须走 `/images/edits` 并实际上传全部参考图片。服务不支持编辑时直接失败，不静默降级为纯文本。标准兼容协议通常没有异步任务查询，本模块不虚构任务接口；提交回包丢失时保留clientId与未知记录，需服务端查回，不能自动重交。

## 非口播动态视频

采用本地已安装 `comfy_extras/nodes_minimax_h3.py` 的 `MiniMaxH3ImageToVideo` 首帧接口，以及原生音画联合采样、视频/音频VAE解码、CreateVideo、SaveVideo。没有强制上传配音、没有口型引导节点，模型提示词遵循 `h3-prompt-writing` 的I2VA首帧说明与三段结构。具体场景、动作、运镜与环境声来自镜头提示词，首帧来自用户选用的镜头图；用户中文内容原样保留，文本规划步骤应输出适合模型的英文视觉描述、保留中文对白。

服务端收集后使用FFprobe检查流、画幅、尺寸、时长，并用FFmpeg完整解码视频。素材中始终保留 `qualityAccepted:false`；这些检查不能证明动作自然、人物一致或内容满足用户要求。

云视频桥以multipart上传图、模型、prompt、duration、aspect、clientId，返回 `jobId/statusUrl/videoUrl`。原ID与查询地址持久化；后续查询必须匹配原ID。未提供查询地址、未知状态、下载失败等保留未知，不自动再提交。跨域产物下载不携带模型Bearer密钥。

## 取消与恢复

提交Comfy前写入完整图、图指纹、clientId、输入、输出节点、媒体类型、模型和引用；回包丢失时可用原clientId及图匹配原队列/历史。`recover` 只查询原任务，不提交新任务。

已取得prompt ID的停止只调用 `/queue` 删除该ID与 `/interrupt` 的 `{prompt_id:本次ID}`。已核对本机 `server.py` 实现：该字段会核实当前运行ID，不会触发无ID的全局中断。停止本地等待仍不能直接证明远端已终止，保留原任务供查询。

## 与前序步骤及合成的关系

合成使用传入当前集的有序镜头清单，缺视频、重复镜头ID、时长不匹配均拒绝；使用真实镜头视频及原音轨，统一画幅、24FPS并等比补边。无原音轨的镜头才补静音。可选 `narrationAssetId` 或 `narration:{assetId}` 来自上一步配音；只在与当前集总时长相符时混入，不擅自裁剪整篇配音，多集需独立匹配。分集绑定与旧下游失效由领域模块处理。
