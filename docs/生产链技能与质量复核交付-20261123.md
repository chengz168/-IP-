# 生产链技能与质量复核交付（2026-11-23）

## 本批变化

1. 将两项已核对版本与 MIT 许可的 GitHub 制作方法改写为中文规则，按题材和阶段接入现有创作请求。商品卖点必须对应资料和可见证据，分镜与生图只保留一个主要视觉焦点。来源、适用阶段和限制可在技能库查询；未执行第三方脚本。详见《GitHub阶段技能接入-20261123.md》。
2. 七步导航先等待子编辑器和草稿保存再切换，阻止重复点击和异步换稿。保存目标步骤失败会返回原步骤，保留编辑。
3. 合成输入包含实际旁白和镜头文件 SHA256。探测前后、合成后、产物解码前后核对，防止同编号、同路径媒体替换后误登记或交接旧结果。参考图片也在登记时复核。
4. 发布步骤内新增成片质量复核。技术检查包含所选文件、摘要、视频轨道、时长和字幕时间格式；事实、形状、动作、声音和字幕感官效果分别由人工审看。保存问题说明或逐项人工确认，保留带媒体版本的历史；文案、设置或文件变更后失效。普通草稿保存不能伪造或擦除复核历史。
5. 查询 ComfyUI 原任务和收取产物直接访问原服务，避免 GPU 繁忙时被额外的两秒启动探测阻断；新提交继续检查环境和防止重复启动。
