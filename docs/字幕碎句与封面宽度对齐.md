# 字幕碎句与封面宽度对齐

日期：2026-11-15。整体目标保持完整复刻，当前不宣称完成。

上一轮完成真实原速音轨修复和C1受控生成，属于progress。C1自动转写末字有差异，真人感及人物匹配未验收；本轮不继续随机声音候选。

本轮直接查原安装包公开渲染配置，未执行其模块。封面预览与导出均使用：启用文字背景且显式指定背景宽度时使用该宽度，否则画布宽度×0.9。1080画布为972；当前textDefaults.boxWidth=980。原版同样逐字换行，因此不擅自增加自动平衡、不暗改生成标题、不把单字落行消失视为已有事实。保留用户已存的显式boxWidth，新的默认值对齐972；背景宽度影响折行也需与原版相同。改动覆盖编辑预览和后台绘制，字体/模板字号/坐标保持原设置。

本地ASR原词序列中，6字阈值把“路邊的燈亮了,”拆成5字与仅0.24秒的“了,”。调整规则限于同一识别段内、上一组尚未以标点结束、时间紧邻且末组仅一个文字字符的短尾：将上一组最后一个完整词移入尾组，两组均保留至少2个文字字符，尾组不超过原maxChars；仍保留原最大长度与识别词边界，零时长兼容不变。独立强调句、跨停顿、英文单词、无词级凭据不处理。真实输入不改字、不改原始ASR记录，不自动简繁转换。此为已授权本地识别能力的分组修正，不声称原云端采用同算法。

先补能在旧代码重现的定向回归；修后实际使用已有本轮配音/口型上游，新建隔离验证草稿，经软件实际字幕识别及剪辑按钮生成、同模板封面导出。核对实际字幕词边界、输出图像、视频音轨、完整播放、刷新绑定和原文件保护；所有原草稿及设置不变，恢复原草稿。生产变更后执行全套、构建、目录包和文件一致性，保留旧失败证据。旧封面内容质量不因默认宽度修正自动通过。
