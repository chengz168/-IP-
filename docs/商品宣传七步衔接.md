# 商品宣传接入现有七步流程

商品宣传使用现有任务、文案确认、声音、剪辑、封面和发布数据，不在第一步另建完整制作流程。

| 现有步骤 | 商品宣传操作 | 交接数据 |
| --- | --- | --- |
| 学习对标 | 商品宣传页读取商品资料、勾选主图和详情图，或上传图片；生成脚本草稿 | 商品事实、图片来源、视觉观察、分镜和模型请求记录 |
| 改写文案 | 接收草稿，用户可以直接核对确认，也可编辑或改写 | 已确认最终正文；不强制重复改写 |
| 声音生成 | 复用本地或云端声音配置与现有生成按钮 | 带正文、模型、音色及参考音频哈希的实际音频 |
| 视频生成 | 在“商品宣传”模式调整选图和镜头，必要时同步第二步确认稿 | 复用第三步整段音频，按实际时长生成商品原图展示视频和字幕 |
| 网感剪辑 | 选用原片与字幕成片，继续音乐、标题、字幕等现有工具 | 当前原片、真实字幕时间轴、剪辑结果 |
| 标题封面 | 复用既有标题与封面制作 | 当前任务封面与标题 |
| 一键发布 | 复用既有发布和导出能力 | 发布素材；实际平台确认与本地导出分别记录 |

## 一致性与失败恢复

- 第一步选用脚本后进入第二步待确认，不替用户确认，也不生成声音或视频。
- 第四步开启旁白时，必须存在与当前正文及声音设置匹配的第三步音频；不会再次调用配音模型。
- 第二步修改正文后，可在第四步按原文顺序同步到镜头，保持已有图片绑定；程序保留全部字符，不让模型重抄正文。
- 商品资料或图片选择改变后，旧脚本不可生成新视频。确认稿、声音或商品镜头改变后，旧交接失效，素材库文件保留。
- 第四步允许主动选择无旁白模式，此时字幕使用镜头计划时间；有旁白时使用实际识别时间轴。镜头切换按计划比例覆盖完整音频，不声称逐词驱动画面。
- 有旁白时保留识别原文与真实时间轴；等长繁简、同音或极少错字可以按确认稿留痕校对，并提示回听，不能据此认定实际发音正确。漏字、明显错句、数字或否定表述变化会明确报错，不用字数估算冒充真实字幕轴。
- 未完成商品视频时，自动流程提示先完成第四步，不错误要求数字人形象。选用视频后继续复用后续流程。
- 采集、识图、脚本和视频任务使用现有任务中心、取消、历史和输入版本检查；迟到结果不会自动覆盖已变更内容。

## 当前实现范围

读取公开商品网页的 JSON-LD、元信息、明确商品 JSON 和已识别的抖音商品 DOM；动态页面由隐藏、静音的独立 Electron 会话读取。登录、验证或平台限制会返回明确失败，允许上传原图补充资料；不保证任意平台或任意链接稳定读取。

图像观察优先使用配置的视觉模型；本地 Ollama 文本模型只有服务明确声明视觉能力才可复用。未配置视觉能力时明确标记未识图，文案只依据已核对文字。

当前视频保留原商品图片，以完整原图、模糊衬底、轻微平移和淡入淡出制作展示视频。画面说明保留为分镜记录，不代表已执行动态实拍或生成商品使用动作。生成结果保留 `qualityAccepted:false`，文件有效不等于内容质量已被用户接受。

## 本机验证工具

`scripts/inspect-product-page.cjs` 使用项目 Electron 对公开商品页面进行隐藏采集，并将证据保存在被 Git 忽略的 evidence 目录。

`scripts/verify-product-promo.cjs` 连接本机验证会话 CDP 9375；需调用方安装 `playwright-core` 或以 `PLAYWRIGHT_MODULE` 指定模块位置。其 collect 模式会创建独立验证任务，其他模式操作当前任务。真实桌面运行不需要 Playwright。

模型、私有音色、用户草稿、生成媒体和本机证据不随源码提交。

## 2026-11-20 本机验证结果

- 在日常源码入口创建独立商品测试任务，通过页面完成商品脚本生成、第二步编辑确认、第三步 C 音色配音、第四步视频合成与播放、第五步接收、第六步封面编辑及第七步发布包导出。
- 配音实际为 16.451338 秒；成片为 1080×1920、25fps、16.48 秒，4 个商品原图镜头与 7 条字幕。成片完整解码及页面播放至结束通过，后续剪辑复用第三步音频，没有重复配音。
- 商品第一版模型稿经人工在第二步核对删改，最终稿 97 字；不能用此回执宣称自动生成文案已达到商业内容质量要求。字幕存在按确认稿校对的记录，仍需回听检查发音。
- 独立隐藏采集曾取得本次真实商品的 5 张主图及 9 张详情图，但日常主应用本次访问返回平台风控页面。后续测试使用此前成功采集的真实资料快照和 3 张原图，经应用正常导入继续；不把它记为主应用实时采集成功或任意链接稳定可用。
- 第六步实际编辑封面，改用商品原图和短标题，避免截取字幕成片导致封面带字幕。第七步导出包含真实视频、1080×1920 JPG 封面与发布信息 JSON 的本地素材包，未上传或公开发布。
- 商品视频页面与发布页面在 1400×1000、1100×760 两种尺寸下未发现横向溢出；长内容保留纵向滚动。该检查不代表全应用所有页面视觉验收完成。
- 本批全套回归 1115 项通过、0 失败、0 跳过；之后补充“生成后切换语言不能选用旧成片”的保护，该定向契约测试 20 项通过。最新界面构建成功，仍有现存的大包体积警告。
- 实际本地入口已重开加载本批前后端；与修改前备份比较，旧草稿、素材记录、声音、形象和模型设置保持一致。测试任务和真实产物保留在日常工作区。

实际证据保存在本机被 Git 忽略的 `evidence/validation/product-promo-20261120`，包括采集成功与受限页面、模型请求、字幕原始识别、完整播放、两尺寸页面、导出和数据保留回执。生成视频属于原图展示，尚未通过用户内容质量验收，不能认定已经完成高质量动态商品广告或整个项目的最终验收。
