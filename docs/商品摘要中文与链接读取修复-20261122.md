# 商品摘要中文与商品链接读取修复（2026-11-22）

本批针对两个实际问题：第一步商品摘要漏接历史镜头中文译稿；同机普通浏览器能打开的商品链接在软件内采集失败。

商品镜头新增独立翻译入口，复用既有服务端保护、取消、原子保存和失败凭据。商品镜头以脚本来源及位置生成独立标识，并逐字段核对，不能串用故事镜头译稿；原脚本、配音与媒体选择不会因查看译稿修改。第一步摘要显示有效中文译稿，第四步旧编辑入口须显式采用中文设计才修改字段。新脚本仍沿用既有中文生成约束。

后台商品浏览器保留实际Chromium平台版本，去掉应用专属UA标记；普通APP价格提示不直接当安全验证，有明确验证/环境安全风险仍停止。失败记录保存有限公开正文、命中提示、图数量，区分浏览器加载失败与已观察到的平台提示，不记录Cookie或账号。不能据此承诺所有商品/平台永久可匿名访问。

重复读取已有脚本先呈现新资料供核对，用户可保留原脚本，或主动采用新资料重新制作；同ID状态刷新保留候选，换任务或链接即作废。

实际软件验收：用户商品3854345420239143257读取成功，真实商品标题和14张图片；第一步三镜中文转换成功，原三镜逐字段保持。重复读取后仍为三镜，资料核对按钮实际可用。1400×1000及1100×760检查摘要可读，页面无横向溢出，底部下一步可见。原任务测试曾触发旧版读取逻辑清空脚本，已经真实保存接口恢复，并补上上述保护。

测试记录位于本机evidence/validation/product-source-localization-20261122，不入库。首次全量因原FFmpeg/FFprobe路径失效出现1201通过/11失败/25跳过；本机现有FFmpeg6.1.1版本与drawtext等滤镜核对后，修正环境的全量1241通过/0失败/0跳过。最终中文/页面/组件关联35项、商品服务/采集/镜头接口43项通过；构建通过，仍有既有大chunk提示。媒体路径已通过软件设置保存改为现有D盘工具，checkMedia实际通过，模型设置及密钥保持。

本批不包含新广告视频生成或整体视频质量验收；不将界面译稿、采集成功或测试通过当作广告内容质量通过。
