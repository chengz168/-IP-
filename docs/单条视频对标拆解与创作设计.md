# 单条视频对标拆解与创作

2026-11-17。用户要求在学习对标中加入分享链接视频的脚本、钩子、段落结构分析，并接入软件内创作。固定真实参考为 `https://v.douyin.com/ws7-_Lce-t8/`；视频具体内容以实际采集证据为准，分享标题不能代替正文。

## 用户流程

学习对标增加“视频拆解”页签。填写分享文本或选择本地音视频，点击解析。选择“文案脚本”或“同时观察画面”；不配置视觉也可做文案拆解。显示来源、原始识别文字和逐句时间轴、开头钩子及原文依据、按顺序的段落功能、结尾表达、可复用结构及不确定项。画面单独显示实际采样范围，不假称完整剪辑理解。

解析结果不直接改稿。用户可以“使用原始脚本”进入第二步；或填写自己的主题/素材事实，按结构生成创作稿，编辑核对后“使用创作稿”进入第二步，再沿用现有确认、配音、口播或非口播分镜、剪辑、封面和导出。非口播与口播由第四步现有模式选择，不能把原参考视频当作自己生成的成片。

## 接口与持久化契约

- `analyzeReferenceVideo({id,assetId?,includeVisual:false|true})`：URL从已保存draft.sourceUrl获取。Runtime类型reference-analysis。仅创建报告run.output，不自动覆盖draft。
- output：`{version:1,source:{url,title,assetId,sha256,duration,basis},transcript:{text,segments:[{start,end,text}]},analysis:{summary,hook:{kind,quote,explanation,start,end},sections:[{label,purpose,quote,start,end}],ending:{quote,explanation,start,end},reusableStructure:[string],uncertainties:[string]},visual:{status,observations:[{time,description}],limitation},inputSignature,qualityAccepted:false,stale:false}`。所有分析quote必须对应原文连续摘录，时间由原始segments定位，不信任模型自编时间。无有效时间轴时不伪造秒数，start/end为null。
- `createReferenceScript({id,runId,brief})`：Runtime类型reference-script；原analysis成功且source未变化/原稿签名一致才允许。用户主题和事实作为正文依据，结构仅供写法参考。返回`{text,sourceRunId,inputSignature,brief,qualityAccepted:false,stale:false}`；报告和创作均保留实际模型和提示词到run.output.evidence，不在前端暴露密钥。
- `useReferenceScript({id,runId,kind:'transcript'|'created',text?})`：只允许当前任务成功run。created用reference-script，transcript用reference-analysis。允许用户编辑text，长度20..20000；校验输入签名/来源文件哈希及工作流锁，原子写sourceText，清rewrite/finalText并撤确认，step=1，留draft.referenceSelection provenance；下游通过既有失效规则撤引用，原素材保留。不能自动确认。
- 报告从state.runs恢复，无新顶层数据表。选用后仍能查看历史报告；输入已变化时标明失效，拒绝旧稿覆盖。并发/重复/停止/失败不改旧稿；锁定使用中的媒体，拒绝删除。
