# 长参考视频与分离音轨修复

当分享页对应约38分钟访谈时，旧的30分钟硬编码限制会拒绝采集。部分网页还使用独立视频流和音频流，旧流程在优先画面模式下可能将先取得的视频流判为无声视频，遗漏真实访谈音轨。

现在链接元数据、浏览器媒体和参考分析入口统一接受60分钟以内的媒体。本地yt-dlp工作进程同步支持该边界。无效时长与超限时长分别报告；输入文件仍有原有200MB限制，ASR执行时限仍为30分钟，不能据此承诺任何60分钟来源都能成功。

参考分析采集网页时，遇到分离资源会短暂等待音画两路。发现独立音轨后，使用同次页面采集的资源进行真实流探测，时长差超过1秒拒绝配对；FFmpeg显式选择视频和音轨，以流复制合并，不重新编码。合并后再次检查流和时长，再交给现有本地识别。发现音轨但合并失败时不会接受无声来源；临时文件在退出和取消后清理。只具备静态采样的画面分析仍不代表逐帧完整理解。

## 复用决定

继续采用已有FFmpeg、faster-whisper和yt-dlp；不增加下载器或模型。2026-11-28通过专用Chrome搜索GitHub的`ffmpeg merge audio video`，并读取FFmpeg官方仓库与Streamcopy文档。搜索中的Telegram机器人和Canvas录屏工具不适合当前Electron静默采集路径。FFmpeg官方仓库标注主要为LGPL、可选组件为GPL；本次调用已有本机二进制，没有引入第三方源码或额外分发二进制。

本轮检索、真实来源和媒体测试证据保存在本机忽略目录，未提交参考视频和工作区。行为验证覆盖38分钟和60分钟边界、超限拒绝、真实FFmpeg分离音画合流、时长不符拒绝、延迟音轨等待、静默窗口与取消。完整模型拆解和创作成片另作实际任务验收。

## 单项资产提示词范围

实际试制发现，独立电脑资产同时收到整片分镜说明和镜头阶段预设，导致模型把人物、额外电脑和拼贴一起画入参考图。现在独立资产图只表达当前资产的名称、外观、图片提示、视觉风格和本次修订要求；整片动作表继续用于分镜和镜头图，不参与单项资产构图。原全局要求仍保留在生成任务凭据中。角色、场景、道具分别具有明确生成范围，历史无资产目标的图片和镜头图保持原编译路径。编译版本升级为6，不修改历史记录。

该修复复用项目现有生成器与提示词编译器，没有新依赖。提示词隔离测试不等于内容质量通过，实际图片仍逐张审看；早期生成错误的台式机、键盘结构不佳和多人物拼贴参考保留为拒绝候选，不用于成片。
