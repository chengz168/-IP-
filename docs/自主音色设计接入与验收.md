# 自主音色设计接入与验收

## 问题与目标

用户拒绝当前配音的真人感及人物匹配度，并希望能自主合成声音。现有 IndexTTS 接口依赖参考音频；不把它描述成从零音色设计。新增独立 Qwen3-TTS VoiceDesign 候选，使用文字描述与新正文产生声音，不输入原人物音轨。最终仍需集成原声音资源选择、试听和后续口型链，不能只交付一个外部实验。

## 本阶段资源与授权

官方模型 `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign` 固定 revision `5ecdb67327fd37bb2e042aab12ff7391903235d3`。11 项文件合计 4,520,159,099 字节；包含完整 speech_tokenizer，与独立 tokenizer 的 blob 一致，不重复下载。清单与官方元数据镜像记录在 `evidence/research/generation-chain-20261115/voice-design-plan/plan.json`。公开模型卡标注 Apache-2.0，不把模型许可解释成所有生成内容的无限制权利。

安装目标 `D:/AI-Runtimes/super-ip/qwen3-tts-voice-design`。用户于本轮明确回复“允许下载并继续真实试听验证”，授权清单内11项模型及独立Python依赖。已开始固定revision下载和完整哈希校验；独立环境使用Python3.11.16，复用已再次核验SHA256的Torch2.8.0+cu128安装包。已有 IndexTTS、MuseTalk、ComfyUI 环境保持独立。官方 Python API 文本已按固定源码 commit 保存、blob 核验。

## 实施阶段

并行现有资源验证：不等待新模型批准，先使用已经安装并获准验证的 H3 联合音画模型，基于示例二人物首帧及自行编写的公开结构提示词，自主生成一句新女声，不提供原音轨或参考视频。此试验原生画面为 352×608/24fps/192 帧，仅用于取得声音候选，不能当作最终 1080p 视频。模型与 LoRA 沿用本机现有文件；独立脚本提交，未冒认产品按钮。提交图、图 SHA、clientId 与真实 promptId 保存后只查询原任务；质量必须实际检查及试听。

1. 固定模型文件、源码/发行包版本及校验清单，完成只读检查和独立运行器。缺模型时明确非零失败，无 WAV、无成功回执、无隐式联网下载。
2. 获准后准备独立 Python 环境及权重，逐项核验。第一次实际生成只做短句，保存描述、正文、种子、实际模型信息、原始浮点输出及音频统计。不声称种子能保证跨设备/版本逐位确定。
3. 使用同一短稿制作不同音色描述候选，完整解码、削波/有限采样及正文检查；用户试听自然度、年龄感、语气和人物匹配。未试听接受前不重做完整视频。
4. 选定音色后保存为有生成来源的声音资源。优先核验既有 IndexTTS 能否复用这个自主声音，不能声称单靠同一描述就能跨文案稳定保持音色；如需额外 Base 权重，另列实际清单。
5. 通过新正文生成新配音，并用实际新音频重新驱动口型；保持原 UI 资源、试听、任务、取消与持久化交互。接入后完成针对性回归、实际按钮、刷新绑定与视窗布局，再打包验证。

## 独立运行器约束

- 只接受 text、instruct、language、seed、max_new_tokens；本阶段中文短句，正文最多 200 字、音色描述最多 1000 字。不接受真人音频路径或远程模型地址。
- 运行输出创建于显式指定的新目录，不覆盖历史候选与原参考素材；记录 failed/cancelled/technical-complete，技术完成与质量接受分开。
- 模型文件逐项核对大小与 SHA256，普通 Git 文件核对 blob SHA1；运行前后检查不变。禁止通过“只检查文件存在”当作完整性通过。
- 运行时强制离线，模型使用绝对本地目录和 local_files_only；不安装或加载远程自定义代码。
- 官方 Qwen API 真正返回一条有限、非静音浮点音轨后才写新 WAV；保存原始浮点音轨与量化试听音轨的不同身份和削波统计，不用后期增益冒称改善真人感。
- 成功回执包含来源版本、文件哈希、描述与正文、种子、采样率、样本数及实际耗时；naturalnessAccepted、characterMatchAccepted、qualityAccepted 均保持 false，直到获得具体试听证据。
- 本阶段未接生产生成按钮；缺环境验收不等于模型推理验收。

## 恢复与风险

保存 job.json 后执行；失败保留现场，不自动重交。候选目录已存在时拒绝覆盖；恢复先检查实际进程和回执。CUDA 显存不足或依赖冲突需保留真实异常，不降级为系统配音冒充成功。新增依赖必须使用独立目录，不能升级已有 IndexTTS/MuseTalk 的 transformers。生成描述不包含真人姓名或要求模仿原人物声线；声音质量不能仅靠 ASR 一致或模型介绍判定。

## 整体完成边界

此阶段只是补齐声音设计能力。完整 208 秒、同等质量、所有页面/模板/按钮/交互与样式一比一仍按原目标验收，整体 goal active。

## 产品入口具体实现

在声音管理既有声音训练卡片标题区增加“设计新音色”入口，打开独立弹窗；原默认页面仍沿已有样式。弹窗提供名称、音色文字描述和200字以内试听正文，不要求参考音频。预设只填入文字，不冒称原厂内部提示词。实际生成期间锁定输入，显示真实阶段且可停止；失败在弹窗显示中文原因。生成结果先保留为音频候选，用户完整试听后再明确点击保存到声音库；记录模型revision、实际输出SHA和描述。保存候选与复用生成分开，不能直接当作已被用户接受的最终音色。

模型设置增加独立环境路径及真实离线检查。通过现有Runtime保留任务、输入快照、进程和输出收据。刷新后可从本任务最新设计记录恢复候选，不重复提交。取消等待子进程树退出；未完成或失败结果不能登记为声音。任何原稿、原声音、原厂素材均不覆盖。与其他本地生成有冲突时明确等待，不隐式重试。

本轮原MuseTalk任务76c8ab2c已成功：269帧、1080×1920、30fps、8.966667秒，新声音8.939683秒；完整解码、音轨相关0.99998261063071、不静音原生播放到结束及刷新绑定通过。身体背景沿用示例二源片；自然度、人物匹配、连续口型和完整208秒仍未验收。新Qwen下载及安装进行中，后文待批准语句为保留的历史状态。
