# 本地口型立即停止验收

日期：2026-11-16。范围：用户报告 MuseTalk 本地生成点击停止后仍运行，以及停止反馈恢复过早。

## 已查证原因

`server/local-musetalk.cjs` 的 `runWorker` 原默认 `cancelGrace=20000`；取消先写 `cancel.request`，工作器未到检查点时等待最多 20 秒后才调用 Windows `taskkill /T /F`。`Runtime.cancel()` 只发送信号，前端收到回复就把停止状态清除，实际工作器可能仍未退出。

## 修改及验收契约

1. 本地工作器取消默认立即启动本次 PID 的进程树终止，保留协作取消标记；不终止其他模型进程。
2. 确认子进程关闭后才结束本地任务，生成停止回执；取消不登记或绑定半成品，模型独占锁随退出释放。
3. 运行记录保存取消请求时间，取消后的迟到进度不得继续推进；前端立即显示并保持“正在停止…”，直到原任务终态。
4. 云端任务沿用现有“停止本地查询，远程结果待确认”语义，不冒称远程已取消。
5. 验证真实 OS 子进程树取消、真实 MuseTalk 产品按钮停止、停止后可重试、无新视频资产、原任务配置保留及相关回归。

视频输入自动适配由独立子任务处理，验收见 `docs/形象视频自动适配验收.md`；本批生成短片仅用于过程验证，不据此声称画面或口型质量通过。

## 实际验收结果

- 用户原任务 `4f8f5086-cb37-4848-8b88-875b35ceff01` 从取消标记写入到结束约 12.39 秒，与原协作取消等待机制一致。
- `node --test tests/musetalk-stop.test.cjs tests/core.test.cjs`：19 项通过，退出码 0。故意不读取取消标记的真实 Node 工作器及其子进程在约 291 毫秒内退出；取消持久化、重复请求、迟到进度与写盘失败信号均有断言。
- 独立产品工作区使用用户本人原片和 2 秒驱动，真实 MuseTalk 任务 `65193956-166f-45d4-a97b-a6807ea48c1f` 在预处理阶段点击真实“停止处理”，约 431.7 毫秒到 cancelled，停止回执记录工作器退出约 276 毫秒。Windows CIM 核实工作器 PID 6872 已不存在，未绑定视频，生成按钮恢复可用。
- 停止后通过产品按钮重新生成，任务 `1a58781c-3fe7-4d5c-8e45-09740fbea91b` 成功，完成 15 次推理、60 帧。2 秒输出完整解码与产品内原速、不静音播放到 ended 通过。
- 后续任务 `16e1fe3a-864c-44a9-aaee-5215ab4fa0dd` 原计划在推理阶段停止，恢复检查时已成功结束，未点击停止。该轮仅算再次生成成功，**不计入推理中取消验收**；没有为补结果反复提交。
- 全量 `npm test`：753 项，750 通过、0 失败、3 跳过，退出码 0。跳过为依赖条件未满足的真实 H3 封装及两项 yt-dlp 测试；临时在测试进程 PATH 中加入现有 FFmpeg 目录。`npm run build` 退出码 0，有现有的大包提示。
- 日常窗口确认无活动任务、无资源弹窗，保存当前草稿后重启到本轮主进程（PID 8316）。新提示可见，完整当前草稿、设置、素材、形象及声音与重启前一致；保留约 217 秒配音和当前镜头配置，没有替换为 2 秒测试任务。隔离窗口已关闭。

证据根目录：`evidence/validation/musetalk-stop-20261116/`，包括 `reported-stop-baseline.json`、`product-stop-result.json`、`real-generation-result.json`、`inference-stop-result.json`、`daily-update-result.json` 与 `full-tests.log`。证据、用户素材、测试工作区和模型不进入 Git。

验收边界：已验证真实模型预处理期间取消及停止后重试；真实推理中取消与持续“正在停止…”反馈仍缺该阶段的产品观察，不声称全阶段停止均已实测，也不据此认定口型自然度通过。
