这是本项目定义和实现的适配协议，不是轻语IP原厂私有接口。本机Ollama、系统朗读和已有Whisper已有真实专项，不能据此视为克隆、口型和平台发布整链验收通过。

2026-11-14另取得原厂客户端IPC契约，见 `evidence/reference/service-audit/generation-contracts.json`。原厂本地声音是voiceCloneModule/voiceV2Module的soundClone调用，接受参考音频与参考文本，新版另含情绪字段；本地数字人为humanModule/hdModule的generateDigitalHuman，接受audio_file/video_file及版本等。云端调用仅取得IPC名称与客户端入参，尚无完整HTTP协议。这些证据不改变下方本项目桥接协议，也不表示已成功连接原厂模型。安装目录python-modules本次为空；声音和口型生成效果仍未通过。

## 兼容文本、TTS和ASR

设置的Base URL应包含服务要求的版本前缀，例如服务文档指定的 `/v1`。模型名和音色ID由实际服务提供，不预填不存在的模型。

- 模型列表：`GET {baseUrl}/models`，读取 `data[].id`。
- 文本：`POST {baseUrl}/chat/completions`，JSON包含model、messages、stream=false，读取 `choices[0].message.content`。
- TTS：`POST {baseUrl}/audio/speech`，包含model、input、voice、speed、response_format=mp3，返回可被FFprobe解析的音频本体。
- ASR：`POST {baseUrl}/audio/transcriptions`，multipart包含model、file、response_format=verbose_json，返回text和可选segments（start、end、text）。没有时间轴时不能自动当作字幕。

请求使用配置的 `Authorization: Bearer ...`。桌面密钥通过系统safeStorage加密，业务JSON不保存密钥。浏览器开发服务的密钥仅保存在内存。

## 链接文案提取桥

完整接口地址由用户提供。POST JSON `{ "url": "分享链接或文本" }`，同步返回 `{ "text": "真实提取的正文" }`。

## 本地Whisper识别

设置 `asrProtocol=local-whisper`，`asrPythonPath` 为已安装faster-whisper的Python解释器完整路径，`asrModelPath` 为含model.bin、config.json、tokenizer.json的已有模型目录，`asrLanguage` 可选zh/auto/en。旧配置默认compatible，不自动切换。

本地模式使用CPU/int8与离线目录加载，不调用配置的云端地址或读取密钥。媒体先检查真实音轨并临时转换16kHz单声道WAV，进程退出后清理本次目录。返回非空text及有序、合法、未超出媒体时长的segments；无语音/无音轨/缺模型明确失败。提供实际模型加载检查、识别进度与主动停止。已在当前本机small模型验证，不声明任意环境无需安装依赖即可运行。

Python worker作为独立文件打包到 `resources/app.asar.unpacked/server/local-asr.py`，不会把Python环境或模型捆绑到包中；本机验证使用既有环境，无安装/下载动作。识别期间输入变更不会回填旧结果；成功结果保留在执行记录，当前UI支持查看JSON。

## 声音克隆桥

POST multipart：`name`为声音名称，`file`为音频样本；视频样本先在本地抽取音轨。同步返回 `{ "voiceId": "可用于TTS的真实音色ID" }`。当前未实现异步训练查询，异步训练服务需要增加适配。

## 数字人口型桥

POST multipart：`video`为形象视频，`audio`为驱动音频，`model`为v1/v2，`shots`为JSON数组。服务需要自行将本地的模型选项映射至真实推理配置。

同步返回 `{ "status": "succeeded", "videoUrl": "结果视频下载地址" }`。

异步返回 `{ "jobId": "远程ID", "status": "queued", "statusUrl": "完整查询地址" }`。查询使用GET，返回status为queued/running/succeeded/failed、可选progress、成功videoUrl或失败error。远程ID应立即持久化；查询异常、超时、停止本地查询时不得视为已取消远程任务，也不得自动重提。

当前任务中心显示远程ID和未知状态；尚未实现跨重启的主动查询恢复入口。该项必须在实际服务接入后继续完成。

## IP大脑样本文案与主页采集桥

本地样本文案已接入当前文本模型，保存原文、来源、分析、连续摘录依据与学习版本，支持5个选题、3条候选及选用到第二步。浅度和深度按不同提示分析文本；未实现原厂教程所述的账号视频画面学习，不等同原厂内部模型。

可选 `provider.brainUrl` 是本项目定义的同步采集适配契约，不是原厂API。POST JSON `{ "url": "完整账号主页链接", "mode": "shallow或deep" }`。同步返回 `{ "name": "账号名称", "samples": [{ "title": "原文标题", "text": "真实文案", "url": "原文地址" }] }`。samples需1至100条，合并正文80至30000字；标题和正文不能为空，url可省略。认证沿用当前服务密钥，采集结果仍交给已配置的文本模型分析。

只有主页网址不能标记为已学习；未配置或无有效样本时明确失败。若返回 `{ "jobId": "远程任务ID" }`，立即保留ID并标记unknown，因为当前没有已验证的结果查询协议；同任务或同档案阻止重交，重启后仍保留该保护。当前未接入真实主页采集服务；桥协议的模拟契约测试不能替代实际服务验收。
