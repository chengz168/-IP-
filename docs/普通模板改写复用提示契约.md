# 普通模板改写复用提示契约

真实972字改写相对954字候选大段逐字沿用，但普通模板的旧规则没有复用警告。本次只把已有的“连续8字片段覆盖超过75%”字面检查扩展到普通模板，不改模型输出、不重试模型、不自动确认或回写旧运行记录。

## 最小规则

- 普通模板比较整段输出与整段原文；去除空白与标点后的输出至少30字时，统计位于任一原文连续8字片段中的输出位置。覆盖比例严格大于75%时增加一条重组复核警告。
- 原厂`reference-visible`模板继续按现有规则只比较首段之后的正文；首段30字及保留原文开头的要求仍仅适用于该模板，不扩大到普通模板。
- 复用警告不构成拒绝，也不意味着抄袭、事实错误或语义质量差；合理的事实、数字、单位和专名允许沿用。`accepted`仍为false，等待人工验收。完全相同输出的既有拒绝规则继续生效。

## 边界与验收

少于30字的文本不触发比例警告，空文本与短原文不会除零或产生复用NaN。专名、固定术语、法定表述密集的文案可能高复用，提示需明确保留人工判断，不将高复用当作错误事实。跨句语义、论证结构、自然程度及财经事实正确性不在本规则可证明范围内。

新增短中文夹具测试普通高复用仅警告、低复用不误拒、空短文本、模板首段边界及完全相同输出仍拒绝。真实954/972文本仅在独立本地证据目录回算并记录输入哈希与新旧quality差异，不提交财经全文，不修改旧run。主代理随后统一全量测试与构建，本子任务只运行定向测试。
