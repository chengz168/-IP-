# 专用口型输入与离线检查

日期：2026-11-15。沿用完整复刻目标，此批完成候选运行前的真实输入准备和只读检查，不表示专用口型已经可生成。

## 后续已授权的真实验证

用户随后明确批准11项4,482,904,130字节模型及独立推理环境准备，用同一示例二夜间继续8秒真实对照。固定源码已下载并通过48项Git blob核验；Torch系列官方安装包已校验并安装。其余模型与依赖的完成状态，以独立运行目录中的model-receipt.json、dependency-receipt.json和实际readiness报告为准，下方“未下载”描述保留为此前阶段事实。

新增worker.py和model_backend.py负责单次独立验证。成功必须来自实际模型调用，保留原视频前240帧、原尺寸及原帧率，逐帧记录人脸框、框内修改像素数和编码前框外像素是否一致；不调用上游shell拼接、反向循环或吞异常入口。中文PNG路径通过字节解码读写。无人脸、多个人脸、特征数不符、融合失败、输入SHA变化、媒体处理失败或取消都停止，不写技术成功。

每次输出目录独占创建；result.json记录running/failed/cancelled/technical-complete，events.jsonl保留模型尝试和已生成帧数。强制进程结束可能留下running和部分帧，不能仅凭文件存在绑定视频；本候选不提供自动恢复或重交。cancel.request是协作取消入口；媒体子进程会终止，GPU算子需要返回到检查点才响应。

检查通过后设置HF离线变量，并通过Python审计钩子拒绝套接字连接、DNS和sendto；它不是系统级网络沙箱。未知模型文件的实际SHA只作本地记录，不冒称独立官方校验。第一版仅支持整数帧率和恰好覆盖完整帧的1至8秒驱动，其他情况明确拒绝，不隐式补帧或变速。

生成后封装已核对的原驱动音轨，重新核对输入，检查实际尺寸、帧率、解码帧数、音轨覆盖及完整解码。verify-musetalk-sample.cjs只接受真实technical-complete，制作原示例/原版成片/新候选三路对照、9时刻采样、音轨一致性与边缘背景测量。音轨复用不计新配音，原视频身体与背景复用会明确标注；模型仅生成并融合人脸局部，不冒称整帧重新生成。

当前仅9项工作器契约/真实FFmpeg检查和4项真实本机HTTP下载器检查通过；实际模型与效果验收另行记录。该候选未接产品生成按钮，生产默认H3路径和打包清单没有修改。

## 依据及范围

已核实原版客户端传入形象视频和驱动音频；服务内部模型与提示词未知。原示例二为1080×1920、30fps、593帧，原成片为同尺寸30fps、6240帧、208秒。本机Comfy虽暴露InfiniteTalk和若干云API节点，所查模型目录没有其专用权重；节点存在不能当成服务可用。既有两份H3样片不满足同等质量。

本批不下载MuseTalk模型、不安装依赖、不加载候选模型，不改默认H3生产图。对候选先做：固定模型清单只读检查、固定源码和依赖版本检查、原尺寸/原帧率输入计划、真实音轨规范化及原厂/本地背景保持的局部测量。

## 输入契约

- 第一阶段仅1至8秒单人物验证。输入必须是现有绝对文件路径，包含视频流和独立有效音轨；原尺寸及恒定帧率明确，带旋转的视频暂拒绝以免隐式改变几何。
- 保存原视频和原驱动的完整SHA、采样率/声道、尺寸、帧率、原帧数与计划帧数。音轨规范为16kHz单声道PCM，并记录实际采样数。保留原驱动作为将来封装来源。
- 原形象视频始终只读引用，计划使用从0开始的连续源帧，不重绘、不循环、不伸缩。原视频不足计划帧时明确拒绝；长片循环/多镜头是后续独立契约，不在短验证中暗中启用。
- 新目录原子创建；失败保留明确失败回执和已完成的临时音轨，不能留下成功manifest。已有目录不覆盖，不把准备音轨/输入清单当成推理产物。
- 本批清单可供后续模型工作器直接读取；尚未接产品生成按钮，不能声称口型生成完成。

## 就绪检查

模型11项来自既有固定计划。先检查目录、文件类型和完整大小，提供完整SHA模式；缺少已知SHA的文件明确标为仅本地散列已记录，不冒称官方校验。源码要求固定提交收据，48份Python源文件逐项核对官方固定树的Git blob散列；同时拒绝源包内未登记Python文件。源码树另按commit对象指向的真实tree SHA重新获取并核对，不能混用commit和tree标识。

依赖使用固定官方文档版本要求，未解析版本不猜测。只有权重完整、源码一致、依赖版本匹配且解释器位于独立运行目录，才允许设备检查并实际导入通用依赖（包括mmcv.ops二进制扩展）；缺文件时不导入torch或触发S3FD隐式下载。检查只返回事实，不创建运行目录、不联网或安装。本批模块位于独立的integrations/musetalk-local中，不进入当前生产路由或目录包。

## 保持性测量的边界

源示例、原成片和两份本地候选各取前8秒，以30fps和108×192灰度网格对齐，计算同时间左右各20%区域的逐帧差异及整体差异。左右边缘刻意避开当前示例脸部，只用于观察此固定样本背景保持，不称检测出人物，不作为口型、身份、真实感或整片质量评分。低分辨率、缩放和压缩会影响数值，不设置自动质量通过阈值。

验收：必要单测、真实FFmpeg音轨准备、原视频SHA不变、固定输入和30fps/240帧契约、缺模型真实检查与无新增文件证明、实际四路测量。没有生产入口修改，本批不重复整套产品测试或打包。
