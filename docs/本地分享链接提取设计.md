# 本地分享链接提取设计

2026-11-15。当前原软件功能包含粘贴视频分享文本并提取文案，本项目界面已有入口，后端却只能请求外部extractUrl。本批补齐本地实际解析、下载与既有语音识别链，不能把视频简介或分享文本当成视频口播正文。

## 实现范围

- 用独立安装的官方yt-dlp固定版本解析单视频；支持范围以实际试跑结果为准，不承诺所有抖音/快手/小红书链接均可用。不会自动读取浏览器Cookie，也不绕过登录、付费、DRM或平台验证。
- 识别分享文本内唯一HTTP/HTTPS链接，剥离明确的中文句末标点；无链接、多链接、非HTTP协议在创建运行前返回中文错误。保留原始分享文本与解析后的链接。
- 新增独立接入方式local/bridge，历史配置存在extractUrl时保持服务桥路径；本地必须配置真实yt-dlp程序和已有ASR，不自动下载安装模型。
- yt-dlp以参数数组启动，忽略用户全局配置、禁止播放列表、限制文件体积/时长、固定下载隔离目录；每次最多一个实际文件，下载完成后必须FFprobe确认音轨、有效时长和非直播。真实文件复制到素材库后调用现有ASR，成功回执保留源媒体ID、SHA、实际解析版本、原始URL、标题及ASR时间轴。
- 子进程超时/取消停止整个Windows进程树，并等待退出；下载临时目录和失败素材回滚。取消、识别失败或写盘失败不把半成品注册成成功，也不改当前文案。
- 新旧工作流同一extract入口，仍用现有识别快照防止输入变化后迟到结果覆盖。模型设置增加本地接入、解析器路径及只读版本检查，页面间距按既有设置结构，不重做整体视觉。

## 验收

1. 分享文本/多链接/特殊参数、程序缺失、非音视频/无音轨、超限、取消、落盘失败和输入变化回归。
2. 官方版本下载前记录发布信息，下载后SHA核验和实际--version；使用真实本机HTTP媒体及本机Whisper完成按钮→文件下载→新识别→文案→刷新，全过程记录明确为本机协议媒体，不冒称公网平台通过。
3. 对已持有的实际平台链接进行有限只读解析尝试；平台失败完整留证，不用本地媒体成功替代平台能力。没有用户会话时不自动读浏览器Cookie。
4. 新旧入口、设置页两尺寸四字号布局，必要全套测试、构建、目录包一致；原工作区和此前验收文件SHA不变。

本批不包含账号主页批量学习、平台登录或发布，也不提升声音/视频质量验收状态。完整复刻目标保持active。
