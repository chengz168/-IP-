# 本人画面与背景优化（2026-11-17）

## 当前问题与本批范围

现有 MuseTalk 输出保留源视频人脸以外区域，因此本人衣着和房间背景不会自动变化。用户本次选择简洁商务演播室。本批新增可选的“优化形象”：对源视频生成独立副本及形象，随后由现有第三步口型流程消费这个副本；不覆盖原片，不改变身份、衣着、动作，不宣称表情重建。

## 流程与契约

单形象页 → 优化形象 → 选择自然调色或原画、保留背景或商务演播室 → 生成副本 → 预览/选用 → 原有驱动音频和口型生成 → 剪辑、字幕、封面、导出。

接口 `avatarOptimize({id?, avatarId, look:'natural'|'original', background:'original'|'business-studio'})` 返回 `{avatar,asset}`。运行类型 `avatar-optimize`，支持原停止入口。形象副本不会修改原草稿，前端在任务与形象未变化时选用并保存；旧成片依赖由现有 Store 逻辑撤销。优化后仍须重新生成口型视频。

画面处理采用基于原片亮部估计的固定白平衡、轻度降噪与锐化，参数写入素材证据。背景使用真实人像分割蒙版与程序绘制的商务演播室合成；不得以矩形裁切、色键或 CSS 背景冒充任意场景抠像。分割模型未配置时明确拒绝商务背景任务。模型和依赖均不随任务自动下载。

## 数据、兼容与故障

新增 provider 配置 `portraitPython` 和 `portraitModel`，允许已有本机 Python / ONNX 权重路径。既有草稿、形象和远程恢复逻辑不变；新形象有新 ID / 视频资产，现有 avatarContext 文件戳与多镜头资源快照继续保护依赖。

输出登记前核对输入文件哈希、来源形象引用、时长、帧数、方向/尺寸、音轨和完整解码。保存实际引擎、模型哈希、来源哈希、参数和 `qualityAccepted:false`。取消须终止本次进程树并等待退出；失败或取消不新增成功资源、不切换草稿；保存失败回滚新增资源。原片及已有217秒成片保留。

## 验收清单

- 产品入口、参数切换、取消、失败提示、成功选用、刷新持久化；两个窗口尺寸独立截图检查。
- 原背景且原画的无效任务拒绝；模型缺失、文件变化、失败回滚、停止及迟到结果保护。
- 使用“我本人”同一短源和已有音频，通过真实产品按钮生成并播放；记录原片哈希与产物帧数、时长、音轨。
- 前后实际帧分别检查肤色、曝光、头发/眼镜/肩膀边缘、漏抠背景、时间闪烁；口型由现有产品继续生成后另行核对。
- 格式通过不代表内容质量通过，样片主观质量和用户认可单独记录。发现失真不自动接受或整段217秒重算。
