# 声音样本裁剪实现与验收

2026-11-14。前批video-viewport已完成列举范围验收，属于实际进展，整体复刻目标仍active。本批补教程中明确展示、当前代码缺失的声音样本裁剪。

## 依据和边界

本地voice教程约86至93秒的解码画面00044、00046，实际显示“音频预览与裁剪”、真实波形、可拖动选区、试听选区与所选时长；提示建议5至30秒，超过30秒默认前30秒。机器转录仅辅助定位，不当作声音模型效果保证。原厂当前管理页已有空上传状态截图，但本批尚未取得8.4.0上传后同状态参照，不宣称版本间像素一致。

当前ResourceStudio上传/直接录音后整段送训练，保存样本还绕过已有实际音轨校验。VoiceUpload已有音轨校验，但同样缺选区。本批用同一组件提供两个入口的波形、双端点拖动/键盘及数值调整、限定选区试听。波形由现有FFmpeg实际音轨绘制，不使用随机占位波形；选择范围变化停止试听，换源/换任务/离页清理播放并拒绝迟到结果。

## 实现设计

后端增加prepareVoiceSample和trimVoiceSample，使用现有50MB输入边界和实际音轨探测。prepare保存源SHA256及实际时长，返回真实波形PNG；临时图片处理后清理。trim按已准备的SHA及有限数值验证范围，真实解码为24kHz单声道PCM WAV，核对输出时长并保存来源/起止时间，原素材不覆盖。失败或取消不留半成品资产。

前端默认选择0至min(30,实际时长)，5至30秒只作为教程建议，不伪装成所有克隆模型的通用硬限制。先试听/调节，再点击原有保存或训练：执行真实裁剪，保存或训练实际使用裁后素材。同一输入和选区复用本次已裁结果，避免重复生成；未经准备、非法范围或处理中的按钮禁用并显示原因。缺少克隆服务仍如实失败，不把裁剪视为克隆成功。

模块：server/voice-samples.cjs、server/service.cjs；共用VoiceSampleEditor.vue及样式；ResourceStudio.vue与VoiceUpload.vue接入。保持既有声音/形象入口，录音本身本批只复用既有实现，不声称真人麦克风质量已验收。

## 验收与恢复

先留修改前缺失证据。后端验证真实三段不同频率样本裁剪后时长、声道、采样率及片段内容，视频音轨、无音轨、越界/非数值/短区间、SHA变化、取消和写盘失败回滚。桌面真实调整端点、试听停止、换源、保存/刷新、非法范围及缺克隆服务反馈；两尺寸四字号核对波形、时长、错误和可操作控件。已有真实系统朗读仅做选择片段，不新调用模型。

在隔离工作区验收，恢复前核对原工作区完整JSON含updatedAt，不能用旧基线覆盖用户修改。运行必要测试/构建/目录包哈希；不启动此前被拒绝的打包EXE。质量结论限于裁剪与样本准备，不包含真实克隆相似度、情绪、口型和原厂同源效果。

定位纠正：TaskCenter在src/views，VoiceSamples文件为voice-samples.cjs，样本既有测试在speech-panel.test.cjs；先按rg实际文件列表定位，不继续猜测文件名。UI检索range slider keyboard命中键盘导航条目，仅采用有序Tab与可见焦点检查，不生成新设计系统。
