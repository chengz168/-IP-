# H3短片尾帧封装修正

2026-11-15本地配音7.941224秒驱动的新H3任务实际成功，但短片collect使用-c:v copy和-shortest后，视频189帧/7.875秒，音频7.942秒。该封装不能认为画面覆盖完整音轨。原任务ID、模型输出和首次收据保留，不重新提交推理。

短片封装以-frames:v保留ceil(驱动时长×24)帧，不使用-shortest或按时间截流；真实测试发现按-t截流与B帧重排序不能保证精确帧数。流复制原H3视频、使用原驱动编码AAC，保留足够覆盖完整音轨的实际新生成帧。封装后验证帧数恰为ceil(驱动时长×24)、帧率24、视频流覆盖音轨、总时长在原允许范围。超出所需帧的模型输出仅裁掉，不补重复帧或循环。该修正针对固定H3 24fps链路。

先用真实FFmpeg制作192帧视频与7.941224秒音轨，通过真实HTTP获取与collect检查191帧、完整音轨和异常拒绝。再完整测试、构建与目录包核验。已有成功候选保留；独立源码窗口重启加载修正，明确执行只读查询原promptId并重新封装，原子保存新资产和绑定，失败回滚、不触发模型POST。回执记录旧新资产、原任务、生成视频SHA和POST次数。

截图辅助先检查指定独立窗口是否最小化，恢复该PID窗口后重新验证播放器，初次超时保留。连续听审/口型与整品一致性仍未验收。
