# 文案自动选择视频制作方式交付记录

## 用户可见变化

- 新建任务默认自动识别最终文案的制作方式，并在第四步显示当前方式、置信度和依据。
- 用户点击模式页签或“手动调整”即可覆盖；“恢复自动识别”重新按当前确认稿选择。历史草稿第一次迁移会保留原模式为手动，避免覆盖用户选择。
- 对白、场景标记进入剧情分镜；镜头、特写、操作演示进入可沿用第三步旁白的分镜展示；真实关联商品脚本与已确认商品图才进入商品流程。日常单人讲解仍走口播。
- 在第二步确认分镜或商品稿后进入声音步骤；不启动人物口型代替尚未完成的分镜或商品链路。确认文案时旧媒体引用依照原有失效策略处理，素材文件留在素材库。

## 边界

自动识别根据结构标记和明确的镜头、动作信号进行可解释路由，不保证覆盖所有写作风格。置信度低的稿件显示依据与手动入口；没有场景或对白结构的复杂叙述仍需用户检查。实际剧情视频质量不属于本次通过项；各集仍按既有分镜、资产、图片、视频与合成流程制作并人工检查。
