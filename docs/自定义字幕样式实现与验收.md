## 实现设计与影响

1. 共用纯数据参数模块和严格验证。增加edit.subtitleCustom，旧任务未确认自定义前仍按原三预设渲染；调整样式打开时把旧参数按视频尺寸转换，避免只是打开弹窗就改变已有结果。确认后自动失效旧剪辑/发布引用，保留实际素材。
2. 完整四区域和八个基础预设；字体/字号、粗斜下划线、色值及不透明度，描边宽度/颜色、阴影距离/不透明度/颜色，背景色/不透明度，底部距离和字间距。横竖预览使用分辨率基准，换方向按比例换底部距离。
3. 已有系统字体和可选本地字体目录，读取真实字体family。字体缺失明确报错，预览/导出共用同一个字体文件来源；不下载或偷偷替换字体。字体路径留在设置，业务任务只记录字体ID/名称。
4. 预览调用已有本地FFmpeg/libass真渲染PNG，异步去抖、单并发、忽略过期响应；不写入素材库/运行历史，不使已有成片失效。确认前等待有效预览并在后端校验参数，失败弹窗保留。
5. 新ASS支持背景与描边同时存在、独立阴影、透明色、Unicode和控制字符转义；按实际尺寸/倍速/剪气口后的时间轴烧录。临时文件成功失败均清理。大字号/长字幕超画面给出真实错误，不能默默裁字冒充可用。
6. 用原软件现有前端演示图片作为本地参考预览资源；不携带原厂后台、模型、登录或发布逻辑。动态字幕模板仍单独学习/实现。

- 增加四区域样式弹窗、八基础预设、字体/字号/粗斜下划线、颜色/透明度、描边、阴影、纯色背景、底部距离与字间距；有原图尺寸的790×700弹窗、固定页脚、滚动、溢出位置菜单与横竖预览。修正通用modal样式覆盖专用宽度的问题。
- 悬停实际核验：描边2，黑背景80%，阴影距离3、阴影80%；阴影距离与透明度并排，颜色独立下一行。没有虚构描边透明度控件；后端保留该参数。
- 只读原包公开ASS字段赋值后修正单位：字号按height/1080，描边/阴影/字间距/底部距离使用实际像素。换方向时换算底部距离；旧任务根据真实视频尺寸转换字号，360×640输入48的旧字号转换27。没有确认前不更改旧任务或旧渲染方式。
- 字体来自真实系统目录和可选本地目录，解析TTF/OTF/TTC名称表。任务只存字体ID和family；字体缺失报错。实际用本机原软件已有字体目录生成过预览，未复制整套字体进安装包。
- 预览使用同一ASS/libass渲染，250ms去抖、单并发、旧响应丢弃，不写业务状态。FFmpeg不能读取asar虚拟路径，预览图片先复制到真实临时目录；字体、ASS、图片与输出预览均在finally清理。
- 确认保存、取消保留临时编辑、刷新恢复、非法颜色拦截、真实文件只读导致保存失败后保留编辑均经过源码桌面操作。保存失败也回滚Store内存；确认变更失效旧结果及发布引用，历史素材保留。
