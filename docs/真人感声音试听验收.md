# 真人感声音试听验收

日期：2026-11-15。用户要求声音像真人，听不出明显合成感。当前没有通过此项验收的结果，不能承诺所有听众无法辨别。

本轮先核对已生成声音的真实输入和处理，整理同稿候选供听审，不再盲目增加随机音色。已有 IndexTTS normal 使用 speed=1；现有工作器将 speed 传给模型 duration_factor，没有后期 atempo。Qwen 最新 conversation-v2 的 ASR 正文不同，暂不纳入此次同稿候选；自动转写差异本身不能确定实际发音有误。

范围：已有 IndexTTS 授权参考普通语速、Qwen chat、Qwen warm 三条新生成结果。最初拟纳入 oral，逐项读取实际输入后发现正文不同，已排除；clear 曾出现 ASR 正文差异，也未纳入。逐项校验生成回执、文件 SHA、输入正文；不把原参考成片当作真人录音，没有已确认的真人同稿对照。试听只能帮助选择候选和定位问题，不能证明不可辨别。

处理：FFmpeg 只做响度测量，使用相同采样规格和恒定增益生成试听文件；不使用 loudnorm 动态处理、变速、变调、混响、降噪或静音剪切。公共目标响度不高于最安静源文件；单条另受真峰值余量约束。如余量导致响度无法接近目标，记录实际响度，不谎称等响。

交付：独立离线试听页，随机显示 A/B/C，默认隐藏模型及提示词；完整播放后可记录自然度和具体问题。评分、来源揭示及导出均由人操作，程序不自动填写自然度分数。此页不进入产品主界面，不更改音色默认、用户素材或生产数据，不触发新模型推理。

验收：三条来源和正文一致、完整解码、恒定增益及采样处理记录、试听页播放/停止互斥和表单导出实际验证。技术检查不能替代人工听审；自然度和人物匹配继续保持未通过。收到具体听感后只针对首要问题改动，先短句确认，再验证新正文、长句和最终口型。
