# 声音预设交付与验收（2026-11-25）

## 本批交付

声音生成页新增“预设声音”入口，新旧工作流共用同一预设库和声音选择状态。内置八种中文音色设计：自然女声、温柔女声、活力女声、知性女声、自然男声、沉稳男声、活力男声、叙事男声。名称、场景和描述表达设计方向，不能据此认定实际自然度已经人工通过。

可按男女筛选、逐条试听并使用，也可单独生成或串行添加全部缺少的预设。已生成的音色直接进入原声音下拉框；原有 C 参考女声、用户声音、语速及情绪不会因添加预设自动改变。当前实现用于本地 IndexTTS，不把本地样本伪装成云端服务音色 ID。

预设定义随源码分发，样本由当前工作区已有 Qwen VoiceDesign 独立生成。本机已准备完八种样本，无须再次生成；其他工作区需要已有本地模型环境，点击生成后才登记音色，不会自动下载模型。模型和本机生成音频不纳入源码仓库。

## 完整性与交互

- 登记前验证当前任务成功记录、固定输入、无参考音频来源和输出 SHA256；缺失或变更的样本不会显示已就绪。
- 重复添加幂等，失效重建沿用声音 ID；生成失败或保存失败不冒认成功，保留原声音。
- 自动流程、形象优化及现有声音任务期间保留操作互斥。
- 停止按钮请求取消实际本地进程树，并阻止继续生成下一种；已完成音色保留。进度和停止操作放在固定底栏，小窗口滚动时仍可操作。
- 试听状态有对应的无障碍名称，播放失败显示真实错误。

## 实际验证结果

1. 定向声音相关测试 22 项通过；全量回归 1446 项通过、0 失败。补强保存回滚用例、清理测试自身退出监听后，新增预设测试 9 项再次通过。
2. 最终前端构建成功。构建仍提示既有大体积主包，这是构建警告，不等于已解决性能问题。
3. 从实际软件点击“添加全部预设”，真实生成八条 WAV。逐条经 FFmpeg 完整解码、FFprobe 时长与采样信息检查及 SHA 校验，均通过；均为 24 kHz 单声道，时长 6.56～8.88 秒，生成回执中 PCM 满幅采样点为零。
4. 八条均运行本机 Whisper 回读，大部分内容与输入一致；部分“你好”被回读为“您好”，简繁体和标点有差异。ASR 回读只是辅助，不是逐字准确或自然听感的人工验收。
5. 在实际软件中创建临时测试草稿，使用“自然男声”对不同的 64 字正文点击“生成声音”。IndexTTS 返回真实新音频，时长约 12.98 秒，参考 SHA 与预设一致，输出 SHA 与参考不同。播放器实际播放时间推进、无解码错误。回读中的“扒炉”“一项一项”仍存在识别差异，不能把回读视为发音质量已完全通过。
6. 实际点击男声/女声筛选各得到四张卡片；男女样本播放器均可播放、停止。声音下拉框包含原有两种及新增八种，键盘 End 与 Enter 能选中末项。旧工作流也能打开同一预设库。
7. 检查 1400×1000 及 1100×760 界面；小窗口弹窗内容可滚动、底栏可见，没有页面横向溢出。相关截图已实际查看。
8. 结束临时测试草稿前将真实运行记录及音频验收回执留在本机。最终核对原 22 个草稿、104 条素材记录、原两种声音及设置均保留，当前任务和原 C 音色选择未改变；本机共 10 种声音、113 条素材记录。
9. 已正常关闭验证会话，使用本地日常源码入口重新启动，核对工作区、实际窗口及无调试端口。桌面入口仍指向同一源码启动器，本批不产生或声称安装了新安装包。

## 证据与边界

本机证据目录：`evidence/validation/voice-presets-20261125/`（不提交仓库）。包含生成回执、八条音频的技术检查与回读、新正文配音记录、停止记录、界面截图、数据保留检查、回归及构建输出、本地启动检查。

所有预设保持 `qualityAccepted: false`，不冒充用户已试听认可。技术链路已经验证，真人感、场景适配和最终成片效果仍应由实际试听确认；本批完成不代表整个视频产品或任意内容类型都已验收完成。
