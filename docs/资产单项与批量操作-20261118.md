# 资产单项与批量操作

## 本批范围与交互

用户要求截图中的资产操作既能单个，也能批量。现有“提取本集资产”识别整集镜头实体，现有“生成资产图片”只为当前资产出图。此次分别补齐，不把提取实体与生成图片混为同一操作。

- 分镜：提取当前镜头、勾选镜头批量提取、保留本集提取。只修改目标镜头绑定，其他镜头及共享资产候选保留。
- 资产图片：查看当前项与批量勾选分离。全选仅针对当前可见筛选；可勾选没有有效图片候选的待生成项。切换范围、类型或分集裁剪隐藏勾选，避免误生成。
- 单项生成保留；批量按明确勾选的资产串行生成，降低本地模型并发争用。逐项状态及失败原因可见。已有确认图不被替换，新结果均为候选。
- 普通单项错误可以继续后项；取消或结果未知时停止后续提交。保留已完成项，未提交项标记跳过。远程未知只查原任务，不自动重发或自动续跑。

## 接口与模块

- `extractStoryAssets({id,episodeId,shotId})` 或 `shotIds` 指定单镜头/批量；旧 episodeId / 全集调用兼容。
- `generateStoryAssetImages({id,assetIds,instructions})`，结果 `{story,items,counts}`。复用 `story-image` 任务类型，`parameters.batchAssetIds`、`parameters.batchItems` 提供持久进度，`parameters.input` 和 remote 始终对应当前项，兼容原任务查询。
- 后端：StoryStudio、service 路由及回归。前端：StoryStudio、story-ui、样式及组件行为测试。主任务负责本地软件、真实媒体和交付。

## 验收清单

1. 单镜头、勾选两镜头、本集提取的输入范围正确；其他镜头绑定、已有资产及图片不改；非法/跨集/空选择不调用模型。
2. 多资产逐项生成，顺序与勾选快照一致；不同修改要求不串项；不自动确认；重复/缺失资产提前拒绝。
3. 单项失败保留其他结果；停止不发下一项；提交后未知保留当前项凭据，查询不补发；存储故障停止后续。
4. 真实软件验证筛选、全选、单项查看与勾选分离；批量真实生成至少两项图片，预览尺寸、刷新保留及逐项候选。
5. 1400×1000和1100×760检查按钮、checkbox、结果列表及滚动；分别有可访问名称。
6. 定向及整体回归、构建打包检查；桌面日常无活动任务后备份并正常更新重开，保护业务数据；提交用户授权仓库。

不把控制流通过视为内容质量自动通过；本批不要求生成整条原稿成片。日常存在活动任务时不强行关闭。
