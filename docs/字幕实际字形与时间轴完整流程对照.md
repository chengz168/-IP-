# 字幕实际字形与时间轴完整流程对照

总目标完整复刻保持active；本批先消除已确认的实际字幕示意字形差异，再核对编辑字幕流程。

1. 只读原版实窗、静态字体映射和已保存参数，取得实际渲染字体证据；不根据显示名猜字体。
2. 对照同尺寸同参数DOM与原版截图，测量字形、位置、字重、换行；未证实的原因不写成事实。
3. 只对确认的差异修改对应模块，保留旧任务渲染与已有真实字体校验，避免为截图匹配暗中切换烧录字体。
4. 操作原版编辑字幕每个按钮与重要异常路径，记录时间轴、播放、编辑、分句、保存/取消等实际行为；按证据补实现。
5. 实际桌面交互、代表截图、真实本地视频、针对性测试及必要全套测试；将局部验证与整品验收分开。
6. 使用隔离工作区。结束恢复原工作区完整字节、原版配置只读核对，包首次启动既往拒绝边界保持。

验收：实际字形取得可审查证据；新实现具备同状态对照与按钮输入输出证据；保存后真实持久化、取消不改任务、异常保留内容；所有未通过项继续列出。

## 已核实的字幕编辑契约与本批实现

证据为原版951、969静态模块及历史真实截图subtitle-editor-reopened-rows.png；原厂当前唯一任务无compositionData，点击编辑会触发平台识别，本批不执行该付费风险入口。不能将静态契约验收写成原厂本次实点验收。

- 独立临时会话：打开复制已保存字幕；取消/关闭后同一任务同一视频、已保存字幕未变化时保留临时内容；确认才写回，保存失败回滚任务并保留临时内容。换任务、换源、外部更新字幕时失效。
- 原版插入始终可用：当前end到下一start，至少0.05秒；末尾默认1秒，不移动现有行。这与旧实现“无间隙禁用”不同，可能与下一行重叠，不能偷偷声称已解决所有时间冲突。
- 开始时间限制为上一条end与本条end-0.05之间；结束时间至少start+0.05，并按本次变化量平移后续所有行。时间内部保留3位精度，数字框显示2位、步长0.1。删除后重排，最后一条禁用删除。
- 文本在失焦时，如有同源识别记录，按识别字符时间与相邻两行做最长公共子序列对齐；没有识别快照则只改文字，不虚构时间。
- 新工作流表格仅原版列与确定/取消；既有校对、历史、辅助译文、关键词、导入功能保留在旧工作流字幕编辑入口，避免挤占原版表格布局。辅助动作先明确保存当前临时字幕，再调用原有真实服务。
- 字体弹窗使用所选公开字族与系统回退；真实ASS仍使用保存的fontId对应文件。当前只有一组同参数实际字形近似证据，不外推全部字体或成片一致。

验证覆盖临时内容跨500ms不落盘、取消重开、确认刷新、保存失败恢复、换源/换任务/外部字幕失效、插入/删除/前后时间联动、文本失焦与无ASR分支、旧辅助入口；多尺寸四字号、长文本自动1至4行、键盘焦点与固定底部按钮；真实FFmpeg一次输出、解码和播放。全局完整复刻仍未通过。
