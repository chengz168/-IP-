# 商品视频中文镜头与提示优化

## 问题与范围

用户截图中第四步画面、动作、运镜为英文，现有样片动作幅度小、白底重复，用户没有接受内容质量。本批将中文编辑层与模型编译层分开，不以提示长度或媒体可播放代替效果验收。

1. 商品脚本要求所有面向用户的字段为中文；镜头表达覆盖整体、可见细节和合理使用动作，并与台词、参考图、资料一致。
2. 第四步新增当前镜头的中文优化候选，明确预览、应用或取消。不修改确认稿、旁白、商品事实、绑定图或时长，不自动覆盖既有镜头。
3. H3 仍沿用其规定的分区和参考标记；产品短镜头提示把主要动作安排在实际保留的时段内，并注明多生成部分只作连续收尾。避免长铺垫、多个复杂动作和镜内切镜。
4. 单镜不能靠提示将白底原图瞬间变成完整生活场景；首帧决定开场构图，优化候选必须兼容当前参考图。场景重构需要可审核的新首帧，本批不静默替换用户原图。

## 验收及恢复

- 候选输出中文检查、结构校验；上游、镜头或编辑变更后候选不得覆盖当前内容。
- 应用沿用原保存与失效机制；旧候选历史保留，确认稿、音轨与配音设置不变。
- 定向回归、必要全量与构建；日常软件按原入口更新并启动核验，保护用户数据。
- 真实 H3 镜头与旧镜对照，记录商品形态、动作、构图和时长；不符合则明确未通过。没有亲耳试听不得称声音验收。
- 网络来源仅采用可核对的官方原始资料，记录实际访问结果，不能声称获得对标软件内部提示词。
