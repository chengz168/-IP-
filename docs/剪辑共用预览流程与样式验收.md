# 剪辑共用预览流程与样式验收

依据原厂 `951.2ef9483f.js` 静态解码、`951.17e37a69.css` 和已保存的真实操作截图，当前所有剪辑模块应共用预览区。证据在 `evidence/reference/service-audit/edit-preview-contexts.json`、`evidence/reference/reference-render-result.png`。

## 本批实现

- 新工作流七个剪辑模块共用一个预览组件；换模块不重建播放器、不丢预览模式。
- 无成片时只显示编辑预览。有当前或同源历史成片时出现两种模式；新生成成功自动切成片，换任务或视频源回编辑。
- 成片模式提供真实打开/导出；渲染配置改动后可查看同源历史结果，但标注“成片未更新”，不得恢复任务就绪或自动进入发布。利用已有执行快照和输出引用判定，不新增伪造产物。
- 编辑预览使用真实源视频首帧；抽帧是只读操作，不写草稿、素材库或执行历史。切任务/视频时不接受过时回包；失败显示错误，可重试。
- 标题图层沿用现有真实绘制与拖动；字幕/个人名片完整编辑预览图层另列差距，不能将本批共用预览视为这些图层已完成。
- 成片窗口内容区展开：同一播放器保留时间与播放状态，展开按钮/退出按钮/Escape可用，切任务或模式关闭；布局对应原厂54/40/34px边距、24px圆角，键盘焦点可回到展开按钮。
- 预览标题、说明、模式按钮和结果操作按原厂换行与间距排列。两窗口四字号检查空、编辑、成片、过期、展开与窄窗长文件名状态。

## 验收

1. 使用现有本地媒体在隔离工作区实际剪辑生成，验证自动切成片、模式切换、跨模块保留播放器、修改参数后过期及再次生成恢复。
2. 刷新后同源历史成片可查看但不标为就绪；换源/换任务不能显示另一任务或另一源的历史结果。首次旧任务只读打开不改业务JSON。
3. 打开/原生导出/取消/缺文件错误，以及窗口展开与退出保持时间；真实导出SHA和媒体解码核对。
4. 首帧实际PNG尺寸与直接解码帧核对；无新增资产、运行记录、磁盘临时残留，失败恢复后可重试。
5. 适用状态边界测试、源码桌面与局部视觉检查、构建和目录包核对。恢复原工作区并核对完整JSON。

整体目标持续active；本批不声称全部页面、字幕/名片预览及生成质量已经一比一。
