# C音色轻情绪受控对照

2026-11-16。上一批发布标签真实交互和导出验证已完成，整体复刻目标仍在进行。用户相对偏好C，主要指出停顿及语调像念稿。C1只改变标点，自动转写有差异且未经听审，不替换C。

## 本轮依据及范围

直接核对当前工作器inference_arguments、生产speech-request与固定版本infer_v2_5.py：C的情绪为空，实际未传情绪向量；0.7强度对该空情绪没有有效作用。现有产品支持高兴情绪及0至1强度，可经真实高级设置控制，无需新模型或新接口。

本轮只生成一个C2候选：完整文案、标点、授权参考声、种子42、语速1及模型版本均沿用C，情绪设为高兴、强度0.2。有效变量是增加低强度高兴向量。尝试目的是观察句内语调变化；改善自然度属于待验证假设，启用情绪向量也可能改变听感或降低人物匹配，不能预先认定更好。

不修改生产默认、不删原C、不追加随机种子候选、不把播放/ASR当人工质量。只读复制正式业务数据到独立验证工作区，后续写入仅经现有产品API；不下载模型、不付费、不上传或启动打包EXE。

## 执行与验收

先核对无活跃任务、原完整数据SHA及6保护文件SHA、C来源和参考声SHA。新稿经API建立，在真实声音高级设置中选择高兴并填写0.2，然后点击一次生成声音；提交前保存意图，查到任务后保存ID，观察超时只查询原任务，不重交。

完成后核对任务/素材来源与全部控制参数、生成文件SHA、完整解码、非静音及满幅采样数，自动转写与原正文对照并保留任何差异。实际产品音频完整不静音播放到结束、刷新绑定；试听页仅做恒定增益与统一采样，不后期改停顿、变速、变调或加混响。相同响度必须经实际测量，无法达到时记录差值。

交付C/C2试听与具体控制参数，人工评判语调、停顿和声音人物适配；程序不填自然度分数，不自动默认新候选。结束关闭独立窗口，检查正式数据及保护SHA不变。若C2未过正文或人工质量，不继续用其生成长片。

证据目录：evidence/validation/voice-C-emotion-20261116。仅新增验证脚本和文档时，不重复全套构建打包；若发现生产问题，按影响范围修正并验证。
