# 视频预览打开、导出与样式对照

本批只改新工作流视频生成页的结果卡片，以及它复用的桌面文件导出桥。原厂证据为 `evidence/reference/service-audit/video-preview-actions.json`、用户截图和 `evidence/validation/video-preview-actions/reference-css.json`。完整复刻目标仍在进行。

## 行为与布局

- 有视频时，标题右侧显示“打开”“导出”；空状态保留占位，不显示结果按钮。
- 打开定位当前视频文件；导出弹出标题为“导出视频”的原生另存框，以素材文件名为默认名，复制实际文件。取消不提示成功，不修改草稿或源媒体。封面原有导出标题保留。
- 卡片标题、按钮垂直居中；按钮间距8px，圆角胶囊；打开蓝底，导出半透明底。预览内容内边距14px、圆角18px，视频圆角14px；文件名在视频下方，间距10px，长名省略并提供完整提示。
- 保持上一批低窗口配置滚动和固定生成按钮；视频在可用区域按比例完整显示。窄窗口大字号不得使操作按钮或文件名溢出。
- 操作期间防止重复提交；实际失败给出可读错误，不报成功。浏览器无法定位本地文件时禁用“打开”，导出使用下载入口；桌面验收不以浏览器下载替代原生对话框。

## 验收清单

1. 空预览、现有竖屏视频、长文件名分别检查两窗口四字号，共24局部状态；检查卡片包围、标题按钮对齐、8px按钮间距、文件名完整提示和无横向溢出，保存截图并人工查看代表图。
2. 真实点击打开后核对资源管理器选中文件；真实原生导出后源/目标SHA一致，并探测、播放；取消不产生文件、不显示成功。
3. 移走隔离工作区媒体后，打开和导出均失败且提示可读；恢复文件可再次操作。测试期间不动用户媒体。
4. 同路径导出不截断源文件；普通视频导出不改变封面视频的既有标题。这些桥接边界用独立测试验证。
5. 完成适用测试、构建、目录包核对；不启动此前被拒绝的打包EXE。恢复本批开始时含4模板的原工作区，并核对完整JSON。

不把复制视频当作新口型生成，不认定生成质量或全页像素一致。
