## 原厂事实及当前缺口

本模块是第五步网感剪辑中的“标题”，与第六步标题封面的15套模板和图层系统不同。原图05-edit.png、title-editor/opened.png显示主标题、副标题、生成图标、“一直显示/显示几秒”、“模板/自定义”、两列模板卡片、编辑/成片预览。当前Workflow.vue只提供主标题和黄色/白色两种基础样式，render.cjs仅烧录主标题；已有edit.subtitle字段没有实际用于副标题绘制，不能把字段存在视为功能完成。

本轮真实点击：自定义模式、滚动基础/位置/描边/阴影/背景；切回模板；选择显示几秒出现初始3秒输入；再恢复一直显示及模板模式。截图目录为evidence/reference/title-editor。未点标题生成图标或剪辑生成，未触发新模型调用或付费生成。原任务数据与步骤已只读比较，pipeline_data/settings_data相同，task_steps相同，仅updated_at变化，见restore-report.json。打开自定义即出现“这是一条预览”，同时原成片仍存在而预览标记未更新，这是原厂实际表现，不能据此认为已生成新成片。

原软件公开模板字面量静态核对为10项：黄色喜脉体、黄白行楷、黄白标题黑、黄白大楷、白色猴尊斜体、红色律动宋、橙黄错位、橙白粗黑宋、橙白思源宋、蓝色文道潮黑。catalog.json仅保存可见名称与样式配置及参考图片标识，不执行原软件模块、不复用原厂实现或图片。只有前三项和第四项当前已有UI截图，全部卡片仍需实点核对。

已见自定义分组：字体、字号、颜色、透明度、粗体/斜体/下划线；字间距与顶部距离；描边开关；阴影距离/透明度/颜色；背景颜色/透明度/圆角/宽度/高度。当前任务显示微软雅黑56、100%、顶部120、阴影3/45%、背景38%/24×12/圆角18；这是该任务数值，不能当所有新任务默认值或真实成片坐标语义。模板有70/68/64等不同字号，必须核对实际缩放。

## 下一批实施范围

1. 写只读旧数据转换与完整标题配置，保留旧黄/白成片兼容；首次编辑再写新配置，不启动即污染原任务。主副标题、持续时间、模式、模板、真实字体和自定义样式独立保存。
2. 单独TitlePanel组件，按原图标题/输入/分段/卡片/属性栅格实现；主副标题并排、52px级标题行等实际量取后落实。窄窗四字号要保持可操作，不用裁字代替排版。
3. 预览与实际烧录共用独立实现的标题排版、字宽和字体加载；复用现有Canvas及后台绘制基础时先确认透明图层、视频真实尺寸和取消机制。编辑预览在源视频上显示，成片预览不叠第二份标题。拖动更新真实坐标，暂停/倍速/持续时间使用最终输出时间轴。
4. 10模板有实际绘制和缩略图；字体缺失明确提示，不能静默以近似字体冒充。主副标题颜色及错位排版按已核对配置独立实现。
5. 真正渲染副标题、限定时长、位置、描边、阴影和背景。输入变化使旧成片失效、历史保留；渲染期间换任务或编辑不能附着过期结果。AI生成需按已有本地模型实际返回并核对源签名，不能做假加载或拼接示例当结果。
