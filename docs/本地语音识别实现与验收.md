## 实现契约

1. 设置明确区分兼容服务与本地 Whisper，旧配置默认仍为兼容服务。用户填写已有 Python 与模型目录，本地模式不使用远程地址或密钥、不自动安装或下载。
2. 本地进程加载固定目录模型，CPU/int8、离线环境；先检查音轨，将音视频转换为临时16kHz单声道WAV，结束、失败及停止后清理本次临时目录。
3. 子进程使用逐行JSON报告加载/识别进度及结果；启动错误、缺依赖/模型、无音轨、无识别文字、非法时间轴、超时均失败并保留执行记录。只在验证成功后返回文字和字幕，不造占位结果。
4. 支持停止本地进程，等待退出后才清理临时音频；任务状态标记已取消。已有远程任务的未知状态规则保持原有语义。
5. 用户在识别期间切换任务、更换源视频、修改原文或字幕时，不覆盖新输入；识别输出仍留在执行记录供查阅。字幕带时间轴才可用于剪辑。
6. 设置页沿用独立滚动、分区、双列标签顶端对齐和一致字段间距；长路径不撑宽页面。1400×1000和1100×760均检查本地/兼容两种状态以及页面底部操作。

## 验收

- 契约测试：非法输入/时间轴拒绝；设置持久化兼容；本地分支不请求云端；取消与进程退出/清理；输入变化保护。
- 真实本机：检查现有模型并实际识别有声视频，记录耗时、原文、字幕时间轴及进程退出状态；静音、无音轨或缺配置明确失败；不把单样本识别当准确率承诺。
- 源码桌面：设置保存恢复→提取文案→生成字幕→编辑保存→真实剪辑→播放；至少验证一次主动取消和一次输入变化后不覆盖。
- 适当测试、构建、受影响页面实图与几何检查、目录打包和哈希。打包EXE启动此前被审批拒绝，不能变换方式绕过；此项仍未验收。
