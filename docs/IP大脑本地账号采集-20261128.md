## 边界与验收

- 本地路径限定抖音公开账号主页。浅度最多3条有效作品，深度最多6条；最多额外尝试2条来替换失败样本。
- 仅采集主页“作品”区域，核对封面作者，排除其他账号推荐。用户明确选择口播文案时，再核对每条作品详情作者并提取音轨；发布文案模式单独读取作者真实发布的标题与配文。
- 两类样本分别标记为 `profile-video` / `profile-caption`，保留对应依据；发布文案不能显示为视频转写、字幕或画面分析。原有默认仍为口播文案。
- 深度账号学习增加文案样本及分析粒度，不宣称分析完整账号、全部历史或视频画面。
- 保留作品链接、成功/失败和覆盖范围；口播样本另保留素材哈希及转写。原素材未变且ASR配置相同时才复用转写，失败后的重试优先未尝试作品。
- 页面要求登录/验证或未返回公开作品时明确失败，不绕过平台限制；本地文案/视频导入仍可用。
- 解析会话互斥，停止释放会话；采集后输入、模型配置或源媒体变化则不覆盖档案。

## 实际验证与交付

- 通过实际应用 UI 点击“添加并学习”，不是另建 Store 写正式数据。2026-11-28 发布文案模式采到6条、合计321字，调用现有本地 `qwen3.5:9b-q4_K_M` 完成分析并保存1个档案；3条摘录均可定位原文。
- 同账号音轨模式两次有限采样未积累80字有效文案，真实标记失败，没有伪造口播档案。ASR含错字，不能宣称该账号口播内容已完整学习。
- 摘录校验保留原文位置，容忍双空格压缩、中文间排版空格和已有的等价标点；拒绝改字、跨段拼接、英文单词粘连。保留模型原摘录便于核对。
- 最终针对性回归：86项，85通过、0失败、1项媒体条件未启用而跳过；构建成功。存在原有大包体提示。
- 已安全更新并启动实际本地源码入口，原29个草稿、声音配置、模型设置与已有素材保留。新增采集素材及执行记录留在本机。
- 实际1400×1000窗口检查了可点击按钮、学习内容选择、样本计数、分析弹窗、滚动和来源展开；分析弹窗在可视窗口内。
- 本地验证记录：`evidence/validation/brain-profile-20261128/verification.json`，实际成功运行与样本另保存在同目录，不提交仓库。

实测兼容性：Electron 默认 User-Agent 含应用名称和 Electron 标记时，账号页走客户端路由并返回“用户不存在”。保留实际 Chromium 版本、仅删除应用标记后，同一独立会话加载出公开作品区域。已加回归测试，不改变用户日常Chrome配置。
