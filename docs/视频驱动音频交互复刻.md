# 视频驱动音频交互复刻

日期：2026-11-15。范围仅限视频生成页的驱动音频区域，整品复刻目标继续执行。

## 已核实的原版行为

用户指定人物为内置“示例2-夜间”。原版驱动音频显示来源（手动音频/上一步音频/未选择）、文件名、播放暂停按钮、真实波形和选取按钮。静态只读源码显示使用 WaveSurfer：高30px、柱宽2px、柱间距2px、圆角2px、归一化；换源重新初始化，卸载销毁。空音频隐藏播放器但保留选取入口。来源源码片段、SHA和实操截图路径存于 `evidence/validation/video-driver-audio/reference.json`。原版截图实际观察到播放/暂停图标切换，不以截图证明听感或口型。

## 实施方案

1. 在 VideoPanel 复用新 VideoDriverAudio 组件。来源由显式video.audioId与voice.audioId区分；不更改生成协议或原有资产。任务ID及音频ID共同作为组件键，切任务/换音频停止旧播放；页面卸载清理元素、事件、请求及AudioContext。
2. 原生audio负责真实播放、暂停、结束、拖动定位；加载或解码失败显示中文错误。异步play完成后核对所属源和意图，迟到的旧播放不能启动新源。打开选择器先暂停，取消选择保持原绑定；不自动恢复播放。
3. 波形从真实文件解码获得。最多读取64MiB、最长600秒，8kHz解码、512个实际峰值；真实静音不制造声纹。超限/不支持解码时保留可试听的进度条，并明确波形不可用。请求设30秒超时，离页或换源取消，实际播放不依赖波形计算。
4. 波形遵循原版柱宽/间距/高度/归一化及圆角，按窗口实际宽度重画。点击与键盘方向键/Home/End可定位。播放按钮36×36、波形盒48高、间距10、选取按钮38高，文字溢出省略。窄窗仅滚配置字段，不让旧全宽按钮规则影响新布局。

## 验收

- 必要单元测试覆盖旧play迟到、暂停意图、换源销毁、错误、结束、定位、读取上限及真实峰值。
- 新独立桌面工作区，不改9347/9349既有验收数据；使用已有示例二8秒驱动和产物。实际播放到结束、暂停/定位、换源、选择取消、离页、刷新、缺文件；无生成POST。
- 1400×1000及1100×760的四字号、已选/空音频布局，直接查看代表截图。原视频/原示例/业务数据SHA保护。
- 完整测试、构建、目录包一致性；不绕过既有打包EXE启动审批拒绝。

本批不生成新模型画面，不将试听控件、测试或播放器成功当成同质量验收。MuseTalk新增模型下载继续等待已有问题的答复。
