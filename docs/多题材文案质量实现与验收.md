1. 使用已有本机文本模型，不下载、不切换用户原工作区模型、不调用原厂生成。测试输入为明确编写的虚构验收素材，不冒称真实产品参数或真实活动。

4. 根据基线问题补共享检查：明显后台过程、完全重复、候选重复等可确定问题应保留证据并拒绝选用；事实与表达质量没有充分证据时仍为待复核。不得将关键词或字数检查冒称语义验收。
5. 补齐创作成功与失败的真实请求/原始响应证据；失败不替换旧候选。前后端共同拒绝明显无效候选，旧批次也按当前检查规则核对，不能仅依赖存储标记。
6. 运行有意义的质量/候选回归测试、构建和最终目录包哈希；用实际桌面验证候选选择/拒绝及已有界面布局，再恢复原工作区完整JSON含updatedAt。独立EXE首次启动仍沿用未验收状态。

- 基线：隔离服务生成并保存每个案例和请求，已完成案例不重复请求；原工作区只读比较。
- 修正：仅对有明确问题证据的模块改动；原始模板、用户自定义数据、历史失败不覆盖。
