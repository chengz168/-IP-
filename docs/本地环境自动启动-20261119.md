# 本地环境自动启动与故障恢复

用户要求软件打开时判断本地环境是否启用，未启用则自动启用。截图的13项图片均因 ComfyUI 8188 无服务失败；本轮检查确认该端口无监听，Ollama 已运行。上批只在验收期间外部启动服务，没有接入日常生命周期，不能保证用户下次打开软件仍可用。

## 本批设计与验收

1. Electron 创建业务服务后异步检查已选择协议的常驻服务，窗口立即可用。ComfyUI、Ollama 健康则复用，未运行则从已配置或已核实的已有安装启动，等待真实健康回包。禁止下载模型、执行任意shell命令、启动云端或不匹配的服务。
2. 同一地址启动请求共享等待，多窗口通过服务专用启动锁避免重复进程。健康只代表服务就绪，模型权重仍由原生成预检确认。启动失败、超时、路径缺失或被其他程序占用明确显示原因和日志。
3. 入口为全局环境状态与模型设置内的管理面板，可配置已有安装目录、解释器与Ollama程序，默认自动启用。保存不覆盖其他模型和业务配置；关闭软件不结束外部或共享服务。
4. 本地声音、口型等现有Python工作器继续按任务启动，开软件只检查文件条件，不提前加载全部GPU模型。不把文件检查当推理成功。
5. 生成前等待对应服务就绪；结果未知任务只查询原任务，禁止因服务重启而自动重新提交。公共连接/模型预检故障停止批量余项，保留已成功候选；普通单项内容失败保留原继续策略。
6. 回归覆盖启动/复用/并发/云端跳过/路径错误/超时/取消与批次终止，真实Electron打开时从未运行状态自动启动Comfy，健康后通过产品按钮实际出图；两尺寸检查、打包和日常更新、业务保护、提交授权仓库。

## 实施记录

- root负责环境管理器、Electron/业务接入、真实服务验收、本地更新和提交。
- local_environment_ui负责全局状态、设置面板及组件定向回归，文件范围独立。
- 仅修改本批相关模块，保留历史失败记录，不自动重跑13项或自动选用生成结果。

## 最终实现

- `server/local-environment.cjs` 管理已选 ComfyUI 与 Ollama。软件打开时异步检查；已有健康服务直接复用，断开时启动本机已有安装并等待真实响应。生成前也经过同一管理器，不把进程创建当服务可用。
- 默认启用，标题栏可打开环境详情，设置 → 模型设置 → 本地运行环境可保存开关、ComfyUI目录、Python程序、Ollama程序。关闭自动启动时所有入口只检测，按钮相应显示“检查环境”。路径与现有模型来源配置独立保存，不覆盖业务或服务密钥。
- 同址请求共享等待，多窗口用专用原子启动锁协调。锁带唯一token，进程记录校验可执行路径和系统创建时间；损坏旧锁静置后核验文件身份再恢复。无法确认的活进程记录明确报错，禁止猜测重启或kill；进程记录以临时文件原子替换，退出只停止本窗口等待。
- 声音、口型、语音识别、音色设计沿用按任务加载；开机做文件预检，界面明确不代表本次推理成功。未新增模型下载。
- 公共连接或模型预检故障立即停止批量后项，已失败首项保留原因，其余显示“公共模型环境不可用，未继续提交”；普通单项失败仍保留原继续策略。

## 真实软件验收

证据目录：`evidence/validation/local-environment-20261119/`，不随公开源码提交。

1. 冷启动前 `8188/system_stats` 实际 ECONNREFUSED，Ollama 已运行并响应。仅启动真实Electron入口，观察到 checking/starting 状态、窗口与详情仍可操作，没有手动启动Comfy脚本。
2. 首次真实启动发现启动环境无 USERNAME，Python getpass 报错退出。保留 `initial-failure.json`、界面和服务日志，随后增加从系统账户读取用户名的Windows兼容处理。重新冷启动后成功，启动器PID23840，服务监听PID27172。
3. 通过软件“资产图片 → 生成资产图片”按钮完成真实推理，任务 `b4fb2179-c077-41b5-980f-880993225890`，Comfy任务 `7356b44c-7327-4de0-b60d-22dab6a177b7`，素材 `e3134a3e-6b7d-4b00-8ad7-13c3662e75eb`。图片768×1344，真实预览加载成功；画面为单个红球与浅色背景，未据此宣称其他内容或视频质量通过。
4. 正常关软件再打开，环境立即复用，监听PID27172及完整进程记录保持一致，没有新增启动。记录见 `reopen-reuse.json`。
5. 实际点击环境详情、启动设置、保存路径、关闭/重新开启自动启动、手动检查；未保存配置会提示先保存。1400×1000、1100×760分别检查标题栏、环境弹窗、设置输入与底部操作，未见横向溢出；日常六项环境列表可纵向滚动，底部按钮可达。独立验收无renderer异常。
