## 运行

在当前项目目录执行：

```powershell
npm install
npm run build
npm start
```

桌面程序默认1400×1000。当前机器已安装依赖，可直接运行 `启动超级IP智能体.cmd`。浏览器开发预览使用 `npm run dev`，地址为本机127.0.0.1:5173。桌面与浏览器开发服务使用同一data目录，不能同时写入；启动另一种模式前先关闭当前服务。

源代码运行的数据位于项目data目录，独立打包程序默认使用Windows用户数据目录。设置中的输出目录留空时，产物写入数据目录的outputs。设置页提供任务与受管理素材备份、哈希校验和恢复前副本；发布包历史目录另行保存。

## 已实现与验证

- 七步流程、四个学习页签、旧版多栏、新旧视图共用任务。
- 任务自动保存、资源导入与管理、提示词管理、执行记录、上游变动解除旧产物引用。
- FFmpeg真实剪辑：音量、速度、字幕、标题、名片、背景音乐、音效、视频/图片画中画；多轨和剪气口已有真实后端专项。完整桌面交互与全部模板仍需验收。
