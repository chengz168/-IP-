# 本地H3真实进度设计

## 已证实的问题

2026-11-15新配音驱动H3任务实际15分48秒，而本地运行记录从提交至结束一直停在12%。该百分比只能表示本地阶段，不能说明真实采样进度，容易误导用户以为卡住。

## 本批实现

订阅配置的同一本机ComfyUI /ws?clientId=<本任务clientId>。使用服务端已有executing与progress事件；只接受与本次prompt_id及生成图节点匹配的消息。未取得提交ID前暂存有限数量消息，取得原ID后筛选；缺prompt_id消息不推断关联，非法值和其他任务均忽略。

Runtime增加独立activity字段，保存promptId、节点、真实value/max、观察时间与中文阶段文字。运行条在有activity时显示实际阶段及“采样x/y”，不将其伪装成总完成百分比；原运行记录progress用于既有流程兼容。执行详情继续保留真实阶段日志。没有进度事件时明确等待服务状态，不按时间增长百分比。

订阅在提交前尽力连接，连接失败或断开不影响原任务GET查询，不把观察超时当任务失败，不触发POST重交。每次执行段按原clientId和promptId分别订阅，关闭/取消立即断开；长片/多镜头显示第几段并保留相同原任务恢复契约。事件不将任务标成功，最终状态只认历史与真实输出。

## 验证

真实本机HTTP/WebSocket夹具覆盖早到消息、错误prompt/node、非法步数、乱序、连接失败、取消清理和未完成事件不能提前完成任务；真实ComfyUI连接和实际产品新任务检查；任务状态持久化、刷新及进度条两尺寸四字号。原业务与既有验收文件保持SHA，所有新实验独立工作区。完成后当前全套测试、构建和目录包一致性核验。连续口型、听感与整品一致性不因本批通过而标完成。
