# 最终目标与验收矩阵

目标是从短视频链接、商品链接或参考素材，在同一七步工作流内完成可用的短视频创作。内容画像用于选择制作方法，不能代替实际模型能力或成片质量。

| 范围 | 必须验收的行为 | 证据 |
| --- | --- | --- |
| 输入 | 单条与批量提取，逐条显示成功/失败，停止、刷新恢复，显式选择一条正文接下游 | 后端持久化回归、真实软件操作截图 |
| 解析 | 区分标题、转写正文和静态画面观察；无音轨视频不捏造旁白；时间轴仅引用有效证据 | 来源哈希、模型响应、时间轴回归 |
| 类型 | 十类画像，低置信不冒充确定，手动选择有效，旧结果不可污染新内容 | 定向回归、真实预设显示 |
| 脚本 | 资料事实、钩子、结构、旁白与镜头关联；商品不凭空增加功效和优惠 | 保存请求与结果、人工审稿 |
| 资产 | 原图与角色/场景/道具关系可查；能逐项重生成并保留候选 | 独立验收任务、素材与版本记录 |
| 配音 | 对应确认正文和当前音色，停顿语调自然度须听审 | 新生成音频、请求签名、试听 |
| 动态视频 | 有符合文案的主体动作，外观/身份一致；不可将静态图排列当作动作生成 | 新生成镜头、关键帧和成片审看 |
| 成片 | 字幕对齐、画面比例、封面和导出可用；机械可播放与内容质量分开记录 | FFprobe、解码、实际播放器、质量结论 |
| 交付 | 保留旧任务素材配置，更新实际桌面入口并验证，提交到指定仓库 | 数据保护回执、启动回执、远端HEAD |

本轮UI探索至少包含：输入两条重复分享文本、批次执行时切页再返回、成功后编辑正文再选用旧结果、长链接/失败文字在小窗口的布局。
