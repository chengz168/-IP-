# 字幕编辑器布局校正

日期：2026-11-14。整体复刻仍在进行，本文只定义本批可核验的布局修正。

## 依据与范围

原软件当前窗口为1400×1000，样式弹窗790×700。以实际点击截图为主，安装包前端公开CSS仅用于核对尺寸；不执行原软件混淆模块。现有对照显示：字体/字号行、颜色/透明度行、预设文字、色块、固定页脚与原图仍有差异。

本批先校正左右列宽、内边距、表单标签和控件间距、预设字体及原生色块。保持真实FFmpeg预览及已保存参数契约，暂不凭CSS预览外观改变实际ASS字号或换行。原软件CSS预览与真实输出的差异需另外建立受控输出证据。

## 实施及验收

1. 新建本地隔离任务，通过UI进入编辑器；保存开始前完整业务JSON。测量改前控件位置并保存截图。
2. 从原软件实际点选简约白字和背景预设，保存相同弹窗截图，研究后恢复原始临时参数并取消。
3. 单独修正编辑器CSS和必要的样式分组，不扩散覆盖到其他页面。
4. 在1400×1000与1100×760、四档字号检查基础/特效/背景/位置、菜单、错误状态，实际点选预设及调整参数；确认、刷新、取消及失败行为沿用既有契约。
5. 查看实图并对照几何；真实预览正常、无页面错误后运行适当构建及检查。通过UI删除本次临时任务，恢复字号和窗口，比对完整业务JSON。

几何问题为0不代表全页面或像素一致。预览字形/字号与背景换行、22动态模板、封面编辑及剩余实际业务仍单独记录，不能标为完整复刻。

人工复看72状态截图发现：旧的字号切换成功提示会覆盖窄窗弹窗页脚，几何规则没有捕捉遮挡。本批扩展公共Modal：打开弹窗时清理上个操作的非错误提示，保留已有错误。字幕确认失败在编辑器内部固定错误区呈现，不用浮层遮挡操作。补真实文件只读、失败内容保留、恢复可写后重试、刷新恢复专项；几何报告需增加实际遮挡检查。
