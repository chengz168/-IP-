# 封面缺失字体的显式恢复

真实七步链路验收中，用户工作区保留的附加字体目录已不存在。清除失效目录后系统字体可用于字幕，但内置封面模板依赖的字体仍会导致封面准备失败。此功能让用户通过一次明确操作恢复当前封面，不修改系统模板，也不静默替换旧设计。

## 行为

原字体错误继续显示，并提供“改用本机系统字体”。操作检查各层当前字体，使用字体目录加载与FontFace的local来源核实可用性；仅把不可用字体换为已确认可用的Microsoft YaHei或微软雅黑。本机原字体仍可用但文件ID已失效时，只清理引用，保留字形。

所有候选变更在真正准备字体成功、任务ID和封面签名仍匹配后一次性提交。字体仍不被现有准备流程支持、加载失败、切换任务、编辑封面或卸载组件时不提交候选。现有可用层、文本、其他样式和原模板保持；更换字体后需检查换行。

普通模式缩略图继续保留真实加载失败及原因。模板面板另有默认关闭的“系统字体模板”开关：开启只更换预览方式，不写当前封面、原模板或默认设置；之后明确点选才选用对应的系统字体版，每项预览和已选场景均明确标记。系统版也必须经过真实字体准备，无法准备则当前封面保持。模式切换、字体目录重载和目录变化作废旧预览与异步选择。

恢复或选用后需要重新生成当前封面，导出文件沿用已有签名与过期校验。异步选择还保护等待期间的行内编辑与拖动；标题生成等待模板准备完成后再抽帧，切任务时不回填旧标题。
