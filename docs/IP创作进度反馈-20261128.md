# IP创作进度反馈

需求：IP选题分析弹窗只有等待文字，首次生成、换一批及生成文案缺少清晰的加载反馈。

2026-11-28检查已有 BrainStudio、Runtime、OperationStatus 与本机技能 UI/UX Pro Max。通过专用 Google Chrome 搜索并打开 vueComponent/ant-design-vue 的 4.2.6/components/progress，核对本机同版本源码与 MIT 许可证。检索词：ant-design-vue progress indeterminate 4.2.6。该组件已有数值进度能力，但本链路没有逐 token 百分比；本次继续现有 Vue/CSS 实现，未复制第三方代码、未引入依赖或模型，无额外推理成本。未对该仓库的最新维护活跃度作结论；本次仅核对固定版本的适配性。

实现：当前草稿、档案和任务类型共同筛选真实运行记录；本次准备阶段用局部 pending 状态，排除历史运行。未提供可计算数值时使用不定进度，已有服务端数值时才显示百分比。停止、失败和完成由实际状态决定，不按计时虚构进度。旧选题在重新生成期间保留。进度区域有可访问名称、不定进度不设置 aria-valuenow，支持减少动态效果。

验证：边界测试覆盖任务隔离、重新打开、准备阶段、历史任务、真实数值与停止/终态；另外构建界面并在实际应用核验。正式草稿和资产只通过应用交互使用，局部界面测试不作为真实模型质量验收。
