# 自主音色候选恢复修正

日期：2026-11-15。声音自然度听审仍未通过，本轮修正独立的可用性问题，不以此声称改善音质。

## 已核实的代码问题

VoiceDesign当前只从本任务最新run读取候选，并要求该run成功。再次生成变为running、cancelled或failed时，前一次成功音频从弹窗消失，尽管素材和成功记录仍在；之前只验证过没有旧成功记录的新草稿取消，不能覆盖此场景。后端save允许保存本任务真实成功的历史素材，因此缺口主要在前端选择和输入对应关系。

## 修正与验收

1. 在当前隔离验证草稿已有真实oral候选的情况下，再通过按钮提交一次仅用于取消的短句。确认开始推理后实际停止，记录旧UI无试听音频、旧素材依旧存在；不覆盖原候选、不修改最终文案和配音。
2. 将最新尝试与最近可用成功候选分开。最新尝试负责错误、输入恢复和停止；候选只选择本任务成功且素材存在、origin正确的记录，跳过其他任务或缺失素材。
3. 候选对应的正文/描述必须与表单一致才允许保存。失败后保留新输入，显示旧音频及明确提示；提供“恢复这份试听的输入”按钮，经用户操作填回旧候选输入并重新完整试听后才能保存，防止旧声音被当成新描述结果。
4. 候选改变时清空试听完成状态；生成期间不播放旧候选，关闭或输入切换时停止正在播放的音频。恢复不能清除实际错误回执或伪造新生成。
5. 新增针对恢复、跨任务/缺素材和输入绑定的回归检查；前端构建、源码实际取消后恢复/播放/保存/刷新/错误保留、两尺寸四字号布局及目录包资源核对。所有原始参考文件SHA保持不变。

本功能属于新增自主音色入口的可靠性修正，不冒称原厂有相同入口或原厂像素一致。若后续听审拒绝候选，仍保留为未接受历史，不生成长视频。
