# 人物画面与背景优化：本机配置与实际边界

本批产品入口为第四步“视频生成”中的单形象模式 → “优化形象”。选择画面处理与背景，生成独立形象副本，先预览，再点“选用此副本”；选用后重新生成口型视频。原形象、原片、已有音频保留，旧视频的实际文件仍可从素材库访问。

## 已有环境配置

在菜单 → 设置 → 通用 → “本地人物与背景优化”填写：

- 画面处理 Python：已有 `numpy`、`Pillow` 的 Python 解释器完整路径；替换背景还需 `onnxruntime`。
- RVM 人像抠像模型：已有 `rvm_mobilenetv3_fp32.onnx` 的完整路径。
- 媒体工具：已有 FFmpeg 与 FFprobe 完整路径。

本机本轮实测 Python 位于 `D:\AI-Runtimes\super-ip\qwen3-tts-voice-design\.venv\Scripts\python.exe`，模型位于 `D:\AI-Runtimes\super-ip\portrait-matting\rvm_mobilenetv3_fp32.onnx`。这些仅为本机配置示例，不随源码提供模型、Python 或用户素材；换机器须配置自己的已有路径。模型推理当前固定使用 ONNX CPU，不根据显卡存在宣称 GPU 加速。

模型来源为 `PeterL1n/RobustVideoMatting` v1.0.0 同名 ONNX。用户已批准本轮下载。官方发布资产大小为 14,975,696 字节，未提供摘要；官方下载分发连接失败，本轮使用固定提交 `eafish/web-onnx` 的模型镜像，并核对镜像 LFS 大小与 SHA256。实际下载来源、版本与哈希只写入本机验收回执，模型不进入代码仓库。

## 当前实现能力

- 从原片亮部低饱和候选估计一次固定白平衡，减少逐帧色温变化；轻度平滑与锐化。曝光恢复、换衣、整容、表情或动作重建未实现。
- 用真实 RVM 前景与 alpha 合成程序绘制的浅灰商务背景；递归状态随连续帧复用。模型未配置时明确拒绝执行。
- 旋转、非整数帧率、可变帧率原视频自动转换为临时正向 CFR 副本；原音轨从原件复制。
- 生成独立视频、首帧封面与形象 ID，保存模型/原件/结果哈希和实际处理参数；原件或形象发生变化则拒绝登记。
- 支持停止并等待本次进程树退出；失败、取消和保存失败回滚本次资源。结果保留 `qualityAccepted:false`，格式校验不能代替画质认可。
