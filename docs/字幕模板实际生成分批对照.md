# 字幕模板实际生成分批对照

日期：2026-11-15。目标仍是功能、UI和交互完整复刻，本批只解决已取得可靠源码证据的三个模板，不代表全产品完成。

## 已核实差异与依据

原厂30份字幕引擎文件已只读提取、记录SHA并用AST白名单解码，路径为 `evidence/validation/subtitle-template-runtime/reference`。没有执行原厂模块、没有更改原厂数据库。`TemplateBase`以1920×1080为基准；三个simple模板字号显式按高/1080缩放，坐标各按对应轴取整。`index`在事件生成后按高/1080将正offsetY向上移动，不能将所有模板统一当作顶部对齐的一行字。

原厂简约黄白用江城律动宋.ttf，六句不同黄白颜色、位置、缩入或上移；蓝白用喜脉体.ttf，固定种子20260115控制附加动画；棕白用思源宋体.ttf，六句分别淡入、弹入、滑动、倾斜、逐字和闪光标。三者第2、4句如有下一句都延长到下一句结束；长字按候选运动位置计算安全宽度，字号下限70%，不主动增加分行。原厂ASS构建器WrapStyle为0，保留其渲染器自动换行行为。

当前本地engineVersion=1以height/1920及通用动画生成全部模板，模板GIF只演示四句且使用旧绝对位置900。前台目录的config不等于原厂实际烧录规则。

## 实施范围与兼容

1. 增加独立、可测试的三个simple模板渲染规则，保留文本转义和现有输入校验；不执行原厂混淆代码。新增字体按已配置目录真实文件名解析，不借其他字体冒充。其他19模板暂保留旧引擎并列入后续待办。
2. 同一正式渲染函数供GIF与剪辑使用，GIF演示完整六句并裁出实际字幕区域；修改引擎缓存版本，旧GIF不复用。
3. 三个新模板的输出元数据记录engineVersion=2、原生坐标与偏移；预览、任务就绪和自动流程复用检查共同拒绝旧版本成片，历史文件仍保留。没有启用字幕/其他模板不误标旧。
4. 不修改用户当前任务，不改原厂安装。桌面验证使用独立数据根，结束后恢复原数据根并逐字节校验。

## 验收清单

- 横屏/竖屏和1:1的坐标、逐轴取整、六句循环与第2/4句延长；蓝白固定种子跨六句继续，而非每组六句重置。
- 三种颜色和字体文件、字重、阴影；棕白逐字时间与光标；长字缩小/下限、特殊第五句字号覆盖顺序；变速仅改变字幕时段而不擅改固定动画毫秒。
- 正负偏移同时移动pos/move；文本中的ASS指令不能注入；取消信号、缺字体、旧任务绝对位置兼容。
- 真实FFmpeg在横竖屏渲染完整循环，抽取进入/稳定/叠句/逐字/空档，完整解码；这里的参照是已核实规则及静态契约，不冒认为原厂同源最终视频。
- 源码Electron实际选择模板、偏移、剪辑、播放、刷新，GIF非空；至少两个异常场景（缺字体与旧成片）和两个窗口的模板页布局。测试/构建/目录包收据保存实际退出码；打包EXE历史启动审批被拒，本批不启动，startupVerified=false。

保留旧模板渲染分支与历史媒体，新增规则故障明确报错不静默降级。其余19模板、双语/关键词模型调用、原厂main.jsc实际参数及同输入最终视频、完整教程与隐藏提示词、克隆口型、发布、全部页面状态仍需逐项核实，不能以本批结果外推一致。
