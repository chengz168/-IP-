## 已接入的产品流程

第四步“视频生成”新增“非口播创作”，默认读取第二步确认的最终文案。用户指定集数，再逐集拆分镜头、提取人物/场景/道具、生成并确认资产图片、选择构图图、生成动态视频、按镜头顺序合成当前集。图、视频、合成均关联稳定 ID 与输入指纹，局部变更只影响相关镜头或集，重新生成不会自动替换已选版本。

旁白可关闭，或使用第三步配音。只有单集允许直接复用整条第三步配音，多集必须逐集选音频；旁白时长须匹配本集，不随意截取整篇声音。切回无旁白后不再混入曾经选过的音频。图片、动态视频服务分别可配置本地或云端；本地已经核实的组合为 SDXL 与 ComfyUI H3，云端桥协议配置不等于所有厂商已经验收。

“使用当前集，进入网感剪辑”写入本集视频和剪辑源并进入第五步，完整上游剧本保留。自动字幕参考、字幕校对、剪辑标题、封面标题和自动发布信息读取已交接的当前集。换集归档上一次编辑、封面与发布参数，清理旧字幕、标题、封面背景、发布正文及产物引用，避免串集。

上游改稿、撤销确认或实际依赖的旁白变化会使旧下游引用失效；独立剧本或无关声音参数不会误清成片。专用保存和交接入口遵守发布中、自动流程中的输入锁，迟到产物保留素材及 Runtime 证据，不覆盖锁中的草稿。后台刷新保留未保存的模型设置，设置锁与后端一致。
