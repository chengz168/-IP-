# 字幕校对空行与断行修复验收

## 问题和最终行为

可信稿的段落空行会被两条字幕校对路径原样带入建议，渲染后出现多余空白行。原贪心换行还会把句末标点或最后一个字独留末行，影响阅读。

校对建议现在只把连续空行压缩为一次正常换行，保留正文、原字幕、ID和起止时间。常规与自定义ASS共用的换行器利用运行时自带的中文词边界、常用行首行尾标点限制和常用阿拉伯数字单位边界断行；对于不足行宽三分之一的末行，在最后两行之间优先采用合适的分句边界再均衡。不新增依赖，不拆分字幕时间段。显式换行和显式空段不由换行器自行删除；空行只在生成校对建议时压缩。超出整行宽度的长单词仍逐字保底折行。

这里的每行18字是既有显示宽度规则，ASCII字符按0.6单位计、其他字符按1单位计，并非每条字幕最多18个Unicode字符；自定义样式仍按既有字号和画面宽度计算实际行宽。此变更没有改造字体真实测量，也没有声称实现完整中文排版标准。

已知排版边界：按码点估算宽度不等于字体真实测量，也不是完整Unicode字素簇断行。极窄行宽能容纳完整数量却容不下后续标点时，优先保全数量，可能单独显示后续标点；测试明确保留此例外，不能声称任何宽度和输入都无孤行。
