# 整账号公开作品解析

## 范围与真实完成判定

IP 大脑的“采集范围”分为抽样学习和全部公开作品；浅度、深度继续控制分析粒度，口播文案与发布文案仍分开选择。

- 全部模式逐页读取目标账号的作品区域，合并作品 ID，包含可核对的图文发布文案，排除推荐和其他账号。
- 只有明确作品末尾或可靠精确总数吻合，且没有隐藏卡片、归属遗漏、登录限制或计数变化，才认定作品发现完整。停滞不是末尾。
- 每条已发现作品分别提取。空配文、被截断文字、音轨失败、图文无音轨均记录原因；有未成功项时不能标整账号完成。
- 模型分析按每批最多 12 个原文片段、10000 字进行，并按实际模型的 UTF-8 字节预算进一步缩小批次；超长作品分段并保留位置。所有分批结果都可展开，概览仅为有限条目汇总。发布文案分析不能称为口播、字幕或视频画面分析。
- 全量仅指本次可访问的公开作品，不包括私密、已删除、受限作品；不绕过平台验证或登录。

## 恢复与数据保护

运行检查点保存发现清单、提取结果和已核验分析批次。取消、程序中断或模型失败后，继续采集时重新核对主页，并按同账号、来源、模型配置与内容哈希复用结果；媒体另校验文件哈希与作者。旧发现记录不会被当作本次末尾证明。原始资料、声音、模型配置与其他草稿不改变。

发现阶段默认限制 300 次读取、10000 条作品和 5 分钟，触及限制会明确保存为部分结果。继续时会重新遍历主页，不保存可跨越该限制的平台游标，不能承诺无限规模账号都可完整采集。文本不足 80 字时保留采集记录并说明分析材料不足。

停止期间保留检查点，不自动发起新的 GPU 推理。创建后续选题/文案使用已学习风格和明确标识的有限原文摘录，避免整账号长文本超出模型上下文。手动修改学习样本后不继续沿用全量覆盖声明。
