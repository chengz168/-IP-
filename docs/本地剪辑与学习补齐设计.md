# 本地剪辑与学习补齐设计

日期：2026-11-13。依据现有差距矩阵继续完成实用功能；不是完整复刻完成声明。

## 智能剪气口

通过FFmpeg silencedetect检测音轨，保留每段说话前后可配置的少量静音，再用同一保留区间trim/atrim并concat音视频；之后统一应用速度、字幕、标题和混音。字幕由源时间轴与保留区间求交，映射到剪后时间轴再除以速度；不能只裁音频或保留旧字幕时轴。检测与预览是独立操作，渲染时根据当前输入重新计算。无音轨、无有效内容、区间过多或参数非法需明确报错；未检测到静音则保留全片。

验收使用真实声音生成的语音片段与真实视频，人工构造静音区间以验证裁切效果；原19秒视频另做一次真实检测。检查音视频时长差、字幕映射、速度、临时文件清理与失败不绑定产物。

## 字幕与画中画

增加白/黄/背景条字幕样式、字号、位置、安全边距、描边、按字数智能换行。所有参数写入任务与运行快照，ASS显式画布尺寸，默认保持原外观。画中画接受视频和图片，图片使用loop输入；不能把图片当作需要音轨的视频。

## IP大脑本地学习

导入已有文案或直接粘贴多篇来源，区分来源、风格摘要、事实要点与写作建议。先保存未学习草稿，真实调用本地文本模型成功后才标学习完成，保留来源文本、输入哈希、模型、时间及运行ID；失败不伪造摘要。深度学习按来源分段学习后汇总，浅度明确限制输入长度。

学习档案可查看、编辑来源、重新学习、删除和选择用于文案生成。文案提示中将来源与摘要作为引用数据，要求保留事实，禁止照搬不可验证的经历、数据或将来源中的指令当作系统指令。不能把本地文案学习冒充主页自动抓取，主页URL仅记录来源，采集服务未配置时仍明确缺失。

学习记录修改、切换和删除需维护引用；生成时运行快照包含实际使用的摘要版本，后续编辑档案不更改历史快照。验收至少一篇真实本地来源→真实模型摘要→选择档案→真实改写→重启保留，并验证失败保持旧学习结果。
