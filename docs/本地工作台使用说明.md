# 本地工作台使用说明

本机日常入口是桌面“超级IP智能体（本地）”，也可双击项目根目录“启动本地工作台.cmd”。它运行当前源码Electron；独立打包EXE启动仍未验收。桌面入口默认不打开调试端口。

日常数据保存在 `D:\我的智能体\超级IP智能体\workspaces\local-studio`。原 `data` 目录及此前验收目录保留。窗口关闭后草稿、素材和配置保留；重复打开入口会核对已有会话并请求唤起窗口。不要在软件运行时手工覆盖studio.json。

首次进入保留一份空白“本地创作”草稿，预选“C参考女声”和“示例2-夜间”。声音参考已经复制到该工作区；四个原有形象也在受管理素材目录中，日常使用不需要引用evidence目录中的样片或配置。形象身体和背景来自原软件已有示例，口型由本地MuseTalk实际生成；这不是从零生成新人物或新场景。

可按七步操作：输入原文或本地音视频，改写或直接填写文案，确认后进入声音生成；选择C参考女声并生成，再选形象生成视频；在网感剪辑中识别和校对字幕、选择模板并剪辑；编辑标题封面，最后检查发布信息。新建其他任务时请再次核对声音和形象选择。导出发布包不会上传；真实平台上传仍需登录和单独验证。

本机已配置Ollama的qwen3.5:9b-q4_K_M、IndexTTS2.5、MuseTalk1.5、已有Whisper small、Qwen3-TTS音色设计环境和媒体/字体路径。文字、标题及发布信息生成需要本机Ollama服务运行；模型环境在 `D:\AI-Runtimes\super-ip`。FFmpeg及模板字体目前使用本机原软件安装目录中的已有文件，移动或删除该目录后需要在设置中更正路径。当前入口依赖项目内的node_modules及已构建dist，移动项目或清理依赖会影响启动。

C是用户在已有候选中选定的相对基准，不代表所有新文案都听不出AI。自动转写需校对，自动标题和发布文字需核对是否添加了原文未提供的情境；声音与人物匹配、嘴周牙齿细节、长片质量、全部原版功能模板和UI交互一致均未完成。已有本地链路验收产物只证明实际生成能力，不作为这些质量项目的通过凭据。
