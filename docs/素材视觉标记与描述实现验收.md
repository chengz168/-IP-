已有本机 Ollama 模型 qwen3.5:9b-q4_K_M 声明 vision；目前没有已有嵌入模型证据。本批先验证真实视觉分析，不能用文件名或随机标签充当画面分析。

## 设计与影响

1. 新增独立素材能力模块，图片单帧、视频按15%/50%/85%抽三帧，限制画面边长后发给已配置视觉服务；记录模型、抽帧时间、文件哈希、实际返回和来源。抽帧只用临时目录，结束/停止均清理。
2. 视觉配置与文本配置分开；本机快捷填写复用用户已配置的 Ollama 模型，不下载模型。采用真实图片接口、结构化输出和严格字段校验；明确采样覆盖范围，不声称整段逐帧/声音分析。
3. 分析按素材去重，可停止；提交时捕获原描述、标签和文件签名，运行中编辑或删除/变更文件后不覆盖旧目标，执行记录保留模型结果。失败或取消保留已保存描述。
4. 素材详情、500字描述编辑、标记状态、搜索名称/描述/标签，分类和上传流程按原图实现。上传的本地文件先保存，标记失败可以编辑/重试，返回不删除已导入文件。
5. 向量状态显示实际记录。当前无可用嵌入模型时明确未配置，不能写入伪造vectorId。向量化和逐句匹配另有真实服务/成片验收后才关闭矩阵差距。

## 验收条件

真实19秒视频三帧和图片至少各一次本机推理，核对画面描述，不复用文本模型结果。验证描述500字边界、修改取消/保存刷新、分析中手工改字保护、重复拒绝、真实停止、无画面/文件缺失/服务失败不误标。两尺寸四字号覆盖库、详情、编辑、上传、标记与错误状态；查对齐、间距、菜单边界和页脚命中，并人工看图。只在全部最终修改后运行必要测试、构建、目录包与哈希，恢复原工作区完整JSON，不覆盖正式安装。

## 已知限制

原厂内部模型和提示词未知，不能保证输出相同；三帧分析不能证明整段内容都被识别。没有真实嵌入服务验证时保持“未向量化”，素材标记与手选画中画分别验收。
