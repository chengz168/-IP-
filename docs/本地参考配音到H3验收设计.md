# 本地参考配音到H3验收设计

沿用真实产品的声音生成与视频生成入口，先完成IndexTTS正常、高兴0.7和正常1.2倍语速三份独立推理、原生PCM统计、ASR正文与完整播放器验证。保留原始v2及中间v3候选，不混为最终版本，听感与音色相似度仍需试听。

后续在独立工作区选用本批最终正常配音作为驱动。人物参考仍为此前自主H3生成的虚构人物，只作为新推理的首帧输入；不能将已有视频当成本次生成结果。使用正式产品通用提示词、已有本地ComfyUI/H3权重与原有模型参数，不手改生产提示词为实验对白。

独立代理仅记录本机ComfyUI的实际HTTP请求、clientId、图指纹与返回promptId，记录保存在提交之前。真实“生成视频”按钮只点击一次；未知状态沿已保存clientId或promptId查询，不重复提交。声音推理全部结束后才启动H3，避免同时占用显存。原业务及既有验收文件保持SHA不变。

验收保留新视频输出SHA、完整解码、视频时长与帧数、实际驱动来源、ASR和音轨相关性，检查真实播放至结束、刷新绑定及下游原有剪辑入口。逐帧抽样只覆盖已查看画面，不能代替连续口型与听审；所有整体质量、原厂同输入一致性和完整复刻标志继续为false。
