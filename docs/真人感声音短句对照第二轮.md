# 真人感声音短句对照第二轮

用户要求：声音像真人说话，减少可察觉的合成感。当前不能承诺任何听众都无法辨别，也没有已通过的真人感音色。

本轮采用已安装的 Qwen VoiceDesign，通过产品现有“生成试听”按钮生成一个新短句候选。正文、语言、种子、长度上限与已有 chat 候选一致，仅简化 instruct，便于判断描述变化的效果。简化描述改善真人感属于待验证假设。音色本身也可能变化，不能声称保持同一说话人。

对照包含：上一轮 chat、新生成的简短聊天描述，以及已经生成的授权原声音色 IndexTTS normal。跨模型对照同时改变模型及音色来源，不能将差异单独归因于提示词。原声片段不作为新生成结果交付。

验收分开记录：真实推理及来源、完整解码、采样与削波、ASR正文核对、产品音频播放、人工听审。前五项不能替代自然度、人物匹配或声线复用验收。不预设自然度分数，不将未经听审的候选设为默认。

本轮仅增加验证脚本与证据，不修改生产代码或原默认，不新增模型下载。开始前检查无运行任务，保存原草稿快照及保护文件哈希；生成后核对原草稿及保护文件未变。单次提交先落盘意图和任务ID，超时只查询原任务。

证据目录：`evidence/validation/voice-design-20261115/conversation-v2`。技术检查结束后提供实际音频供听审；自然度不合格就保持未通过，不继续用该音色制作完整视频。
