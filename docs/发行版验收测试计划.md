## 核心用例与判定

| 领域 | 必测输入与动作 | 通过判定 |
| --- | --- | --- |
| 签发与验签 | 正确码、改payload、改签名、未知版本/档位、畸形编码 | 仅合法签名和合法结构通过，不使用HMAC，不接受未签名字段 |
| 硬件匹配 | 同机、不同机、仅两因子相同、缺失/占位因子、归一化变化 | 有效匹配达到2票；缺失不算相同；少于2项可用时中文拒绝 |
| 期限 | 默认永久、显式3650天、过期边界、非法天数 | null为永久；有限期真实生效；无3650天等同永久的描述 |
| 授权存储 | safeStorage不可用、解密抛错、损坏文件、重新激活 | 不泄露路径或堆栈，能正常开窗并重新激活；不退回明文 |
| 功能拦截 | 未授权/失效/缓存失败；导出、发布、批量提取、自动流程及直接IPC | 白名单严格受限；其余能力在副作用前拒绝；生产构建无环境变量/参数旁路 |
| 额度 | 本地/云端、并发、未知usage、失败3次、跨日、持久化失败 | 本地免计；云端不会负计数或重复扣费；熔断恢复可验证；失败不伪装成功 |
| 打包 | 配置schema、白名单/排除项、私钥、公钥、asarUnpack、fuses | 公钥可打包；私钥与出码工具不进入产物；配置检查不等于EXE验收 |
| 买家环境 | 文案就绪/缺失、其他能力缺失、跳过、重查 | 来源为真实探测；仅文案是开始创作前提；其他缺失给中文路径指引 |

### P1-A：云端文本默认输出上限未发给上游，预算与实际请求不一致

- 归属：负责人providers集成，后端额度模块协同。
- 证据：server/providers.cjs约50、60、62行。未配置textMaxTokens且调用不传maxTokens时，limit为undefined；云端body条件展开不带max_tokens，但预留使用limit或2048。
- 复现：在临时root构造真实Providers，文本协议compatible，填写测试地址和模型，textMaxTokens留空；调用text('s','u',{})；截获request体并返回合成usage.total_tokens=500000。
- 实际：request.max_tokens缺失；本次预留2050；结算tokens500000，usageRecord.status=succeeded、exceeded=true，超过默认日限200000后才被发现。
- 期望：每次云端请求都明确携带与预留一致的有限输出上限；未填写配置时使用明确默认值。可信usage若仍异常超预算，应留证据并阻止后续请求，不能声称单次费用已被预留严格限制。
- 影响：云端接口可能使用比预留更大的默认输出；后续拒绝请求不能追回已经发生的本条开销。这里500000是为验证边界而构造的回包数字，不是真实账单或模型实测能力。
- 建议回归：空配置、显式配置、单次覆盖三种情形同时断言实际请求max_tokens与预留；覆盖异常usage与后续拦截。

### P1-B：远程Ollama协议被直接视为本地免计

- 归属：负责人providers集成，后端reserve契约协同。
- 证据：server/providers.cjs约44、62行；server/usage-guard.cjs约6、110–112行，免计只看protocol，没有baseUrl或本机地址判定。
- 复现：真实Providers配置baseUrl=https://remote-ollama.example/v1、textProtocol=ollama、model=model；截获request并返回合成prompt_eval_count20、eval_count20。
- 实际：请求目标为远程https://remote-ollama.example/api/chat；结果usage为20+20，但同日账本requests=0、tokens=0，按local票据跳过计量。
- 期望：仅买家本机自跑能力免计；远程地址应按已明确的远端规则记录额度/失败熔断，或明确拒绝不支持地址。协议名称本身不能证明服务在本机。
- 影响：远端Ollama能力可以绕过当前日次数、token及连续失败计数；是否实际收费取决于买家接入的远端服务，本测试未作价格或账单判断。
- 建议回归：localhost/127.0.0.1/IPv6回环与远端HTTP/HTTPS分别验证，三次远端失败验证熔断；不要依靠前端选择器完成后端判定。
