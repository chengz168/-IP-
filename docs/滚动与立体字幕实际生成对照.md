# 滚动与立体字幕实际生成对照

日期：2026-11-15。上一批三套simple模板已实施，本批扩展六套：三行滚动、四行滚动、3D翻转、紫色滑块、红黄字幕、红蓝科普。全产品复刻仍为进行中。

## 依据与已确认规则

依据为 `evidence/validation/subtitle-template-runtime/reference/templates/subtitle` 的六份静态解码文件，以及TemplateBase、AssBuilder。全部只读解析，没有执行原厂模块。它们的字号依视频高/1080取整，横坐标按宽/1920，统一offset正数上移。

- 三行/四行：方正粗黑宋简体，活动45、非活动30；行距65、活动横坐标250、进入200、基线800，均各自缩放取整。小于10秒且为正的相邻空档才延至下一条start，逐字karaoke的厘秒均分并把余数依次分配给前面的字。三行为an1且每行绘制白粗边6和黑细边2两遍；四行为an7且每行一遍。四行额外显示后第二句。不能用统一高亮三行替代。
- 3D：月星楷，字号45、不加粗、an4、固定2px事件阴影。三句一组，前景分别y800/850/900，竖屏x520、横屏600；前景200ms移动并将fry12/fax-0.05变为0，160ms淡入。下一组开始时移到x-50、300ms将fry变-10、fax变0.5、缩至60%、alpha99，保留到再下一组开始。最后不足组按每行end+1.5秒计算转换，再保留2秒；不能直接在本行end裁掉。实际main.jsc如何处理变速尚未核实，本地按现有输入变速后再执行固定毫秒规则。
- 紫色滑块：方正粗黑宋简体，字号50/黑描边4。每个非空格字分别绘制紫底矢量矩形和白字两个图层；字宽依空格0.35、标点0.45、ASCII0.6、其他1.05倍字号估计。逐字间隔为duration厘秒/(字符数+2)，限制1至5厘秒，保留到行尾。
- 红黄：方正粗黑宋简体，字号50，七句循环。第二句24ms间隔/50ms淡入；第三句延下一end，第五句延后第二句end（存在才延）；第4/6/7句分别60/60/140%缩放，位置独立。
- 红蓝科普：三极行楷简体，字号50/白描边2，五句循环。前两句分别红/蓝逐字35ms间隔、60ms缩入；第一/第四句延下一end；第五句上移35、260ms落位。

三行/四行长字缩至75%下限，3D为70%，其他三种为75%，保留原版每模板宽度算法。ASS WrapStyle0保留。输入ASS控制符继续转义；补充平面字符保持完整，避免拆坏代理对。六模板的关键词开关已有支持，本批继续用经过原文签名校验的本地辅助关键词，映射原厂模板可识别的&H6CCBF3&色；原厂自动关键词提示词和调用链尚未取得完整证据，不冒认一致。

## 改动、兼容和回退

增加纯排版模块和共用ASS构建辅助；不复制运行原厂代码。已实现模板字体表扩为九项，正式生成按模板分流，元数据version2。预览使用同函数，3D演示三组、红黄七句、红蓝五句，其他六句；更新缓存版本。预览、任务摘要和自动流程沿用已有版本检查，使新升级六模板的旧产物需重剪，前三模板不误失效。其余13模板保留待核实，新增模块失败明确报错、不静默回退。
