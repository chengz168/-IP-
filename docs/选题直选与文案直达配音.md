# 选题直选与文案直达配音

2026-11-16，本批范围：当前页面列出选题供单选，使用候选文案后直接进入声音步骤。

## 交互和保存

- 选题生成后在原表单下方列出内容机会与五个选题，无选题弹窗。初始不默认勾选，整行点击和键盘均可选择。
- 未选题或资料已变化时禁用生成文案。保留换一批、字数限制、查看已有候选、返回选题。
- 候选文案仍在弹窗选择。使用后同时保存原稿、可编辑稿、最终稿及确认状态，进入第三步声音生成，不额外请求改写模型。
- 使用候选遵循已有内容检查及输入快照检查，保存失败回滚；新最终稿使旧声音和视频引用失效。
- 返回第二步仍可编辑，改字撤销确认；刷新服务端已保存稿件应保留已确认状态。普通 saveDraft 不能绕过撤销确认。

## 实际验收结果

- 隔离 Electron 使用本机 Ollama 的 `qwen3.5:9b-q4_K_M`，实际生成五个选题，选择第三个后生成两份候选；页面内单选、键盘切换、候选返回、输入过期禁用、取消后保留旧结果均通过。
- 点击使用候选后，实际进入声音生成，`step=2`、`confirmed=true`，最终稿与候选一致，未新增改写请求；刷新保留确认，返回第二步修改后仍须重新确认。
- 1400×1000 舒适字号与 1100×760 大字号检查通过：无页面横向越界，长列表可滚动，底部操作可到达，候选正文可滚动。选题 radio 实测为 18×18。
- 首次沿用日常模型参数（32768 上下文、8192 输出）在 180 秒后超时；仅隔离工作区改为 8192 上下文、2048 输出后生成成功。保留首次失败记录，未修改日常工作区的模型参数。
- 两份候选仍标为 `needs-review`，包含字数偏差及缺乏直接资料支持的表述提示；本批不将文案事实或口播质量判为通过，也未生成新的声音或视频。
- 全量 `npm test` 首次因测试进程找不到 FFmpeg 失败；仅在该进程加入已有 FFmpeg 路径后重跑，745 项中 742 通过、0 失败、3 跳过。跳过项为真实 H3 封装与两项有环境条件的下载测试。
- 整合后的 `npm run build` 退出 0；仍有构建产物体积警告。`git diff --check` 与相关脚本语法检查通过。
- 日常工作台已重开以加载新主进程和 preload，重开后只读核对当前任务、最终稿、模型上下文及输出参数均保留，新文件导入桥接存在。用户同期操作导致日常工作区有变化，不声称它的文件哈希未变；正式 `data/studio.json` 未由本批改写。

本机证据目录：`evidence/validation/topic-direct-selection-20261116/`，包含实际模型记录、两尺寸截图、`functional-report.json`、`full-tests.log` 和重开前后收据。声音拖放的权限原因与验证边界见 `docs/桌面声音拖拽修复验收.md`。
