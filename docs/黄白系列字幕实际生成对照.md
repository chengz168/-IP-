# 黄白系列字幕实际生成对照

日期：2026-11-15。本批延续九项原生规则，处理黄白裂开、黄白斜体、黄白书法、黄白跳动、黄底白字。依据是已只读提取并记录哈希的五份静态源码，不执行原厂模块。本批不以模板名称或通用动效近似替代其具体行为。

## 原版可核实契约

- 黄白裂开：东方大楷，sy50/描边sy5，四句循环，基线sy900。第一句逐字固定位置淡入，间隔按整句时长65%均分且至少40ms；第二句白字70→170→100%，layer1，上一句黄字拆上下两个clip，位移10/14为固定像素、裁剪高度280固定像素。第三句黄字从上方sy50移入且70→100%，第四句白字从下方sy50移入且150→100%。
- 黄白斜体：江城斜黑体、sy50/描边sy2、bold与italic。十句循环，第三句字号竖56/横60，其余50。2/3从左右画外移动进入，5/6/7三行叠字，9/10上下组合。2/6/9延下一end，5延后第二句end或现存下一end。安全宽按sx70左右边距及每句最大缩放计算，长字下限70%。各轴取整后再加减半行距并round，不能提前合并坐标。
- 黄白书法：三极行楷，sy50/style描边sy2、事件描边sy4，四句循环。白/黄上下两层clip采用固定60px范围；第一句130%模糊缩入；第二句白字居中逐步增长且延下一end；第三句黄白上下两色逐步增长，另有白色blur8光晕layer1；第四句按60%时长逐段长大并移动模糊，另有blur14拖影，保留原版同一事件同时含move和pos的标签顺序。
- 黄白跳动：思源宋体，六句循环，before按sy65（第五句竖78/横90）与各句横坐标拟合。render默认65，第五句按拟合值/65再乘大字号，保留原版这条运算。每字负字间距是固定-20px，不按比例缩放；不为了小图更好看擅改。每字依时长70%均分且至少90ms，只有纵缩放100→135→100，整句开始时所有字已显示。2/4延下一end。关键词使用有效本地辅助结果。
- 黄底白字：黑体，TypeBox/TypeText两份样式分别borderStyle3和1，sy50/背景边sy8、文字阴影sy1，基线sy840。逐步增长字符串，每阶段1至5厘秒，增长阶段末带竖光标，完整保留阶段不带光标。关键词仅继承有效原文辅助范围。

黄白裂开、书法、黄底白字长字下限75%；斜体/跳动70%。全部按1920×1080基准、字号按高/1080、横坐标按宽/1920；最终offset正数上移，clip/pos/move全部处理。用户ASS指令仍按文字安全转义，补充平面字符保持完整。
