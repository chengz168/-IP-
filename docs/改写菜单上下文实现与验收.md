## 当前证据与设计

原厂窗口198910/PID12548已重新确认。实际展开第二步的提示词和字数菜单，未选择或调用模型，证据`menu-fidelity-rewrite-*.png`。

- 字数菜单显示200/300/500/800/1000字和自定义六项，原图边界约y284–682，高398px；没有四行限制。

## 方案

1. DropdownSelect增加明确的rewrite样式上下文，六行、6px内距、文字居中；默认场景继续四行。高度依据实际宽度下的内容和边框计算，窗口不足时仍限高并向上避让。
2. 第二步提示词从原生select替换为同组件，正确显示资源名称、选择保存、键盘与ESC，历史模板ID不在列表时仍显示，不启动改业务值。
3. WordLimit支持显示标签与菜单上下文；第二步显示“字数”，无障碍名称继续“字数限制”。保持字数字符串和自定义协议。
4. 第二步控件按原图38px、两列参数与操作按钮等高。其余表单45px不改。
5. 实际代码核对发现旧textAction在模型返回后直接写当前任务，缺输入/任务/手工改写保护；共用text-input快照覆盖原文、模板内容、字数、已选分析、写入目标及任务ID。服务对已保存变化标记stale，页面再检查未保存变化；过期输出保留执行记录，不覆盖当前内容。成功重新改写清除旧确认与最终文案，停止失败保留旧文案。此项是实际功能缺口，不能只测试菜单保存。
