# 本地账号连接与发布前检查

2026-11-16。完整目标不变，上一轮C人物短片属于实际进展。本轮优先补齐发布链前置条件，不能把账号记录当作已登录。

现状依据：PublishPanel的立即发布仅弹未接入说明，service.publish固定失败；Resources保存账号时始终写unconnected，没有真实登录窗口。原版按钮台账181节确认平台选择、账号名称、显示名称及成功登录后可选择发布；尚无原版真实上传和登录成功证据。

候选已固定dreammis/social-auto-upload提交3847fff01f5434a8a32829833163cd6723cabc59，读取16份公开文件并逐文件核对Git blob及SHA256，MIT许可留存。候选的抖音登录判据包含creator-micro路径和可见登录标记；直接运行其上传命令会产生对外行为，本轮不执行。复用其公开平台入口及登录判据思路，使用现有Electron浏览器会话，避免另装候选整套Python/浏览器依赖。明确这不是候选CLI安装或其上传能力通过验证。

实现分为同一数据服务的账号连接管理、独立浏览器窗口、现有账号管理卡片和发布前只读检查。账号会话按工作区和账号ID隔离，密码/二维码由平台页面处理，不把cookie或storage导入业务JSON、日志及备份。仅抖音先接真实入口，其他平台如实显示尚未接入；不按仓库宣称支持便标记本产品已支持。登录判据必须有正确平台地址、无可见登录标记和正向创作者页面控件，页面空白或仅路径不能认成功。

账号保存过滤前端伪造的connection/status，连接状态由主进程页面观察产生；平台变更使旧观察失效。关闭窗口、重启、检查失败都不能保留假就绪。只读发布检查核对视频/封面实际文件、媒体流、文案、模式、所选账号和观察状态，返回可审阅清单，不进行上传，不记录published。

先回归缺少浏览器、空白/登录/正向页面、会话隔离、重复窗口、迟到观察、伪造状态和磁盘保存失败。再源码桌面实际打开平台登录页，检查未登录不会认成功，窗口关闭/重开与两个账号隔离、发布前失败/清单、刷新和真实按钮布局；最后构建/目录包核验，恢复原草稿及原账号列表。登录完成和真正上传需要用户在实际平台操作后另验收，不能自动通过。

研究错误：Node直连ECONNRESET；curl切换后遇已保存commit拒绝覆盖，改为沿原提交恢复；raw域连接重置，改GitHub API blob并校验。一次误用Windows通配路径rg已改目录搜索。未把这些失败当调查成功。
