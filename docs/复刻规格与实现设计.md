## 支撑模块

- 新/旧工作流：新流程分步，旧流程同屏多栏；共享同一任务ID、草稿与产物，切换不创建新运行。
- 声音管理：上传/录音、声音名≤10字、训练、语速/情绪、测试合成、音色库。训练必须有真实服务返回与模型ID。
- 形象管理：上传视频、名称≤10字、描述≤200字、形象库。复制至本地受管理目录，避免原软件提示的移动路径失效问题。
- 素材管理：分类、视频/图片、检索、标签、向量索引。未完成向量化不能标为已处理；关键词检索不能标为语义检索。
- 任务中心：任务统计、筛选、继续、详情与删除；记录输入快照、运行ID、时间与失败原因。
- 账号管理：平台、昵称、登录状态、凭据隔离。手工填写账号名称不能被视为已登录。
- 设置：主题、字号、默认视图、运行模式、输出目录、模型服务、提示词、备份/恢复、版本信息。

## 技术与文件职责（设计决定）

使用Electron桌面壳、Vue3组件、Vite构建、Node本地服务；页面与能力分层，便于真实浏览器验证与桌面验证复用。选择依据是桌面文件和媒体处理需求，以及可与现有Windows工作方式衔接，不是从参考软件源码推断。

| 文件/目录 | 职责 |
| --- | --- |
| `electron/main.cjs` / `preload.cjs` | 窗口、受限IPC、对话框、文件协议、加密密钥 |
| `server/store.cjs` | 本地任务、资源、配置，原子保存与备份 |
| `server/media.cjs` | FFprobe校验、FFmpeg渲染、音频抽取、缩略图、字幕 |
| `server/providers.cjs` | 明确配置的文本/TTS/ASR/口型服务，不猜测私有接口 |
| `server/runtime.cjs` | 不可变输入快照、任务状态、远程ID、取消/重试、日志 |
| `src/components/` | 标题栏、步骤栏、表单、媒体预览、封面编辑器、弹窗 |
| `src/views/` | 主工作流、资源、任务、账号和设置 |
| `outputs/` / `data/` | 实际产物与本地数据；不触碰原软件安装和数据库 |

数据结构：Project/Draft、Run/Snapshot、Asset、Artifact、ProviderConfig、VoiceProfile、AvatarProfile、BrainProfile、PublishAccount、PublishRecord。密钥与任务JSON分离；桌面通过safeStorage加密，页面只接触“已配置”状态。任务保存全部业务字段，重开后可继续。

## 执行、恢复与真实性

状态为draft→queued→running→succeeded/failed/cancelled/unknown；远程请求提交后立即保存ID，查询未知状态不能盲目重复创建。每个产物须存在、大小非零、可被媒体探针解析后才标完成。渲染写临时文件，完成校验后原子替换；失败保留错误与参数，清理不完整临时产物。重启时本地running任务标为中断，保留恢复入口，不能自动变成功。

服务未配置或输入缺失时给出明确可操作错误；禁止返回固定文案、假波形、空MP4、模拟发布成功。用户未提供模型服务时仍可进行本地文件导入、剪辑、封面、任务与发布包导出。

## 分批验收

### 按钮实操补充规格（2026-11-13）

1. 营销文案空提交实测要求名称或卖点至少一个，爆款选题要求行业/产品关键词；与教程差异以当前版本实测为准。自定义字数是生成目标，不得伪称严格满足。
2. 教程中的IP大脑包含主页学习档案、分析选题、候选文案和选用，不能只做档案保存。浅度与深度效果、实际采集范围及重试仍需实测。
3. T1–T10选择与视频预览是不同操作；模板可带标题、关键词高亮、动态字幕、配乐/音效，不能以改变字号颜色代替完整模板能力。
4. 素材内容分析、文件保存、向量化各自记录状态与错误；原软件本次分析成功但向量化失败，手选PIP仍可用该素材。自动语义混剪必须有独立匹配和真实出片验证。
5. 字幕编辑与样式编辑的取消实测保留当前编辑，PIP和镜头弹窗取消撤回分配；实现前明确各弹窗工作副本/当前值语义，不统一假设取消即回滚。
6. 封面选帧进度仅预览，点使用当前帧才应用；背景或文字修改将生成状态置为过期。新增文本是独立图层，双击改字、数值坐标、导出图像需要一致。已实测10.20秒背景和新增层写入JPG。
7. 原软件封面视频该样本只替换第0帧，第1帧恢复正文，保持573帧、原时长和音轨；后续实现至少用首两帧/帧数/时长验收，不继续默认1秒片头等同。
8. 下一步、编辑字幕或素材上传下一步可能隐含触发生成/识别/分析；仅切换页面与实际调用状态分别记录，不无条件自动重试。原软件算力、价格与私有协议未知。
