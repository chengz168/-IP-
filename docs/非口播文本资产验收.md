# 非口播文本资产领域验收

日期：2026-11-16。此次为用户新增非口播链路的领域与文本结构实现；不把接口 mock 当成真实图片、视频或质量验收。

## 关联与数据

- `StoryStudio({store, providers, runtime, media, generator})`；普通方法统一返回 `{story,...}`。旧任务没有 story 时按需初始化，不覆盖口播配置。
- `sourceMode` 为 upstream 或 custom；默认取已确认的 `draft.finalText`。`sourceHash` 为剧本文本 JSON 的 SHA256；`episodesSourceHash` 为 `[sourceText,episodeCount,episodeDuration]` JSON 的 SHA256。上游改文案或取消确认后，旧分镜的生成、选择、合成和交接入口均阻止继续。
- 默认 `narrationMode='none'`。单集 upstream 可绑定第三步声音；多集必须指定 `episode.narrationAssetId`，不擅自截取整条音频。合成输入为 `narration:null|{assetId}`。
- `save({id,story,revision})` 采用乐观锁，服务端保留既有候选和确认状态，前端通过 selectImage/selectVideo 明确选用。稳定 ID 支持手动增删改排和重新绑定。异步返回按目标输入 hash 比较，过期结果只保留历史，不覆盖新编辑。
- 资产变更只使引用镜头的图片、视频、合成失效；局部镜头改动只影响该镜头与所属集。候选 `status='ready'|'stale'`，生成成功不自动确认图片或视频。

## 文本与真实生成适配契约

- splitEpisodes 要求模型恰好返回指定集数，分集原文顺序拼接完整覆盖源文本；splitShots 每次只处理一集，原文完整覆盖该集，模型镜头 4 至 15 秒且总和等于每集参考时长。
- 中文 visual/action/camera/sound 保留可编辑描述，imagePrompt/videoPrompt 与资产 prompt 要求具体英文视觉描述，降低仅标题标签输入模型的问题。仍须实际画面验收，英文提示词不保证效果。
- extractAssets 使用模型临时 key 到服务端唯一 ID 的显式映射，并验证所有镜头 ID、绑定和引用完整性；不按名称猜绑定。
- `generator.image(input,ctx)` 接收 target、prompt、instruction、aspect、style、references（每项 assetId 为真实 Store 图片 ID）、inputHash/revision，返回 Store image；video 接收已确认 `image:{assetId}`、动作、时长等；compose 按选用镜头顺序传真实素材 ID 和时长。
- 失败的模型原始返回保留在 Runtime.failureOutput，成功原文在 Runtime.output。未知远程图片/视频阻止同目标直接重交；recover 仅查询原任务，恢复后追加候选，不自动选用。
- useEpisode 记录 `story.activeEpisodeId`，写入 video.assetId 与 edit.sourceId，归档旧字幕并清后续剪辑/封面/发布引用；不改 voice 配置。

## 执行锁与迟到产物补充

StoryStudio 专用写回与普通 Store 保持相同的发布、自动流程执行锁。执行期间新增锁时，迟到文本保留原始返回；迟到图片、视频和合成保留已登记素材及输入、候选证据，标记 `deferred:true`、`storyAttached:false`，不写入当前 story。已确认取得真实素材的写回失败携带 `remoteConfirmed:true`，任务记录为明确失败，不误归为未知远程状态。无旁白模式不采用残留的分集旁白 ID，避免旧音频混入。
