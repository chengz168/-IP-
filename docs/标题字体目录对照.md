# 标题字体目录与颜色字段对照

依据为原版实际菜单滚动截图、两次完整名称搜索，以及静态解码的标题渲染代码。菜单共观察到28项；原版前端直接使用字体接口顺序。主进程为字节码，未确认其目录生成算法，也没有取得接口完整返回值。

本批只适配标题菜单：已核对的本地字体使用原版显示名，保持接口原顺序和真实字体标识、family。存在本地目录时不混入其他系统字体；无本地目录时仍可选择系统字体。旧任务已选系统字体附加保留，未知用户字体保持原名，缺失字体显示名称并继续提示加载错误。

验收：28项名称/顺序/搜索选择、旧系统字体及缺失字体兼容、不改变字体ID与family；颜色有效提交/无效回退、刷新保存；两窗口四字号、色块对齐与横向溢出。使用隔离源码工作区，结束恢复原始完整数据并只读核对原版数据库。无新模型或视频调用；不把这一批视作整产品验收。
