# 非口播分集、分镜与资产创作

日期：2026-11-16。当前项目：超级IP智能体，基线 fbf0c6f。本设计针对用户明确新增的非口播制作链路。

## 用户流程和界面

第四步增加“非口播创作”入口，与单形象、多镜头口播共存。内部使用三个页签：分集分镜、资产图片、镜头视频。沿用当前界面的卡片、紫色选中态、间距和返回路径；不新建独立应用。

1. 使用当前文案，也允许填写非口播剧本；用户指定正整数集数、每集参考时长、画幅、视觉风格和补充要求。按指定数量拆集，每集有标题、内容和独立稳定 ID。
2. 逐集拆分镜头：镜头编号、对应原文、画面、动作、景别、运镜、声音和秒数均可编辑。改变排列不会改变镜头 ID。原文缺少的创作补充需明确区分，事实类不允许无依据扩写。
3. 从镜头提取人物、场景、道具资产，复用同一资产 ID，支持人工编辑与重新绑定。镜头引用资产 ID，不依赖名字猜测。资产图片存在候选历史，生成后待确认，用户可追加修改要求重生成或导入已有图片；失败不删除旧图。
4. 为镜头生成构图图：把所绑定资产的已确认图片及镜头内容传给支持参考图的真实接口。没有参考图能力时明确展示限制，不能把纯文本生成冒充参考图控制。镜头图同样可重做并确认。
5. 基于已确认镜头图、镜头内容和时长生成动态视频，保留候选和远程 ID。选用后可按镜头顺序合成当前集，交接第五步剪辑；多集分别导出，不擅自拼成长集。

## 数据与状态契约

`draft.story` 独立保存，旧任务缺失时按需初始化，不迁移或覆盖原口播配置。顶层字段：`version:1, revision, sourceText, episodeCount, episodeDuration, aspect, style, instructions, episodes, assets`。

- episode：`id, title, text, shots, resultId`。
- shot：`id, text, visual, action, camera, sound, duration, assetIds, imagePrompt, videoPrompt, images, selectedImageId, videos, selectedVideoId`。
- story asset：`id, kind(character|scene|prop), name, description, prompt, images, selectedImageId`。
- image/video 候选：`id` 为素材 ID，另记 `inputHash, createdAt, prompt, revision, status`。人工确认与技术生成成功分开。

文本拆分和资产提取使用已有 Providers.text。服务器对集数、时长、JSON结构、镜头资产引用完整性进行验证；不伪造模型输出。每次调用写 Runtime 的输入快照，模型原始返回可追溯。输入变化后旧结果保存为候选，不迟到覆盖新编辑。保存采用 revision 比较，防止渲染器旧草稿覆盖异步产物。

共享资产修改只使引用镜头的图、视频、合成结果失效；修改局部镜头只影响该镜头和所在集结果。重新生成候选不自动替换用户已选版本。未确认图、缺失绑定、过期视频、失败或远程未知状态均不能当作成片完成。

## 实施分工与阶段

1. 领域与文本链路：数据校验、拆集/拆镜头/提取资产、版本与绑定、单元测试。
2. 图片与动态视频接口：优先探测现有 ComfyUI 模型；云端可配置，真实调用前保持本地默认；下载新模型或付费另行明确。既有 MuseTalk 仅口型，不能用来冒充非口播动作生成。
3. 页面：分集、分镜、资产、候选选择、修改要求、生成状态和单集交接，旧口播路径回归。
4. 隔离产品验收：真实本地文本拆分、真实图片及局部重做、绑定校验、至少一段真实动态视频、顺序合成和完整播放。逐项标记技术验收与内容验收；不足的部分明确保留待验收。

## 验收和恢复

- 指定 2 集得到恰好 2 集；镜头原文可追溯，删改重排后绑定不串。
- 同角色跨镜头引用同一资产，选用不同图片版本可见并能定位受影响镜头。
- 图片重做只新增候选；失败保留上一版；取消和重启不自动重交；提交结果未知保留查询凭据。
- 当前集仅用按顺序选用且仍匹配输入的视频合成，缺镜头阻止合成，不用静态轮播伪装动态生成。
- 设置明确区分文本、图片、非口播视频模型。缺能力明确提示，不能出现假成功或只接按钮。
- 功能测试、构建和隔离实测之外，还需查看实际画面中的主体数量、资产外观、动作、构图和镜头连续性；技术通过不等于人物一致性或质量通过。

## 当前已核查的资源

本机模型目录可见 SDXL、Flux Schnell、Z Image Turbo、Wan 2.1/2.2 与 H3 文件；文件存在并不等于服务已启动或运行验证通过。已有文本模型为本地 Qwen；既有 H3 提示词写死为口播，需要专门的非口播路径。现有项目无独立分集/分镜资产图生成模块，不能直接复用原口播多镜头数据冒充完成。
