# 创作反馈学习

## 目标与实际边界

把用户对结果的明确反馈存成可复用经验，让之后相同类型、相同阶段的创作请求自动参考。它是本地经验检索和提示词适配，不是模型权重训练，也不自动改代码、替换模型或承诺作品质量持续单调提升。

原有 IP 大脑继续承担参考样本分析、风格档案、选题和候选文案；本功能补充生成之后的反馈闭环，两个来源都保留独立证据。系统提示词、制作技能库、原稿及确认稿不被经验编辑覆盖。

## 使用流程

1. 在当前创作阶段的“内容创作预设”中展开，点击“创作反馈与经验”，或到设置 → 创作学习。
2. 选择已有生成结果，核对来源摘录与适用范围，选择“纠正问题”或“保留优点”。
3. 写明可复用的表达或镜头偏好，保存后在之后匹配的任务中自动调用。可填入示例再修改。不要保存具体商品参数、人物身份或事件事实作为通用规则。
4. “已学经验”支持修改、停用、删除和恢复历史版本内容；“调用记录”显示经验版本及来源任务。

本入口只接受成功且未过期、未被质量检查拒绝的模型创作结果。用户确认其可复用偏好；运行成功本身不被视为质量认可。确定性范围拆集、取证、法务检查、翻译和封面标题不作为此入口的学习对象。

## 执行模型

- 使用现有工作区 Store，`creativeLearning` 是独立业务字段，不放进模型设置，也不改写系统预设。仅实际应用服务通过 IPC 保存；无需嵌入服务、额外数据库或模型下载。
- 选题、文案创作、改写、拆集、分镜、资产描述共六阶段。IP 大脑选题/候选、营销文案、商品脚本、参考视频新脚本、商品镜头优化也接入对应阶段。
- 通过创作预设、内容画像类型和阶段三项精确匹配；宠物与生活记录即使共用同一题材预设也不互串。手动类型及低置信度类型需用户自行核对，系统不会擅自替用户切换。
- 每次按更新时间取最近最多四条启用经验，各条4–300字，总库最多100条，避免无限上下文增长。编辑较早条目后也能进入近期调用范围。界面显示当前阶段匹配量。
- 经验是低优先级表达偏好。原有事实、当前任务要求、结构校验与输出格式优先。历史摘录只存本地来源，不随经验发送给模型。若规则相互冲突，应停用旧规则；不宣称已自动解决语义冲突。
- Runtime 在任务开始时冻结经验版本，Providers.text 在真实文本请求中编译附加；每次请求附加均留下版本记录。“附加到请求”不等于服务已收到、模型遵循或质量通过。中断、断网和生成失败仍保留原始运行快照。
- 已审核镜头、图像/视频原始生成、声音推理不附加未经审核的反馈。视觉偏好通过下一轮分镜设计进入创作；不会自动改变当前已审核设计或声音引擎参数。
- 不从未选用、重试、生成成功等行为推断好坏，不自动抽取私人事实、不自动训练或进行无人值守优化实验。

## 版本与恢复

新建/编辑/启停/删除都检查库版本，编辑单条还检查条目版本，避免两个页面互相覆盖。写盘失败回滚内存变更。每条保留最近十个历史版本；恢复旧内容产生新版本。停用、删除和暂停只影响后续任务；已有运行快照保留可审计来源，不随经验删除而消失。

## 验收要求

- 实际请求包含启用的匹配经验，暂停后新请求不含经验；旧记录保留原版本。
- 内容类型/阶段不互串；取证、法务、翻译、标题及声音/视频原始推理不误加经验。
- 并发变更被拒绝；重复反馈不重复入库；保存失败完全回滚。
- 通过真实应用入口保存、改版、回退并清理验收用经验；保留用户草稿、素材、声音、形象和模型配置。
- 真实模型内容对照要区分“遵循某条偏好”与“整体作品质量提升”，不得用自动测试或请求透传代替最终成片质量验收。

## 本批实际验证（2026-11-28）

- 通过实际桌面应用按钮调用已有 `qwen3.5:9b-q4_K_M`，对同一160字目标做三次改写：无经验、经验v1、经验v2。来源、参数、完整回复与实际请求均保存在本机证据目录。
