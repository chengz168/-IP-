# 拆集原文保持与质量复验

日期：2026年11月17日。此次以用户工作台内原有1131字符稿件在独立源码Electron、真实本地模型和正式按钮复现。没有覆盖日常草稿，没有将测试替身当作模型输出。

## 缺陷与改动

原实现要求模型在JSON中重抄全文，单集真实返回只有886字符，漏掉结尾245字符。旧完整性校验正确拒绝保存，但用户无法拆集。新实现让模型只选择原文单元的结束边界，服务端按原文切片恢复正文；单集直接保留全文，运行明确标为`modelExecuted:false`。严格边界递增、最后覆盖尾部、数量正确且逐字符完整后才提交，不通过时保留旧结果。

长稿分镜一次输出触及4096 token上限。现在先确定连续原文范围，再逐镜头单独设计；每次真实返回分别保留，整套完成并通过原文、时长、ID与版本校验后才一次保存。时长由程序分配为4至15秒且总和匹配。镜头整套重复画面/动作或出现分屏、拼贴时拒绝，不把分屏图冒充连续镜头。

资产仍由用户点击“提取 / 合并当前集资产”触发，模型自动识别并保存绑定；拆集完成不会自动执行图片或视频生成。已有实体复用必须使用原ID，拒绝同名同类重复创建或不一致的ID/类别，不能依据名称相似猜测不同实体相同。页面已明确解释触发顺序。
