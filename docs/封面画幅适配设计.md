# 封面画幅适配与验收

2026-11-17。真实非口播验收发现：1024×576视频的封面固定1080×1920，背景被竖裁；合成首帧时按保全画面缩放，出现左右大面积黑边。旧产物保留，不把该视觉缺陷判为高质量通过。

本次增加用户明确选择的三种画幅：竖版1080×1920、横版1920×1080、方形1080×1080，并提供“匹配视频画幅”。不在读取旧稿或切换视频源时自动改已有设计。旧稿、旧模板和新任务默认继续使用竖版；只有明确切换才重新计算当前图层、遮罩和装饰的位置，保留文字、字体、颜色、层次和绑定。坐标按对应轴归一化迁移，字号按短边比例保留，避免横向拉扁文字。

预览、鼠标坐标、内联编辑、模板缩略图、后台绘制与最终导出必须使用同一场景尺寸。后端依据当前已保存场景校验实际图片尺寸；任意尺寸、过期签名、写盘失败继续拒绝，不能只放开图片校验。已有任务失效规则保持：改变画幅属于改变封面设计，应解除旧封面与首帧视频引用，不清除原剪辑结果。

验收包括：三画幅模板与编辑坐标、旧稿不变、切换往返无文本/绑定丢失、图片尺寸不符拒绝、异步过期不附着、真实横屏源抽帧→横版封面→首帧视频→播放/解码/音轨核对，以及小窗口独立滚动。匹配只支持上述三种常见比例；其他比例保留用户选择并提示，不伪造任意比例自适应。横版背景原比例相同，封面和首帧不再因竖版布局引入左右黑边；内容构图仍需人工检查。
