# 资产生成连接错误与非口播流程修复

## 事实与问题
用户截图生成资产报 fetch failed。日常记录三次图片失败；本轮 GET 127.0.0.1:8188/system_stats 返回连接拒绝，未找到 ComfyUI 实际进程。已存在本机启动脚本及权重，先恢复既有服务，不新增模型。UI 对任何失败都给重新载入，缺少下一步导航，镜头制作主参考需要返回分镜。

## 实施范围
1. 本地请求中文连接诊断，任何图片提交前只读检查节点与模型。提交后结果不明继续保留 unknown，不自动重发。
2. 模型面板折叠时亦可检查，分别显示图片/视频连接和节点权重状态，详细 JSON 收起。
3. 当前集制作进度和可定位待办，资产确认、构图确认、视频确认、合成依次衔接；视频页就地设置绑定/主参考。
4. 用已有本机服务真实生成资产图；候选不自动认可内容质量。保留日常数据，更新原桌面入口，构建包只读核验，提交授权远端。

## 验收清单
- 服务关闭、无权重、服务就绪三个分支；错误不诱导丢弃编辑，不自动提交。
- 提交前失败无 remote，无 unknown；提交后回包丢失保留凭据并只查询原任务。
- 当前集/多集待办、共享资产定位、就地绑定、主参考切换、旧候选失效。
- 真实产品按钮资产图片成功；审查尺寸、主体、内容，不把产物存在当质量通过。
- 1400×1000、1100×760 无横向溢出和遮挡；窄屏长错误换行；修改刷新持久化。
- 定向测试、全量回归、build/pack；备份并正常重开日常，业务哈希核对；commit/push 核远端。

## 本批实际结果

### 连接与执行语义

已使用本机现有启动脚本恢复 ComfyUI 8188 服务，没有新增模型下载。通过独立源码 Electron 的真实按钮生成一张 768×1344 猫咪资产图片，预览后明确选用。另将隔离工作区地址改为未启动的 18189 端口，实际按钮失败返回中文连接错误；记录为 failed、无远程任务 ID，没有“载入服务器版本”按钮，编辑内容保留。恢复 8188 后检查正常。

图片任务对 SDXL、Z-Image 都在上传和提交前检查节点、权重。明确的提交前错误不登记为远端状态未知；提交后回包丢失仍保留 unknown，只查询原任务，不自动补发。权重缺失及提交状态分支同时有定向回归覆盖。

### 调整后的制作顺序

1. 在第二步确认最终文案，或选择独立剧本；指定集数后拆集，再逐集拆分镜头。
2. 提取、检查本集人物/场景/道具及镜头绑定，生成或导入资产图；预览后明确选用。
3. 逐镜头确认首帧。镜头视频页可以直接修改绑定和本地主参考，不必往返分镜页。
4. 使用已选首帧生成动态视频，预览后明确选用。
5. 按分镜顺序合成当前集，检查后点击“使用当前集，进入网感剪辑”；继续剪辑、封面和发布流程。

工作台显示五阶段完成数和具体下一待办，自动定位缺少的资产、镜头首帧、视频或合成区。导航不代替生成或人工确认；资产改动造成下游版本失效时，历史候选保留。多集分别制作与合成。

当前 Z-Image 仅支持文字生图，不能使用绑定的视觉参考；界面提前提示切换支持参考的模型或选用已有首帧。本地 SDXL 只使用一张主参考，其余绑定传文字，不承诺多人物外观一致。

视频请求现同时传入当前画面、动作、运镜和声音字段，避免非空旧高级提示遮蔽当前镜头编辑；回归测试验证这些字段确实进入生成请求。
