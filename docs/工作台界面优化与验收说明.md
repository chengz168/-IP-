# 工作台界面优化与验收说明

日期：2026-11-27。范围为工作台样式、导航与键盘交互，不包含新的模型推理或生成内容质量验收。

## 用户可见变化

- 常驻左侧导航直接进入创作、任务、声音、形象、素材、账号、设置和帮助；保留旧工作流入口。
- 创作步骤集中在顶部，底部保留状态与上/下一步，不再重复展示同一页面进度条。
- 工作台统一深色蓝灰表面、蓝色主操作、卡片边框和间距、键盘焦点与滚动条。
- 任务表在窄窗口下保留表内滚动并固定操作列；资源卡片和素材分类支持长名称换行。
- 非口播模型配置保持折叠，首次未检查时减少空状态卡片；实际检查结果仍按原规则显示。
- 弹窗优先处理 Escape 和焦点，全局快捷键不越过弹窗新建任务或触发页面级保存。

## 业务保持条件

步骤仍调用原有 moveWorkflowStep：先保存子编辑器与主草稿，再切换。非口播/商品从视频生成进入剪辑，仍经过当前集交接。交接失败停留原步骤，不能沿用旧视频跳转。

入口继续使用 App.vue；未采用工作区中另一套直接修改 draft.step 的控制逻辑。已有未跟踪的其他重设计文件保留在本机，本批未整体合入。

## 复用判断

调研使用专用 Google Chrome，会话仅连接回环 CDP。核对 Vue 官方生态中的 vueComponent/ant-design-vue 仓库及 MIT LICENSE。项目已有 ant-design-vue 4.2.6，当前导航和样式问题使用已有 Vue 组件与 CSS 即可，未增加依赖、升级组件库或下载模型。GitHub 代码搜索要求登录，因此未声称已通过搜索找到可直接接入的代码。

已采用本机 ui-ux-pro-max 和 playwright-interactive 技能进行设计与验证。设计数据库中的工具界面、焦点和对比度建议作为参考；营销落地页结构不适合本工具，未采用。
