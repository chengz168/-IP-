# 中文镜头与内容创作预设

## 本批设计与验收

用户截图仍是历史镜头的英文 visual/action/camera。新增脚本的中文约束不改写历史内容；把它称作全部中文化不准确。

1. 历史英文使用独立中文译稿：原字段和已生成媒体保留，按源字段指纹显示有效译稿；文本更改后旧译稿失效。支持当前镜头和当前集批量转换，转换只译原意，不优化剧情；失败/取消不写入半份译稿。用户主动编辑中文镜头时继续走原设计保存与媒体失效规则。
2. 内容创作预设独立于既有原厂提示词库。系统预设不可由项目改写。任务保存自动/手动选择与补充要求；每次生成冻结预设版本、来源、选择理由与实际阶段规则。
3. 先覆盖商品介绍、知识讲解、操作教程、测评对比、故事叙事、数据解读及资料不足时的通用表达。按明确流程上下文和透明关键词规则路由；证据不足降为通用而非假装理解。用户可覆盖推荐或关闭。事实约束和当前阶段输出契约优先。
4. 实际接入选题/文案生成与改写、参考拆解后的创作稿、商品脚本、非口播分镜、商品单镜优化和视频指令编译。预设只在对应阶段注入，不能把短视频创作技巧当作原软件私有提示词。
5. 来源先读 SKILL.md 与许可证，保存 URL/版本/哈希，仅读取公开资料，不执行第三方脚本。本地化规则为项目编写；未核实许可的第三方全文不随包分发。

## 验证与恢复

- 旧英文当前镜头/整集转换、新英文拒绝、译稿来源变化后失效；不改变原文与媒体选用，取消和过期拒绝写入。
- 自动路由至少覆盖六种内容、混合/资料不足、手动覆盖/关闭；阶段不匹配不注入，预设变化使待选文字候选过期。
- 真实软件操作旧稿转换与商品脚本生成；核对生成调用内实际存在预设快照及规则。两窗口视觉检查推荐、规则和错误态。
- 内容质量另行审看；提示词更长、模型成功或播放器成功均不等于内容质量通过。
- 适当回归和构建后备份业务、检查活动任务、正常关闭与原入口重开。保护既有草稿/素材/音色/形象/模型配置，核对远端提交。

## 实测质量边界

真实本地模型首轮脚本返回成功，记录明确含商品预设、版本和实际system请求。但人工审看发现展示花瓶进入旁白、猫咪抓握表述不当、部分动作与机位冲突、15秒旁白过长，不接受为高质量结果，未选用。已据此加强商品提示：商品/道具分离、材料不扩推具体部件、动物动作符合结构、固定机位不混推拉、依据用可读中文、明确总字数预算。预设只能改进约束，不能保证模型遵守或达到广告成片质量。

本轮没有取得对标软件私有提示词，也没有把Remotion阅读资料写成已接入视频引擎。未知英文品牌不能无歧义全识别；未收录且未标明品牌/型号身份时，中文校验采取保守拒绝，原设计继续保留。

### 真实输出后的限定纠正

商品脚本增加可明确识别的检查：按目标时长每秒3字的中文旁白预算、依据不得直接显示JSON路径、全部镜头显式静态时须补充可执行的主体动作、固定机位不得同时推拉平移。首次不符合时，连同原响应与具体问题限定纠正一次；仍不符合则失败并保存两次响应、保留旧稿。此检查是透明规则，不能替代事实核查、完整运动语义理解或成片审看。局部静止而其他部件运动可通过，不要求每镜必须运动。

中文真实复测：当前任务两个英文镜头重新转换成功，一个原中文镜头跳过；再次整集转换返回0转换/3跳过。首帧摘要、动作、运镜与声音均通过真实DOM核对，未残留普通英文。原始设计不变，保留英文原文核对入口。

真实限定纠正第一次验收：初稿触发检查，限定纠正后仍75字超过15秒45字预算，实际软件正确失败并保留旧稿，两次模型响应均留记录。随后将每镜text的maxLength和每镜字数预算写入结构请求继续复验；不能把失败拦截称为内容质量通过。
