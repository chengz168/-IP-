# 内容类型与实际成片验收

目标是让短视频链接、商品链接和参考素材在同一七步流程内创作，并按内容选择制作方法。十类画像是目前实现的路由目录，不是“所有类型均已高质量完成”的证明。下表仅登记本批实际覆盖，既往证据需单独复核后登记。

| 类型 | 成片验收重点 | 本批实际覆盖与状态 |
| --- | --- | --- |
| 口播表达 | 本人身份、自然配音、口型、表情和背景一致 | 使用用户选定的C音色生成了新音频；本批未新增真人口播整片验收 |
| 商品宣传 | 真实外观、规格卖点有依据、产品动作及原图关联 | 猫砂器具演示动态镜头具备动作，但接砂盒新增筛孔，外观保真未通过；不当作全品类商品验收 |
| 操作教程 | 前提明确、动作顺序正确、每步可执行 | 筛砂→移到接砂盒→倾倒的单镜链路已走通；自动文案与标题经过人工审校，不算全自动质量通过 |
| 知识讲解 | 事实来源、适用范围、图文一致 | 本批未新增真实成片验收 |
| 测评对比 | 同口径比较、依据与结论对应 | 本批未新增真实成片验收 |
| 数据解读 | 数字、单位、时点、图表和来源 | 商业航天链接批量提取途中通过软件正常停止；该项只验证取消，未完成成片验收 |
| 故事短剧 | 人物、服装、场景、道具和事件连续 | 已有分集分镜契约；本批未新增多人物短剧成片验收 |
| 生活记录 | 具体真实观察、资料与镜头关系 | 本批未新增完整生活记录成片验收 |

## 已核实的链路与待解决问题

实际技术链路在独立任务完成，未覆盖旧任务，未将原参考视频片段冒充新生成镜头。H3输入为原视频提取的单张首帧，输出为本地新生成视频。配音、合成、剪辑、封面及导出均通过现有软件操作完成。

画面分析使用12张采样帧，不能称逐帧理解。9B视觉模型将接砂盒误称铲子；模型自动标题“筛掉结块”不符合实际操作含义；字幕识别有错字。上述问题分别保留原结果与人工校正凭据。新模型、更多提示词或更多预设尚不能保证解决这些问题。

最新发布包为workspaces/local-studio/outputs/publish-1795364520957，封面采用真实可用的V3系统字体版。该包视频仍是同一外观未通过的动态样片，不能因封面更新改变内容质量结论。本批已经更新正式本地入口并正常重开，PID24200，无远程调试参数，数据完整SHA前后一致。

下一批依次验收：参考物体识别与资料确认；资产描述和参考图的一致性；商品形状和动态动作；文案、标题和字幕的含义一致性。每条成片需登记可播放文件、实际输入、执行记录、人工修改、外观问题和质量结论，再扩展类型覆盖。模型不可用或资料不足必须显示原因并保留当前编辑，不生成伪造成功记录。
