# 学习转写校对实现与验收

2026-11-14。上一轮分类progress。实际ASR已把“便签”疑似识别为“变迁”，而视频学习没有在保留来源的同时修正文案的入口。本批补可实际使用的校对流程；不将新增入口声称为原厂按钮或像素一致。

## 设计

1. 沿用IP分析弹窗，增加“校对转写”入口和同宽编辑弹窗，显示原视频、逐句时间范围和可编辑文本，支持定位播放本句。仍须用户实际核对音轨，不把机器播放当听觉验收。
2. 保存时只调用文字风格分析，不重复ASR/视觉。原始transcription和视觉回包永久保留，人工修正另存reviewedTranscription及源文件哈希/时间/原版本；时间边界沿用原分段，不冒称逐字重对齐。
3. 同时核验档案revision、当前任务输入、源文件字节和模型配置。停止、换任务输入、换源、并发和写盘失败不覆盖原档案；失败保留新输入/模型原包。校对后重新生成分析并更新revision，清除该档案旧选题/候选；既有任务正文不被自动替换，其他任务的固定快照仍保留。
4. 已校对档案再次普通学习，沿用同哈希的人工文字并重新观察需要的画面；不静默恢复成旧ASR错字。文件变化则明确失败，要求重新选源识别。分析弹窗分别显示当前学习文字和原始ASR，避免混淆。
5. 不调用原厂、克隆、口型、付费或发布，不下载模型、不改变原配置。未知远程学习仍拒绝重交；自动运行任务不可手改。总目标active。

## 验收

后端覆盖真实来源保留、不可伪造时间边界、旧选题失效、任务快照、并发/停止、文件/配置/版本变化和写盘回滚。桌面使用已有真实视频/转写，验证播放定位、空值不提交、取消不改、校对后真实新分析/刷新/再编辑、实际停止留旧及失败后草稿保留；两尺寸四字号校对/分析/展开原转写布局。最后测试/构建/目录包和完整原工作区JSON恢复。内容质量、全部原厂功能/样式仍独立验收。

## 调查记录

现有BrainStudio只有只读转写，重新学习始终重新ASR；brain-topics/copies以档案revision保护，能复用清空旧结果的方式。尝试读取两个猜测的current-output/workflow-current路径失败，实际应按rg --files定位workflow-state等文件，不按猜测修改。UI建议采用字段旁错误、保留输入与明确标签，保持原深色视觉。
