# 单镜提示范围与重影修复

用户反馈AI收入主题试片模糊。原始第三镜6.5秒与成片29.375秒对应帧均出现同样人物、电脑及背景重影；分辨率为1024×576，不能以升分辨率或锐化冒充修复。

第一轮相同首尾图约束后主体清晰度改善，但生成镜头仍插入电脑画面。运行凭据显示：局部英文编译只描述人物胸像，后续又重复附加整集办公剧情、共用电脑资产及“中景和近景交替”。该冲突不能证明全部重影根因，但属于可复现的单镜提示范围缺陷。

修复仅作用于中文镜头编译：从style及storyInstructions的有效副本中剔除明确整集编排、共享资产清单和跨镜景别切换；保留局部画面、动作、声音、原文否定、普通全局一致性要求及有硬性约束的混合句。全片主题和统一道具不会按编排删除。本镜明确排除电脑或屏幕时，再移开全局的正向屏幕内容描述，保留同句后面的文字禁令。源文与省略内容同时保存在promptCompilation，草稿不变。编译版本7，旧任务查询仍沿用冻结输入。规则匹配不等于通用语义理解，未匹配表达不会擅自改写。

开发前复用检查：实际Chrome访问GitHub搜索及MiniMax-AI/MiniMax-H3固定提交199b7d0e1fd95e7b3eafa8c15eca692534142427的首尾帧提示词指南。LICENSE路径未返回许可文本；本次不引入该仓库代码或新增模型，继续使用已安装H3和本项目适配器。

验证：补充句中否定、混合硬性约束、普通全片主题、统一道具以及屏幕排除边界后，范围、原文保留、全局要求、旧任务恢复及编译版本共31项通过（退出码0）。

实际画面：第一版首尾帧候选仍插入电脑，因此拒绝。第二版采用编排过滤后，人物和背景稳定，但中段生成文档窗口遮挡人物，因此也拒绝。第二版实际输入仍含“屏幕为模糊的块状文档”，进一步处理此明确冲突后，同首尾图、种子和时长的第三版候选在每秒4帧抽检中未见电脑插镜、文档窗口或持续重影；3.5秒、6.5秒全尺寸核对及全程解码也通过。该镜采用固定胸像、小幅呼吸眨眼，改变了原第三镜转头动作，未使用锐化或放大来冒充修复。

第三版通过真实应用的镜头选用、整集合成、网感剪辑、封面保存和导出动作回接原片。最终36.5秒、1024×576、24fps、H.264/AAC；原文案、C配音和26条字幕保留。实际应用完整原速静音播放到结尾，播放器报告丢帧0；FFmpeg全程解码退出码0。临时H3设置恢复为用户原设置，旧草稿和原媒体保留，本地实际应用已重启加载修复。

质量边界：本轮只完成第三镜持续重影的针对性修复。其他镜头仍有短叠化和手部、屏幕细节问题，当前1024×576输出不代表1080p或实拍画质。此为助手视觉核验与技术检查，没有标记用户人工验收。完整试片、逐镜对照、失败候选及调用记录保留于本机证据目录，不提交媒体或工作区数据。
