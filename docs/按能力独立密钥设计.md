# 按能力独立密钥最小设计

日期：2026-11-17。范围：配置、密钥存储、请求鉴权与隔离验证，不调用真实云服务。

现状已查证：Electron仅以safeStorage加密保存provider-key.enc；浏览器预览仅保存进程内全局密钥；Providers.headers()、模型发现和非口播图片/视频桥共用该密钥。不同云服务商无法分别配置凭据。业务studio.json和运行快照当前不应保存明文密钥。

## 数据与兼容

保留全局密钥作为旧配置回退，新增text、vision、tts、asr、image、video、avatar、clone、extract、brain十个独立作用域，分别覆盖文本、素材视觉、配音、识别、非口播图片、非口播视频、数字人口型、声音克隆、链接提取和主页文案采集。每次调用优先本作用域的独立密钥，未设置或明确清除后回退全局。各作用域不相互回退；本地Ollama、Windows、Whisper、IndexTTS、MuseTalk、ComfyUI原本无需密钥的路径不读取云密钥。

Electron新增provider-keys.enc，由safeStorage加密完整字典并以临时文件替换，所有密钥一次提交。新文件不存在时只读兼容旧provider-key.enc，不自动迁移、不清除旧文件；第一次明确保存后写入新文件，之后以新文件为准，包括明确清空全局的状态。safeStorage不可用则拒绝写入，不落明文。浏览器预览使用同契约的内存存储，关闭服务后消失。

saveSettings仅接受顶层key（旧全局字段）与capabilityKeys（本次明确修改的作用域字典），不把这两项并入settings.provider。只提交修改过的条目；未编辑条目保持。state只返回keyConfigured和capabilityKeyConfigured布尔状态，不返回值。旧测试或集成只实现get/set时仍支持全局读写，但独立密钥保存必须报不支持，不能静默写回全局。

## 界面与请求

模型设置增加统一的“服务密钥”区，保留原全局更新入口，并逐项显示独立密钥状态。独立输入默认为“保持不变”，用户明确选择“设置独立密钥”或“清除并沿用全局”后保存；设置独立密钥但内容为空时显示字段错误，不把误留空当清除。保存成功清空输入。模型发现读取本能力已保存密钥，或该能力明确修改的临时草稿；清除草稿回退本次全局草稿或已保存全局，不意外继续使用旧独立密钥。

Providers.headers(capability)统一路由。文本、视觉、TTS、ASR、克隆、各服务桥和远程任务查询分别传能力；StoryGenerator图片生成/编辑及其同源下载传image，视频提交/查询/同源下载传video。跨源媒体下载保持不带服务密钥的行为，避免把不同服务的凭据发给下载站；数字人口型同源策略同时补齐，历史查询缺基址时只保留已有查询源为依据，不在记录中保存任何密钥。

## 验收与失败恢复

定向测试覆盖旧密钥兼容、独立优先/缺省回退/明确清除、加密存储不可用、原子替换、白名单拒绝、state/studio/backup/运行快照不含凭据、模型发现临时草稿与本地不读密钥、各实际请求入口正确鉴权和跨源不携带密钥。真实Electron使用新的独立工作区：实际设置保存全局及独立测试值、重开确认布尔状态、清除独立并重开确认回退、检查加密文件存在且studio与回执不含测试值。所有测试值仅内存生成，不打印、不截图明文，不调用云或GPU。

失败不得清空旧配置；业务设置写盘失败时恢复原settings及本次更改的密钥，回退值只保留在内存闭包；若密钥回退也失败，明确提示核对而不冒认成功。不改日常workspace。不把模拟请求路由测试或密钥存储验收称为真实云生成验证。源码窗口和日常安装包分别标识，真实模型效果保持原验收状态。

并发入口补充：`saveCoverDefault` 与 `saveSettings`、`saveAppearance`、`saveStoryModels`、`restoreBackup` 共用设置互斥。已在隔离夹具复现：密钥写入等待期间若允许默认封面保存成功，随后设置写盘失败的整份回滚会抹掉内存中的新模板，后续保存还会覆盖磁盘。现在事务期间默认封面保存明确返回“设置正在保存，请稍候再试”；原事务失败后恢复原设置及密钥并释放入口，用户可重试保存默认模板。定向测试核对并发拒绝、失败后原内存和磁盘保持，以及非并发模板正常落盘。
