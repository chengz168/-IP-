# 动态字幕模板实现与验收

日期：2026-11-14。整体完整复刻目标仍进行，22模板必须有真实渲染，不能用卡片、静态换色或测试通过代替实际效果。

## 依据

新版参考软件为两列内嵌卡片，黑底动画小样持续播放，点卡片即时选择并让已有成片过期，没有独立“确定”弹窗；旧工作流T1–T10另属一套功能。面板顶部模板/自定义分段、关键词高亮，底部上下位置。实点3D翻转后自动开启关键词高亮。

scripts/inspect-reference-subtitle-catalog.cjs仅解析原包公开renderer的标签和配置字面量，不运行原厂模块。实际22项、字体/字号/颜色/动画参数与15项关键词支持名单在evidence/reference/dynamic-subtitles/catalog.json。此元数据不证明正式视频效果，仍需逐模板实际动画/字形和同源成片对比。

## 实现

1. 独立字幕模板模块保存公开参数；ASS引擎独立实现逐字进场、缩放、跳动、滚动、翻转、滑块、描边配色、双语与注音。正式导出及卡片动画样例共用引擎。样例本地生成并缓存，不依赖原厂后台或GIF服务。
2. 字体读取已有系统目录和可选本地目录。缺少模板字体明确提示，不伪称已经使用原字体。必要的字体设置可指向本机原软件已有fonts目录，只读该目录；这是为可用性保留的有意设置改动，临时任务与原任务另行核验。
3. 模板选择采用独立subtitleMode/subtitleTemplate字段，保留旧任务和自定义配置；只有选择模板后使用新引擎。切换/改参数使旧结果失效，模式、关键词及位置落盘恢复。
4. 注音使用本机已安装pypinyin，逐字对齐并校验。双语/关键词优先使用用户已填数据，否则只调用已配置的本机文本服务；没有配置时给出可操作错误，不发起云端调用、不伪造译文或关键词。文本、时间轴和任务在处理期间变化时不覆盖新编辑。
5. 字幕编辑器按需提供译文和关键词编辑；自动生成的辅助文本保存来源文本，用于文字变化后的失效校验。
6. 媒体渲染维持剪口、倍速和取消行为。产物记录实际字体、模板、辅助文本和渲染字幕，能追溯执行配置。

## 验收

- 新建本地独立任务；保存原任务与业务基线，不为观察而生成原软件付费结果；研究结束恢复原软件选中模板/自定义模式并核对差异。
- 22模板真实输出、抽帧与播放；缩放/位置/滚动与逐字动画需检查不同时间的画面，双语必须有真实译文，注音检查逐字对应。
- 原生桌面实际点选、切换自定义、关键词规则、位置调整、取消/确认、刷新恢复；两窗口四字号检查卡片、滚动、控件对齐与按钮实际命中。
- 验证缺字体/缺本机模型/缺译文/错误JSON/文字变化/取消等失败与恢复。保留失败证据，不把自动化观察超时当作任务已终止。
- 按产品改动运行必要测试、构建、目录打包和内容核对；独立EXE启动仍受此前审批拒绝限制，不能绕过或冒称已验收。

本批即使完成独立实现和列举验收，仍须逐模板对照原厂同源成片；不以参数相同推断像素和全部动画时序一致。

## 本轮实际实现与收据

- `server/template-subtitles.cjs`独立实现22项ASS排版与进退场、逐字、波浪、滚动、翻转、拼音和双语。真实读取字体名称及字宽，不通过原厂后台渲染。缺字体、缺辅助文本和已过期辅助文本明确失败。
- `server/subtitle-template-preview.cjs`串行生成并缓存72帧GIF，使用同一引擎竖屏排版后裁取字幕区域。界面两列等宽卡片、10px间隔、模式分段边框、选中态、关键词支持规则、位置与默认按钮均有实际交互证据。
- 字幕编辑提供手工译文和关键词；逐键输入逗号不会被过滤，重新生成关键词时清除旧输入原串。改字使旧辅助文本失效，模型期间改字幕不覆盖新输入。现有本机9B的翻译、关键词提取及取消均已实际执行。
- 注音使用独立`subtitlePythonPath`，默认系统python；不错误复用ASR虚拟环境。已有系统C:/Python314/python.exe内pypinyin0.55.0已实际使用，未下载模型。真实设置保存/刷新/显式配置后剪辑也通过。
- 22项各生成4.8秒可解码正式视频、三张解码帧及ASS。另在真实8秒带音轨源视频上裁去2.988687秒静音并按1.25倍速输出4.033333秒注音视频，字幕时间及逐字注音对应重映射后的条目。
- 最新60/60回归测试通过（2482.5397ms，退出0）；既有Node模块类型警告仍存在。最终构建3198模块，JS299.04kB、CSS110.67kB，3.54秒，退出0。
- 独立桌面业务工作区为evidence/validation/dynamic-subtitles/desktop-workspace；原桌面完整业务JSON另有基线核验。原厂则经UI恢复自定义模式，隐藏templateId由null变为simple_yellow_white和updated_at变化仍有残留，不能称原厂数据库完全恢复。
