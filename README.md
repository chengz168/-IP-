# 超级IP智能体

Electron + Vue 3 的本地视频创作桌面工作台，提供链接文案提取、文案改写、声音生成、数字人口型、字幕剪辑、封面和发布素材导出。

当前版本为 `0.1.0`。**完整复刻轻语IP的目标仍在进行中，当前仓库不是全功能或效果一致性的验收声明。** 测试通过不能替代内容与视觉质量验收。

## 安装与运行

需要可运行当前依赖的Node.js、npm，以及Windows桌面环境：

```powershell
npm ci
npm run build
npm start
```

本机已初始化的日常工作区使用 `启动本地工作台.cmd`，读取 `workspaces/local-studio` 并使用该工作区独立的Electron profile。尚未初始化时会拒绝启动，避免覆盖已有数据。`启动超级IP智能体.cmd` 和 `npm start` 是通用源码入口，默认数据目录与日常工作区不同。

浏览器开发预览使用 `npm run dev`。不要让多个服务同时写同一数据目录。运行目录由 `--studio-data-dir=绝对路径` 指定；源码通用入口未指定时使用 `data`，打包程序使用Windows用户数据目录下的 `studio`。

## 真实生成配置

仓库包含模型桥接和执行逻辑，不含模型权重、Python环境、声源、数字人素材或账号凭据。迁移机器后需在设置中填写实际可用的本地环境或服务：

| 能力 | 接入路径 | 配置和验收边界 |
| --- | --- | --- |
| 文案、标题 | 本地Ollama或已配置文本服务 | 地址、模型和上下文窗口需与实际服务匹配 |
| 文案提取 | 本地链接解析器与Whisper，或识别服务 | 受链接、网络和平台验证影响，不保证任意链接免验证成功 |
| 配音 | 本地IndexTTS、系统朗读或TTS服务 | 克隆需参考音频；系统朗读不等于声音克隆 |
| 新音色设计 | 本地Qwen3-TTS VoiceDesign桥接 | 与参考声音克隆是不同路径 |
| 数字人口型 | 本地MuseTalk或口型服务 | 本次实测驱动嘴部；身体与背景沿用素材，动作可循环 |
| 字幕剪辑 | FFmpeg、FFprobe和识别/字幕渲染环境 | 配置实际工具和字体路径，未捆绑参考软件工具 |
| 封面 | 桌面Canvas与视频抽帧 | 位置、字号和换行须检查实际图片 |
| 发布 | 发布信息及素材目录包导出 | 当前长片未执行平台发布，导出不等于发布成功 |

未配置真实服务时返回中文失败原因，不生成模拟音视频。配置和历史验证见 `docs`；早期文档的状态以各条日期为准。

## 工程与检查

- `src`：Vue界面、交互和前端共享逻辑。
- `electron`：窗口、IPC、媒体协议和解析浏览器。
- `server`：持久化、任务、质量检查、模型接入与媒体处理。
- `integrations`：IndexTTS、MuseTalk、链接解析及音色设计桥接，上游许可证保留在对应目录。
- `tests`：自动化测试与必要夹具。
- `scripts`：开发、日常启动及验证工具；部分历史脚本依赖原机器路径和本地证据，不是通用安装器。
- `docs`：设计、配置、功能差距和验收记录。

```powershell
npm test
npm run build
npm run pack
```

媒体测试需要可用的FFmpeg和FFprobe。依赖真实模型、服务或素材的验证应配置后执行，跳过项须记录。源码窗口验收不能代替打包EXE的首次启动与完整流程验收。

## 数据与提交边界

`data`、`workspaces`、`outputs`、模型、Python环境、账号会话、密钥、临时研究副本与 `evidence` 媒体证据不随源码提交。现有用户数据无需为更新源码重新初始化。本机详细证据保存在 `evidence`，仓库保留文字摘要和适合提交的测试夹具。

待处理项包括字幕准确性、文案事实与长度控制、参考模板真实模型复验、旧封面来源约束、日常入口静默提取复测、部分交互/UI差距与完整产品质量验收。早期记录保留在 [历史开发版记录](docs/历史开发版记录.md)。
